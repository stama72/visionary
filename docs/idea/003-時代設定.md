候補はいくつかあるが、ドイツの自由都市に魅力を感じた。

# 1.自由都市

中世ドイツ、北海沿岸の自由都市がテーマ。ハンザ同盟諸都市の一角という設定。

商人ギルドが支配する都市である。封建領主は存在しない。領主のレイヤーを省ける。しかし、代わりに市参事会を作る必要がある。

北海の貿易で栄えたのが特徴。港を前提に成り立つ都市にする。

船を作って貿易が可能。

教会と商人の政治権力を巡る緊張関係

大商人と手工業者の間の経済格差（ツンフト闘争）

# 2.封建制領邦都市

封建領主が治める中世ドイツの領邦都市。

騎士身分の世俗領主、あるいは、神聖ローマ帝国の帝国教会政策に基づく教会領主が治めた。
