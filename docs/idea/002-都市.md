# 都市について

## 1.都市のレベルデザイン

モデルとなる都市、時代設定を完全には確定させていないため、まだ概略。

### 1.1都市の全体像

- 城門（供給特化） ：地方から穀物や木材が安く運び込まれる。安く大量に買い付けが可能。

* 中央市場（一般・動的定価） ：市民や職人が集まる。在庫量で価格が変動する。
* 大聖堂周辺（繁華街）：目抜き通り。大商人が店を構える。
* 貴族街（高級品需要中心）：貴族、金融系の大商人が住む。
* 職人街 / ギルド（需要特化） ：木材を大量に消費して家具を作る。常に原料を欲している。
* スラム・闇市（不完全市場） ：税金がかからないが、価格が不安定で危険

- 港（高級品交易、大量輸送）：高級品の輸入に加え、一般的な物資の大量の輸出入が可能。

### 1.2都市の作り込み

特殊NPC、建物、ミニゲームの実装。

- 教会：信用やコミュニケーションについてのアドバイスをもらえる。お金または資材を寄付すれば、増改築、孤児院の建設などができる。
- 領主：税金を払う。払った税金に応じて予算が増え、様々な施設の建設クエストが解放される。
- 商人の家：店の奥にはバックオフィス、上階には居住スペースがある。オフィスに訪問できれば商談が成功しやすくなる。さらに仲良くなるとプライベートな食事に招いてくれるようになる。
- 港：船が寄港した時には交易品として都市では珍しい商品や大量の商品を一気に仕入れることができる。船員相手に食料などを売ることもできる。新しい技能を持ったNPCが船に乗ってやって来て都市に住みつくこともある。
- 酒場：たくさんの人に知り合える。お酒が回ると口が軽くなる人もいる。
- 占い師：お金を払って相談すると、次にどこに行くべきか、誰にアプローチすべきを漠然と教えてくれる
- 質屋：アイテムを質に入れるとお金を貸してもらえる。
- 賭場：何かのトランプゲームをNPCと賭けて遊べる。

## 2.都市の発展

### 2.1経済発展

主人公の働きで経済が回る->仕事が増え、職人の所得が増える->設備稼働率が向上し、追加の資本投入、労働投入により、生産性が高まる->さらに職人の所得が増える->需要が増える->さらに経済が回る

->人口が流入する->需要が増える->仕事が増える->さらに人口が流入する

流入してきた人たちの一部には失業や貧困の問題が発生する。都市の生産力のキャパシティーを超え、十分な食料供給ができなくなると彼らを養えなくなる。

彼らの救済にあたる教会を中心に、貧しい人たちの暮らしにも光を当てる作品であってほしい。

生と死、富と困窮のコントラストを描くことが人間を描くことだと思う。

### 2.3噂と気候システム

「今年の冬は寒くなる」という噂が流れると、薪や木材の「適正（目標）在庫」の内部数値を2倍に跳ね上げます。すると、実際の在庫が変わっていなくても、NPC商人が恐怖で価格を吊り上げ始めます。プレイヤーは冬が来る前に木材を買い占める「先物取引」のような遊びが可能になります。

## 3.都市外との物資のやり取り

都市の周囲は都市の支配下にある農村地帯。森林や採石場もその都市近郊のエリアにある。

- 周辺の農村からの収穫物、石材、木材の運び込み
  市場への販売目的の商品作物、徴税された穀物
- 港を通じたあらゆる商品の貿易
- 戦争に向かった兵士による武器や食料の持ち出し
  戦利品を持って帰ることもあるかも
