# 教会（カトリック）

## 1.命を描く

商人の世界(ギルド)と並び立つ、ストーリーのもう一つの核になる。

ギラギラしたお金の光とは正反対の、死にゆく命に宿る美しい信仰の光。

メメント・モリ、カルペ・ディエム。二つの光を合わせて、死と隣り合わせの街で発せられる命の輝きを描く。

### 1.1清貧

キリスト教の教会は長い間、お金を貸して利息を取る行為（高利貸し）や、過剰な利益の追求を「強欲」の罪として地獄に落ちると教えていた。

### 1.2贖罪

高利貸しや過剰な利益の追求は「強欲」の罪だった。

死が近づいた商人は贖罪のため、その資産をなげうって教会に寄付を行い、病院や孤児院の建設に取り組んだ。

## 2.貧困と向き合う

教会、とりわけ修道会は貧民の救済を使命としていた。

### 2.1修道者

世俗的な豊かさを求めた主人公とは違って、信仰と救済によって貧困に向き合うことを選ぶ修道女のキャラクターを用意したい。命のはかなさを受け入れ、信仰によって生きることを象徴する存在。
