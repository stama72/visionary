# 信用・会話システム

GDDは既に書いてある。のちのちの拡張アイデアを記述する。

### 2.5信用の減衰モデル

さらなる拡張アイデア
① 村人の「関係維持コスト」に格差（個性）をつけるすべての村人の減衰速度や回復回数を同じにするのではなく、村人の性格や立場によって変化させます。気難しい大富豪：利益は莫大だが、1日話さないだけで効果が激減し、回復に3回会話が必要（ハイリスク・ハイリターン）。気さくな職人：利益はそこそこだが、1週間放置しても効果が下がりにくい（ローリスク・ミドルリターン）。
これにより： プレイヤーは単純な「金額の計算」だけでなく、「自分のプレイスタイル（マメに寄るか、たまに大口取引するか）」に合わせた関係構築のポートフォリオを選ぶ楽しさが生まれます。
② 「派閥」や「嫉妬（トレードオフ）」の概念を導入するゲーム理論における「ゼロサムゲーム（一方が得をすると他方が損をする）」の要素を少しだけ混ぜます。特定の富豪Aとばかり仲良くしていると、ライバル関係にある富豪Bの効果が（会話していなくても）追加で減衰する。
これにより： 「全員を維持できない」だけでなく、「あっちを立てれば、こっちが立たず」という商人特有の人間関係の政治劇が発生し、選択に強い葛藤が生まれます。
③ 投資による「自動化（アウトソーシング）」の仕組みゲーム中盤以降、余った資金を使って「お土産（ギフト）」を贈るシステムや、下働きを雇って「定期的に挨拶に行かせる」仕組みを解放します。これにより： 機会費用を「時間（行動力）」から「資金」に変換できるようになります。効率化の快感が得られ、中盤の資金の使い道（シンク）としても機能します。④ 減衰の「前兆（シグナル）」を視覚化するゲーム理論では情報の透明性が戦略を面白くします。いつの間にか効果が半減していると理不尽に感じるため、「最近、あの商人さん顔を見せないね」といった噂話や、マップ上のアイコンの色の変化（緑→黄→赤）で、減衰の危機をプレイヤーに察知させます。
これにより： プレイヤーは「あ、そろそろあの富豪に会いに行かないとマズいな」と、自分でスケジュールを管理するコントロール感を楽しめます。
