## 0. この文書の位置づけ

本書は「タイトルに何を求めるか(方針)」と「候補がそれをどう満たすか(評価)」を持つ。**タイトルが指す世界そのものは [02b](02b-world-setting.md) が持つ。** 本書は 02b §1 の核を前提にし、核が変われば方針も見直す。

## 1. 命名方針

**タイトルはアイデンティティ層に属する。** [検討資料02a §5](02a-identity-and-positioning.md) の二層戦略で、マーケティングの第一声(フック)は「相場表のない経済シム。情報は足で稼げ」が担う。ストアページではタイトルのすぐ下にフックとジャンル表記が並ぶので、**「商人の経済ゲームである」ことはタイトルが言わなくても伝わる。** タイトルが担うのは「何を体験する作品か」である。

| # | 条件 | 理由 |
| - | ---- | ---- |
| 1 | **単独で意味が立つ。** 副題・画像に解釈を負わせない | 造語や外国語の成句は、意味の提示を同時にしないと「気取っているだけ」に見える(§3 の Memento Mercator) |
| 2 | **指すのは本質であって、スパイスではない** | 本作の本質は生活の暖かみ(02b §1)。死・暗さ(02b §1.1 の a)は題にしない |
| 3 | **商人/中世は必須にしない** | フックとジャンル表記・カプセル画像が担う。題と役割を重ねない |
| 4 | **日英とも辞書なしで読める** | 日英同時リリース([企画書 §1](02-project-proposal.md))。日本語話者に馴染みのない語(ラテン語・ドイツ語の専門語)は条件1 と同じ理由で落ちる |
| 5 | **検索・商標・一般語で衝突しない** | Steam の既存タイトルだけでなく、一般語としての検索結果の中で埋もれないこと |

**条件2・3 は [#68](https://github.com/stama72/visionary/issues/68) の当初の条件「商人/中世を連想させる」「古典的な深みがある」を置き換えたものである**(#68 決定3)。当初の条件はフックと役割が重なり、深みの出所を死のモチーフに求めた結果、候補が a(スパイス)側に寄った。

## 2. 候補と評価

| 候補 | 1 単独で立つ | 2 本質を指す | 4 日英 | 5 衝突 |
| ---- | ------------ | ------------ | ------ | ------ |
| **Flowers and Candles** | ◎ 具体名詞2つ | ◎ 02b §6 の象徴「花」「明かり」そのもの | △ 「フラワーズ・アンド・キャンドルズ」は長く、略称が作れない | △ 下記 |
| **A Year and a Day** | ◎ | ○ 四季の巡り(d)と、よそ者が市民になる物語(02b §9) | ○ 「一年と一日」 | △ 雑誌・小説・映画に同名がある。Steam には無い |

### 2.1 Flowers and Candles

**象徴を知らなくても字面のまま心地よく、知っている人には「はかなさと生」の二重になる。** 意味の提示を要しない点で、§3 の Memento Mercator と正反対の壊れ方をする。

弱点は3つ。**方針は変えず、人か都市の語を1語入れる方向で変種を探す**(#68 決定5)。

- **一般語として既存カテゴリの中にいる。** Steam に同名は無いが、最近接は [Flowers And Favours: Florist Simulator](https://store.steampowered.com/app/3269600/Flowers_And_Favours_Florist_Simulator/)(cozy な花屋シム)。「flowers and candles」は花屋・ホームフレグランス小売の定型語彙で、一般検索は花屋とキャンドル店に埋まる
- **[企画書 §8](02-project-proposal.md) と逆を向く。** §8 は「cozy ショップシム供給過剰への埋没」に対して「cozy 文脈の見た目に寄せすぎない」を置いている。花とキャンドルは cozy 小売そのものの語彙である。§8 の根拠(供給過剰)は変わっていないので、§8 を書き換えて通す案は採らない
- **主体がいない。** 花と明かりは物であり、02b §1 の核のうち「往来」(人と都市)と「営み」を拾わない

### 2.2 A Year and a Day

**既に決まっている時間設計と一致する。** [ADR-0003](adr/0003-calendar-structure.md) の 1年 = 120日と、[GDD05 §1.1](03-gdd/05-ui-ux.md) の 1日 = 実時間10分から、1年 = 20時間になる。これは [企画書 §2](02-project-proposal.md) のプレイ時間目標 10〜20時間の上端であり、GDD05 §1.2 は 10分を選んだ理由としてこの一致を挙げている。語の出所は中世ドイツ都市の法諺「都市の空気は自由にする」(Stadtluft macht frei)で、一年と一日を都市で暮らせば農奴も自由民になる。英語法にも同じ句がある([Year and a day](https://en.wikipedia.org/wiki/Year_and_a_day))。02b §9 は既に「市民権は一年と一日をこの街で暮らして初めて得られる」を世界の設定に採っている。

注意点は2つ。

- **GDD05 §1.3 は 1日 = 15分(1年 = 30時間)を次点に残している。** 採ると、この値は 10分の側へ引っ張られる。ただし縛りはしない — 一年と一日は市民権の条件であって、クリア時間の宣言ではない
- **プレイヤーの出自を「農奴」と特定すると、身分(市民/非市民/農奴)のシステムを1つ約束する。** 02b §9 は「よそ者として着く」とだけ書き、身分を特定していない

## 3. 方針で落ちた候補

02b v0.1 §11 に並べた6件のうち、次の5件は §1 の方針で落ちる。

| 候補 | 由来 | 落ちた条件 |
| ---- | ---- | ---------- |
| Memento Mercator | ラテン語。memento mori の言い換え。リューベック聖母教会の『死の舞踏』(1463)に商人と高利貸しが並ぶ | 1・2・4。文字どおりには「商人よ、覚えておけ」であり、日本語話者の多くは副題なしで意味を取れない。mercator はメルカトル図法を連想させる。完全にラテン語で、舞台(北ドイツ)の響きも無い。死のモチーフは a(スパイス)を指す |
| Kontor | ハンザの商館・帳場 | 1・4。日本語話者に馴染みがない |
| Stadtluft | 法諺「都市の空気は自由にする」 | 1・4。発音も意味も伝わりにくい。**法諺の中身は A Year and a Day と 02b §9 に残る** |
| Pfennig | 北ドイツの小銭 | 2。小銭は b の象徴で、本質を指さない。深みも出ない。**通貨名としては 02b §11 に残る** |
| Salt and Psalm | ハンザの塩と教会の詩篇 | 4。Psalm の読みが日本語圏で立たない |

## 4. 決定後の手順

1. Steam ストア検索・商標(日米欧)・ドメインの衝突を確認する
2. `docs/` 内の「Visionary(仮題)」を置き換える(02b・README・企画書・コンセプトシート・TDD・タスク仕様)
3. リポジトリ名・ソリューション名(`Visionary.sln` / `Visionary.Sim`)を改名するかは別に判断する。コード側の改名はビルド・CI・パイプラインに波及するため、即座には行わない
