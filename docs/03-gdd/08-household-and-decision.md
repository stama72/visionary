## 1. 設計方針

1. **1つの量で束ねる。** 機会費用が、空間の摩擦・時間の摩擦・信用の効果・Need の発生頻度をすべて決める。個別の規則を並べない
2. **役割は規則で与えず、生産性の差から出す。** 「主婦が家事をする」と決め打ちしない。**機会費用が低いから結果的にそうなる**
3. **循環させない。** 意思決定の入力は常に**前日の確定値**である(§6)
4. **説明可能であること。** NPC が「○○の店まで行くのは面倒でね」と言えば、プレイヤーに数値を見せずに因果が伝わる([GDD02](02-economy.md) 方針2)
5. **数値は初期値。** 構造と依存関係だけを固定する

## 2. 世帯

### 2.1 世帯の範囲(**決定**)

**世帯を経済主体とする。**

| 構成員         | 世帯に含むか       | 根拠                                                                   |
| -------------- | ------------------ | ---------------------------------------------------------------------- |
| 親方(世帯主)   | **含む**     |                                                                        |
| 主婦           | **含む**     | 中世では女性も家業を手伝う。**「主婦」は職業ではなく属性である** |
| 子ども         | **含む**     | その家の子なら将来の跡継ぎ                                             |
| 徒弟           | **含む**     | 住み込み。給金なし・食住のみ([GDD02 §7.1](02-economy.md))              |
| **職人** | **含まない** | **職人は自分の家計を持つ**。別世帯として扱う                     |

**職人を外すことが要点である。** 徒弟は親方の家に住み込み、職人は独立した家計を営む — 史実に沿い、かつ「誰の財布か」が明確になる。

**各役割の人数は [GDD02 §2.4](02-economy.md) が M0 の初期値として持つ**(親方1・主婦1・子ども1・徒弟1の4人)。構造(4つの役割を持つこと)は本節、値(人数)は GDD02 という分け方は §9(季節係数)と同じである。

### 2.2 世帯が持つもの

| 持ち物                   | 単位           | 根拠                                                            |
| ------------------------ | -------------- | --------------------------------------------------------------- |
| **流動資金**       | 世帯           | [GDD02 §6.2](02-economy.md) の家計を世帯単位に改める            |
| **帳簿(取引履歴)** | 世帯           | **資金の増減と一致するため。** 個人別に持つと突合できない |
| 在庫                     | 世帯 + 工房    | 消費財は世帯、生産の入出力は工房                                |
| 信用                     | **個人** | §8.2                                                           |
| 相場知識                 | **個人** | §8.1                                                           |
| 熟練度                   | **個人** | §4                                                             |

> **信用と相場知識だけが個人持ちである。** どちらも「その人が誰と会い、何を見たか」に依存する。世帯で共有されるのは**帰宅時**であり、即座ではない(§8)。**情報の摩擦**([GDD02 §4](02-economy.md))を世帯の内側にも通す。

## 3. 役割と時間配分

### 3.1 1日の可処分時間

1 tick = ゲーム内1時間([ADR-0002](../adr/0002-time-model-and-determinism.md))。24時間のうち睡眠・食事を除いた**可処分時間 T**(初期値 12時間)を配分する。

| 用途               | 内容                                         |
| ------------------ | -------------------------------------------- |
| **家業労働** | [GDD02 §5](02-economy.md) の生産に投入される |
| **家事**     | 世帯の日次家事量を埋める(§3.2)              |
| **買い物**   | 移動 + 待ち(§7)                             |
| 会話・その他       | 余り                                         |

### 3.2 家事

**世帯は日次の家事所要時間を持つ**(構成人数に比例)。埋まらないとどうなるか:

**家事の不足分は、2つの方法で代替できる**:

| 代替策 | 内容 | 経済的な帰結 |
| ------ | ---- | ------------ |
| **サービス業の購入** | 調理する者がいない世帯は酒場で食べる([GDD02 §3.2](02-economy.md)) | **酒場・宿屋の需要源** |
| **徒弟(使用人)を雇う** | 家事を担う人手を世帯に加える | **雇用の需要源。** 食住のコストと引き換えに時間を買う |

**どちらを選ぶかは機会費用で決まる。** 一時的な不足なら外食、恒常的な不足なら雇用のほうが安い。

> **これが酒場・宿屋の需要源である。** [GDD02](02-economy.md) はサービス業を「最終財の大口需要者」として置いたが、**その需要がどこから来るのかは書いていなかった。答えは家事の外部化である。**
>
> 代替もできない(資金が無い)場合は困窮([GDD02 §6.3](02-economy.md))へ落ちる。

### 3.3 商業・サービス職の階層(**決定**)

**商業・サービスにも親方 / 職人 / 徒弟の枠組みを適用する。** 別の職業としては扱わない。

**生産物が無い職種では、熟練度は「信用の上がりやすさ」に効く。** 加えて、**仕事の割り振りを決めるパラメータ**として使う:

| 階層                 | 担当                                         | 理由                                                   |
| -------------------- | -------------------------------------------- | ------------------------------------------------------ |
| **徒弟**       | 家事、店番                                   | 機会費用が最も低い                                     |
| **職人(番頭)** | 仕入れの価格交渉、大口顧客の対応、運送の手配 | **信用が上がりやすいので大口を任せる価値がある** |
| **親方(主人)** | 関係性づくり、大口取引の交渉                 | 最も信用が上がりやすい                                 |

## 4. 熟練度と生産性

### 4.1 熟練度は連続である

- 仕事の経験に応じて**連続的に**上がる。段階的にしない
- 連続なら、**経験時間の長さが雇用時の選好に効く**
- 単位は ‰ の整数(0〜1000)

**家事で忙しい主婦・子ども、未経験の従業員は熟練度が上がりにくく、機会費用が低い。**

> **役割分担が規則ではなく帰結として出てくる。** 「主婦と子どもが買い物をする」と決めていない。機会費用が低いから、§7.2 の委託先に選ばれる。**設定のリアリティが、メカニクスの副産物である。**

### 4.2 生産性

```
生産性‰_i = CeilDiv( 熟練度‰_i × 設備係数‰_i , 1000 )
1時間あたり出力_i = ApplyPermille( レシピの標準出力/時間, 生産性‰_i )
```

- 設備係数は工具の有無・摩耗で決まる([GDD02 §5.3](02-economy.md))
- すべて int と ‰。除算は切り上げヘルパー([ADR-0002](../adr/0002-time-model-and-determinism.md))

> **この式は v1.0 用である。** 時間配分(熟練度に応じて家業へ充てる時間が変わる)を入れて初めて `レシピの標準出力/時間` という時間ベースの量が意味を持つ。**M0 は時間配分を入れない**(§9)ため、この式は使わず、**GDD02 §5.2 が労働力ベースの式(所要労働‰ に対する労働力合計‰ の比)で M0 の生産量を直接定義する。** §9「M0 での式の単純化」もこの節を参照する形に改めた。

## 5. 機会費用

**その1時間を他に使ったときの価値。** 単位は「1時間あたりの貨幣(int)」。

### 5.1 生産職

```
粗利_r     = Σ(出力量_k × 提示価格_k[前日]) − Σ(入力量_j × 原価_j[前日])
時間価値_i = CeilDiv( ApplyPermille(粗利_r, 生産性‰_i) , 所要労働_r )
機会費用_i = max( 職業下限, 移動平均_N(時間価値_i) )
```

- **価格と原価は前日の確定値**(§6)
- 移動平均は [GDD02 §8.1](02-economy.md) の原価と同じ方式。単日の変動で機会費用が跳ねない
- **職業下限**は 0 を防ぐ。生産が止まっている職人の機会費用が 0 になると、あらゆる面倒を引き受けてしまう

### 5.2 商業職 — 信用を貨幣に換算する

**商業職の産出は財ではなく信用である。**

```
機会費用_i = 期待信用増分/時間_i × 信用1点の貨幣価値
```

**信用1点の貨幣価値は、[GDD01 §2.2](01-trust-and-conversation.md) 効果1 から導ける。** 効果1 は実効価格を `p' = p × (1 − α × trust/100)` とするので、**信用が1点上がると、その相手との取引が α/100 だけ有利になる**:

```
信用1点の貨幣価値 = CeilDiv( 想定年間取引額 × α‰ , 100 × 1000 )
```

> **新しい係数を導入していないことが重要である。** 換算レートは既存の α から出る。**α を調整すれば信用の価値も機会費用も同時に動く**ので、調整軸が増えない([GDD02](02-economy.md) 方針2)。

**期待信用増分は階層で異なる**(§3.3)。親方 > 職人 > 徒弟。したがって**大口取引は親方・番頭が担当するのが合理的になる** — これも規則ではなく帰結である。

### 5.3 その他の職

| 職           | 機会費用                                                 |
| ------------ | -------------------------------------------------------- |
| サービス     | §5.1 と同型(レシピを持つため)                           |
| 運送         | `運賃 ÷ 所要時間`。§5.1 の粗利を運賃に置き換えたもの |
| 主婦・子ども | 家業を手伝うときの §5.1。**熟練度が低いので低い** |
| 徒弟         | 同上。**最も低い**                                 |

## 6. 循環の解消(**論点1への回答**)

### 6.1 循環は3本ある

```
① 機会費用 → 払える上限 → 購入 → 設備 → 生産性 → 機会費用
② 機会費用 → 払える上限 → 買う/買わない → 価格 → 粗利 → 機会費用
③ 機会費用 → 誰が家事をするか → 可処分時間 → 熟練度の伸び → 生産性 → 機会費用
```

### 6.2 何が壊れるか

**決定論は壊れない。** [TDD01 §3.3](../04-tdd/01-sim-core-and-m0.md) がシステムの実行順を固定しているので、値は一意に定まる。**壊れるのは意味と安定性である**:

| 壊れ方                       | 内容                                                                                                                                    |
| ---------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| **意味の恣意性**       | どの値が「正しい」かが、システムの並び順という設計上の都合で決まる。**並びを変えると経済が変わる**                                |
| **発散**               | ①は正のフィードバックである。高く買える → 良い設備 → 生産性↑ → さらに高く買える。歯止めが無い                                      |
| **観測不能**           | 同一tick内で値が更新されると、プレイヤーは「なぜこの価格か」を追えない([GDD02](02-economy.md) 方針2)                                     |
| **同一tick内の不整合** | 機会費用を必要時に計算する実装だと、**同じ NPC の機会費用を、同じ tick 内で違うシステムが違う値で見る**。これは決定論の問題になる |

### 6.3 解法:1日遅延で成層化する

**機会費用は1日の初めに一度だけ算出し、その日は固定する。入力はすべて前日の確定値とする。**

```
機会費用[d] = f( 生産性[d−1], 提示価格[d−1], 原価[d−1] )
```

[TDD01 §3.3](../04-tdd/01-sim-core-and-m0.md) の日次パイプラインの**先頭**に置く:

```
0. OpportunityCost   Daily(hour: 0)   ← 前日の確定値から算出。以後1日固定
1. Production
2. Consumption
3. Household
...
```

**これで3本すべてが切れる**:

| 性質                   | なぜ成立するか                                                                                  |
| ---------------------- | ----------------------------------------------------------------------------------------------- |
| **非循環**       | 当日の購入・生産・価格は、当日の機会費用に影響しない                                            |
| **決定的**       | 全システムが同一tick内で同じ値を見る。実行順に依存しない                                        |
| **説明可能**     | 「昨日の稼ぎがこうだったから、今日はこう動く」。**1日という単位はプレイヤーの直感に合う** |
| **発散しにくい** | 移動平均(§5.1)と併せて、正のフィードバックの利得が1日1回に制限される                           |

> **「前日の値を使う」は妥協ではなく仕様である。** 中世の商人が今日の相場を完全に把握して動くほうが不自然であり、**1日遅れは情報の摩擦**([GDD02 §4](02-economy.md))**の一形態**である。

### 6.4 残る危険

- **初日**(`Tick.Zero`)には前日が無い。初期値を職業ごとに与える。**この初期値が長期の均衡に影響しないことを確認する**(§9 の検証項目)
- 移動平均の窓 N が短いと振動しうる。**N は調整軸である**

## 7. 買い物の意思決定

### 7.1 誰の需要か(**決定**)

**需要の単位は品目の性質で決まる。**

| 品目                                                 | 単位           | 計算する人                       |
| ---------------------------------------------------- | -------------- | -------------------------------- |
| **必需**(パン・薪・塩)                         | **世帯** | **主婦。いなければ世帯主** |
| **飲食料の嗜好・奢侈**(ビール・ワイン・香辛料) | **世帯** | 同上                             |
| 肉                                                   | 世帯           | 同上                             |
| **耐久**(衣服・靴) | **個人** | 本人。**予算は `min(相場基準, 世帯の流動資金 × 比率‰)`**([GDD02 §8.2.1](02-economy.md)) |
| 工具                                                 | 工房           | 親方                             |

> **飲食料はすべて世帯単位である。** ビール・ワイン・香辛料は分類上は嗜好・奢侈だが、**いずれも飲食料品なので必需品と同じく主婦が計算する**。分類(値ごろ感の決め方、[GDD02 §8.2](02-economy.md))と、**誰が数えるか**は別の軸である。
>
> **嗜好・奢侈の需要が出るのは徒弟以外**(世帯主・主婦・子ども)。徒弟は食住のみで自分の財布を持たない。職人は別世帯なので自分で持つ(§2.1)。

#### 徒弟はどうやって靴を買うか

**徒弟が自分の財布を持たないと、耐久財を買えなくなる。** 耐久財は個人単位(上表)なので、このままでは徒弟が裸足で歩くことになる。

**解決は予算の側にある。** [GDD02 §8.2.1](02-economy.md) は耐久財の基礎値を `min(相場基準, 世帯の流動資金 × 比率‰)` とした。**世帯の資金の一定比率(初期値10‰)までなら、誰でも買える。**

**同じ条件を全階層に適用する。** 親方であっても、世帯の資金に対して不相応な耐久財は買えない。**「相場を知っていても資金がなければ買えず、資金があっても相場より高くは買わない」** — `min` の両側がそれぞれ別の歯止めになっている。

### 7.2 誰が買いに行くか

**主婦(または世帯主)が世帯分のリストを作り、最も機会費用の低い手空きの構成員に委託する。**

```
委託先 = argmin( 機会費用_i )  over 手が空いている世帯構成員
```

- 通常は**徒弟か子ども**が選ばれる(§4.1)
- 耐久財は本人が選ぶが、**機会費用の低い家族に委託してもよい**

### 7.3 どの店で買うか → [GDD06](06-trade-and-negotiation.md)

**店の選択と実質コストは分冊06 が持つ。** 店ごとに異なるものは06、という境界([GDD02 §0](02-economy.md))による。

**本書が供給するのは機会費用だけである**:

**式そのものは [GDD06 §2](06-trade-and-negotiation.md) が持つ**(移動時間 × 委託先の機会費用を、目標在庫で1単位あたりに割り戻して実効価格へ足す)。ここで重要なのは委託先の機会費用が実質コストに入ることである。

**委託先の機会費用が入ることに意味がある。** 徒弟に行かせれば実質コストが下がり、遠い店も候補に入る。**§7.2 の委託の判断が、店の選択肢の広さに直結する。**

> **待ち時間は実質コストに入れない**([GDD06 §2.1](06-trade-and-negotiation.md))。買い物までの時間には他の仕事ができるため、実際に時間が奪われるわけではない。**時間の緊急性は予算の側**([GDD02 §8.2.2](02-economy.md) の予想在庫)**に入る。**

### 7.4 いつ Need(クエスト)になるか

**世帯内で賄えないときだけ、Need として外に出る。**

```
Need にする条件:
  min(世帯内の機会費用) × 所要時間  >  外注コストの見込み
```

- 日用品は所要時間が短く、世帯内に機会費用の低い者がいる → **Need にならない**
- 遠方・大量・急ぎ・手が空いていない → **Need になる**

> **これが [GDD01 §2.3](01-trust-and-conversation.md) の信用インフレを止める唯一の絞りである。** パンに毎日 Need が立つと、プレイヤーは日課をこなすだけで信用を積める。**機会費用が Need の希少性を作る。**

## 8. 世帯内の情報共有

### 8.1 相場知識(**決定**)

**相場知識は個人が持つ**([GDD01 §4.1](01-trust-and-conversation.md))。世帯内では**帰宅時に共有する**。

| 経路             | 内容                                                             |
| ---------------- | ---------------------------------------------------------------- |
| **帰宅時** | その日の取引履歴にある相場情報を、世帯の全員に共有する           |
| **委託時** | 買い物を頼むとき、**その品目についての相場**を委託先に渡す |

> **子どもは相場を知らないのでぼったくれる。だが家に帰れば大人が知る。**
>
> この流れが**メカニクスから自然に出る**ことが、この設計の価値である。プレイヤーが子どもに高く売ると、その日のうちに世帯全員の相場観が更新され、**世帯主の「その店への信用」が下がる**(§8.2)。[GDD01 §4.5](01-trust-and-conversation.md) の不当価格判定が、世帯という単位で意味を持つ。

**スコープの注意**: 完全な「会話による相場共有」は複雑になる。**M0 では帰宅時共有と委託時共有の2経路のみ**とし、任意の会話による伝播は v1.0 とする(§9)。

### 8.2 信用の波及(**決定**)

**信用は個人が持つが、変化は帰宅時に世帯内へ波及する。**

#### なぜ帰宅時か

即時に波及させると、**世帯の全員が「見ていない出来事」を知ってしまう**。それは情報の摩擦([GDD02 §4](02-economy.md))を世帯の内側で壊すことであり、§8.1 の相場共有と扱いが食い違う。**同じ経路(帰宅)に乗せることで、概念も実装も1つで済む。**

#### 波及の形

| 向き                                     | 内容                                                                   | 波及率(初期値)                                     |
| ---------------------------------------- | ---------------------------------------------------------------------- | -------------------------------------------------- |
| **保有側**(自分が持つ他者への評価) | A が X への信用を Δ 動かしたら、A の世帯の全員も X への信用を動かす   | **高い**。家族で話すため                     |
| **被評価側**(他者が自分に持つ評価) | X が A への信用を動かしたら、X は A の世帯の他の者への信用も少し動かす | **低い**。「あの家の者だから」という緩い連座 |

**負の波及率 > 正の波及率とする。** [GDD01 §2.4](01-trust-and-conversation.md)「信用は築くのに時間がかかり、失うのは一瞬」の非対称性を、波及にも適用する。**悪い話のほうが伝わりやすい。**

> **世帯は噂の最小の伝播単位である。** [GDD01 §7](01-trust-and-conversation.md) は「不履行後の悪い噂の限定伝播(家族・仕事仲間・近所)の範囲を分冊02とあわせて設計する」を宿題としていた。**本節が「家族」の部分に答えを与える。** 仕事仲間は雇用関係([GDD02 §7](02-economy.md))、近所は区画で定義できる。

### 8.3 店に対する信用 → [GDD06 §5](06-trade-and-negotiation.md)

**店主と応対店員の平均を取引時の信用とする**([GDD06 §5](06-trade-and-negotiation.md))。信用の変化も両方に効く。これは導出値であり、`TrustScore` は個人間のままである。

**本書との接続**: これにより、**大口取引を親方・番頭が担当するのが合理的になる**(§3.3)。店主が応対すれば信用は店主に二重に乗るためである。

## 9. M0 のスコープ

**M0 では機会費用を職業 × 階層の固定値とする**([GDD02 §8.2.6](02-economy.md))。

```
機会費用_i = ApplyPermille( 職業別の基準値 , 階層係数‰_i )
```

| 階層・役割 | 階層係数‰(初期値) |
| ---------- | ------------------- |
| 親方(世帯主) | 1000 |
| 職人(番頭) | 600 |
| 主婦 | 400 |
| 子ども | 250 |
| 徒弟 | 200 |

> **職業だけの固定値にはできない。** 職業は世帯の属性である([TDD01 §3.2](../04-tdd/01-sim-core-and-m0.md))ため、職業別の1値だと**同一世帯の構成員が全員同じ機会費用**になる。すると §7.2 の `委託先 = argmin(機会費用)` が常に同値になって「Id 最小の構成員」に退化し、**§7.2 の委託そのものと、それに依存する記述がまとめて成立しなくなる** — [GDD06 §3](06-trade-and-negotiation.md) の「徒弟に行かせれば遠い店も候補に入る」、[GDD02 §4.3](02-economy.md) の「立地のコントラストは徒弟の移動で表す」、§7.4 の `min(世帯内の機会費用)` による Need の絞り。
>
> **新しい概念ではない。** §5.2 が既に「期待信用増分は階層で異なる。親方 > 職人 > 徒弟」と書いており、§5.3 が主婦・子ども・徒弟を「熟練度が低いので低い」としている。**M0 はその順序を固定値で先取りするだけ**であり、熟練度(§4)を入れたときに係数を外せば §5 の式へ戻る。

| 要素                                         | M0                                       | v1.0                       |
| -------------------------------------------- | ---------------------------------------- | -------------------------- |
| 機会費用の**構造**(上乗せが価格に乗る) | **入れる**                         |                            |
| 機会費用の**値**                       | **職業 × 階層の固定値**(§9)      | §5 の式で算出             |
| 世帯を経済主体にする                         | **入れる**(資金・帳簿・需要の単位) |                            |
| 熟練度・時間配分・家事                       | 入れない                                 | 入れる                     |
| 帰宅時の相場共有・信用波及                   | **入れる**(経路が単純なため)       | 任意の会話による伝播を追加 |
| 店の信用(§8.3)                              | **入れる**                         |                            |

**構造を先に固定し、値の由来を後から差し替える**のは [GDD02 §9](02-economy.md)(季節係数)と同じやり方である。

#### M0 での式の単純化(**決定**)

**熟練度と時間配分を入れないため、それらを入力に持つ2つの式を M0 では単純化する。式そのものは書き換えない。**

| 式 | M0 での扱い |
| -- | ----------- |
| §4.2 `生産性‰ = CeilDiv(熟練度‰ × 設備係数‰, 1000)` | **この式自体を使わない。** M0 の生産量は [GDD02 §5.2](02-economy.md) の労働力ベースの式(労働力合計‰ ÷ 所要労働‰、設備係数‰は二値)が持つ。工具の摩耗([GDD02 §5.3](02-economy.md))は M0 に入るので**設備係数は動く**。[GDD02 §7.3](02-economy.md) が M0 で固定するのは**労働力の構成(雇用の増減が無い)**であって設備ではない |
| §7.2 `委託先 = argmin(機会費用) over 手が空いている世帯構成員` | **「手が空いている」を判定しない。世帯構成員のうち機会費用が最小の者**(同値なら Id 昇順、[ADR-0002](../adr/0002-time-model-and-determinism.md)) |

> **どちらも構造を残して入力だけを固定している。** 熟練度と時間配分を入れたとき、式を書き換えずに定数を外すだけで済む。

### 検証項目(M0)

| # | 検証内容                 | 判定基準                                                                          |
| - | ------------------------ | --------------------------------------------------------------------------------- |
| 1 | 循環が切れているか       | 機会費用が同一日内で変化しない(§6.3)                                             |
| 2 | 初期値が均衡に残らないか | 職業別の初期機会費用を変えて長期実行し、**終盤の価格分布が一致する**(§6.4)。**M0 では実行しない** — §9 の機会費用は初期値ではなく**走行中ずっと定数**なので、変えれば実質コストが恒久的に変わり、一致しない方が正しい。この項目は §5 の式で日々算出する v1.0 向けである |
| 3 | Need が希少か            | 日用品(パン)由来の Need が全 Need に占める割合が過大でない(§7.4)                 |
| 4 | 世帯内共有が効くか       | 子どもへの高値販売の後、**世帯主の当該相手への信用が下がる**(§8.1・§8.2)  |
