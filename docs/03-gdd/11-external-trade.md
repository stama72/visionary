## 1. 貿易専用品目

| 層 | 品目 | 分類 | 備考 |
| -- | ---- | ---- | ---- |
| 貿易 | 塩 | **必需**(保存・調味) | 都市内で作れない |
| 貿易 | ワイン | 奢侈 | 同上 |
| 貿易 | 香辛料 | 奢侈 | 同上 |

**貿易専用品目は都市内で作れない。供給は港(§3)のみである。**

> **外部依存が構造的に発生する品目**を持つことで、貿易商の存在意義と、港が止まったときの緊張が生まれる。**塩を必需にしたことの帰結として、港が止まると全 NPC が困る。** 貿易の重要性が体感される設計である。

**塩は買い手側に固有の問題を持ち込む。** **塩の目標在庫は2週間分**(初期値。用途は「必需の消費」で、式は [GDD02c §2.1](02c-price-and-budget.md) が持つ。**品目が M0 に無いので値は本書が持つ**)であるのに対し、[GDD12](12-countryside-and-fairs.md) の農村世帯は季節に一度しか都市に来ない。**自給に倒せないので、来訪間隔と目標在庫の差のぶん在庫が尽きる。** 素直な解は農村世帯の目標在庫を来訪間隔ぶんに取ることだが、**それは目標在庫に「世帯の種別」という次元を入れることになる。** [GDD12](12-countryside-and-fairs.md) と合わせて決める。

## 2. A-1:行商人(陸路)

- **幅広い品目を少量**扱う
- 各区画を巡回し、都市内の提示価格で売買する
- **スプレッドが大きい**(買値と売値の差)。行商人と取引すると必ず損をする
- **[GDD02 §4.2](02-economy.md)「詰みは作らない」の担い手。** プレイヤーが何もしなくても最低限は流通するが、遅く・高い

**行商人は世帯ではない。** [TDD01 §3.2](../04-tdd/01-sim-core-and-m0.md) の `Market` は「品目 × 売り手**世帯**」なので、**売り注文を出す場所を先に設計する必要がある。**

## 3. A-2:港(海路)

- **限られた品目を大量**に扱う: 穀物・木材・鉄鉱石・塩・ワイン・香辛料
- **スプレッドが小さい**。大口取引の効率を表現する
- **貿易専用品目の唯一の供給源**
- **都市内の貿易商が取引した分は、スプレッドが都市内の利益になる**

> **最後の点が重要である。** 港のスプレッドは、貿易商が介在すれば都市内に残り、介在しなければ外部へ出る。**貿易商を育てること自体が都市の富を増やす**という構造になり、プレイヤーが貿易商になる動機にもなる。

**外部価格は季節でゆっくり動く。急変させない**(プレイヤーが読めなくなる)。品目ごとに帯の幅が違う — 鉄鉱石は外部依存が強く帯が狭い、パンは都市内財なので港では扱わない。

> **[GDD02 §4.3](02-economy.md) の区画に役割は無い。**「港区画」という特別な区画は作らず、**貿易商がどこに居るかだけが効く。**

## 4. 貿易商

**貿易商はレシピを持たない職業である。** 港で仕入れ、都市内で売る。

```
販売在庫 < 出荷目標在庫([GDD02c §1](02c-price-and-budget.md)) のとき:
    仕入単価   = 外部価格帯の下限値(v1.0。輸出が無い段階では上限値)
    仕入数量   = min( 出荷目標在庫 − 販売在庫 , floor(流動資金 ÷ 仕入単価) )
    販売在庫  += 仕入数量
    流動資金  -= 仕入単価 × 仕入数量
```

- **仕入数量は流動資金の範囲に切り詰める。** 流動資金を負にしない
- **提示価格は [GDD02c §1](02c-price-and-budget.md) の通常式に従う**(原価 = 仕入れの移動平均)。貿易商は「財の投入がある職業」に分類される

> **輸出経路が無い段階では、スプレッドは都市内に残らない。** 仕入を帯の上限で行い、下限で売る経路が無いなら、**港のスプレッドそのものは都市外に出たままである。** 都市内に残るのは `最低利幅‰` だけであり、貿易商の利益はこの利幅が担う。**輸出を加えて初めて §3 のスプレッド取り込みが機能する。**

**貿易商は [GDD09 §4](09-treasury-and-tax.md) が記録した「販売職の運転資金」の典型例である。** `必要運転資金`([GDD02c §2.1](02c-price-and-budget.md))はレシピの入力と必需の消費しか走査しないので、**貿易商の仕入資金が1枚も入らない。** 貿易商を入れるときに、売り手側の運転資金を表す項を決める必要がある。

## 5. 運送労働者

- **区画間の運搬を担う。** [GDD02 §4.2](02-economy.md) の摩擦の下限のもう一方
- **「遅い」ことが仕様である。** 依頼を受けてから運ぶまでに日数がかかり、運賃も高い。**速さで勝つのがプレイヤーである。まとめ運びで勝てるかは積載量による**(§5.1)
- [GDD06 §3.1](06-trade-and-negotiation.md) の Need「在庫不足 / 遠方在庫」を**履行する主体**がこれである

**運送労働者は産出を持たない世帯である。** 運搬を実装しないまま置くと**消費だけする世帯**になり、確実に破産へ向かって [GDD02 §8-2](02-economy.md) に偽の信号を混ぜる。**運搬の実装とセットでしか入れられない。**

### 5.1 優位性の源泉は積載量である(**方向の決定**)

**1回の移動で運べる数量に上限を置き、運送労働者はその上限が大きい、という形にする。** 運送労働者が普通の世帯より優れているのは、速さでも運賃の安さでもなく、**一度に多く動かせる**ことである。

- **プレイヤーの成長の軸がもう1本できる。** 荷運び手段への投資(分冊04)で上限を上げ、回数をこなす。**「信用を積む」以外の道ができる**
- **空間の摩擦を担保する側面もある。** [GDD02d §2](02d-external-market-and-money.md) の窓口へ持ち込める余剰の量に上限がかかるので、**窓口が区画間の在庫圧力を平準化する経路が細る**([GDD02 §8-4](02-economy.md) / [issue #29](https://github.com/stama72/visionary/issues/29))

> **下の3候補は、[GDD06 §2](06-trade-and-negotiation.md) が移動を「1単位あたりへ割り戻す」と定めていた時期の検討である。** [issue #85](https://github.com/stama72/visionary/issues/85) 後の GDD06 §2 は移動を**外出1回の固定費**として扱い、割り戻しをやめた。**したがって「何で割るか」という問いの立て方そのものが現行の規則には無く、3候補の比較は成り立たない。** 上限をどう効かせるかは [issue #58](https://github.com/stama72/visionary/issues/58) が現行の規則の上で立て直す。**以下は当時の検討として残す。**
>
> **式はまだ無い。上限を移動費(当時の GDD06 §2)へどう効かせるかで、候補が3つある。** どれを採るかで**「大口では運送労働者のほうが安い」が成り立つかどうかが変わる**ので、上の箇条書きはそこに依存しない範囲しか書いていない。
>
> | 候補 | 帰結 |
> | ---- | ---- |
> | **上限(定数)で割る** | 移動費が購入量に依らなくなる。**GDD06 §2 が目標在庫で割っているのと同じ性質**(あちらは「1回の来店で目標在庫ぶんを買う」という単純化として受け入れている)。上限が大きいほど一律に安くなるだけで、**大口と少量の逆転は起きない** |
> | **実際に運ぶ量で割る** | 移動費 → 実質コスト → 購入量([GDD02b §5.2](02b-consumption-and-household.md))→ 運ぶ量 → 移動費 の**循環**。§8.2.3 が「反復せずに一度で解ける」と保証した閉形式が解けなくなる |
> | **回数を数える**(`回数 = CeilDiv(運ぶ量, 上限)`) | 運ぶ量を**目標在庫**(外生の値)に固定すれば循環しない。**上限が小さいほど回数が増えて1単位あたりが上がる**ので、大口ほど運送労働者が有利になる。ただし GDD06 §2 の除数の意味が「按分」から「回数」へ変わる |
>
> **運送労働者との比較は運賃で行う。** [GDD08 §7.2](08-household-and-decision.md) の「委託先の機会費用」は**自世帯の構成員**の値であり、外部への依頼は [GDD08 §7.4](08-household-and-decision.md) の**外注**として運賃で比較される。**[GDD08 §5.3](08-household-and-decision.md) は運送職の機会費用を `運賃 ÷ 所要時間` と定めているので、運賃が入力である。**

> **[GDD02d §2](02d-external-market-and-money.md) の輸出規則の書き換えを伴う。** 現行の輸出は「売り手が余剰を持ち込む」形だが**移動も費用も持たない**ので、上限を効かせるにはまず運搬として書き直す必要がある。
>
> - **書き直さずに上限だけを足すと、貨幣の流出が止まらなくなる。** 輸入は品目別・買い手別に分散するが、輸出は1世帯の余剰が集中するので、**上限は輸出にだけ効く。**[GDD02 §8-6](02-economy.md) が落ちる経路である
> - **書き直すと、[GDD02d §2](02d-external-market-and-money.md) の成立条件 `原価 < 外部買値 < 原価下限` の比較対象が `原価 + 移動費` に変わる。** この不等式は GDD02 の §10.2・§12-1・§13.2 の3か所が持っているので、**同時に直す**

> **M0 には入れない**([GDD02 §9.1](02-economy.md))。**上限を緩和する手段(運送労働者・プレイヤーの荷運び)が M0 に無いので、制限だけが残る。** 設計の詰めは [issue #58](https://github.com/stama72/visionary/issues/58)。

## 6. 外部ではないもの — 農民 NPC との区別(**重要**)

[GDD12](12-countryside-and-fairs.md) の農村職業は、**行商人・港とはまったくの別物である。**

| | 行商人・港(本書) | 農民 NPC([GDD12](12-countryside-and-fairs.md)) |
| -- | ---------- | -------- |
| 価格 | **外部市場の固定価格帯** | **都市内の提示価格** |
| 頻度 | 常時(行商)/ 随時(港) | **季節に一度** |
| 性格 | 都市の外の経済 | **都市経済の一部** |

**農民が外部市場価格ではなく都市内価格で取引するため、都市の価格変動が農民の購買力に直接効く。** 都市の物価が上がれば農民は買い控え、下がれば買う。**閉じたフィードバックの内側にいる。**

## 7. 自動調節への寄与

**貿易が入ると、[GDD02d §4](02d-external-market-and-money.md) の price-specie-flow が NPC を経由する形になる。**

```
税による通貨量の減少([GDD09](09-treasury-and-tax.md))
  → 購買力の低下
  → 物価の下落
  → 輸出競争力の向上(都市内価格が外部価格帯の下限に近づく)
  → 輸出の促進
  → 貿易黒字
  → 通貨量の回復
```

さらに**分業の利益**をもたらす: 余剰生産能力がある品目は**輸出で稼ぎ**、不足する品目は**輸入でコストを抑える**。

> **その結果、都市内の職業構成のばらつきが「個性」として残せる。** 全職業が均等に揃っていなくても、貿易が凸凹を埋める。これは都市ごとの性格づけ(将来の複数都市)にも繋がる。

**M0 との違いは担い手だけである。** [GDD02d §4](02d-external-market-and-money.md) の窓口版は同じ負のフィードバックを**世界側の抽象**で実現している。**本書が加えるのは、その裁定を NPC が担うことで生じる遅れ・資金制約・スプレッドである** — すなわち**プレイヤーが入り込める隙間**である。
