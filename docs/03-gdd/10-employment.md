## 1. 構造

**親方 / 職人 / 徒弟** の3階層([idea/008](../idea/008-NPCと職業.md) §1.4.1 のギルド構造)。

- **工房を持てるのは親方のみ**
- **職人は自分の家計を持つ別世帯である**([GDD08 §2.1](08-household-and-decision.md))。週次で給金を受け取る
- **徒弟は親方の世帯に属し、食住のみで給金は受け取らない**
- 労働力係数‰ は [GDD02 §5.2](02-economy.md) が持つ(親方1000 / 職人800 / 徒弟300、初期値)

> **商業・サービス業にも同じ枠組みを適用する。** 別の職業としては扱わない。生産物が無い職種では熟練度が「信用の上がりやすさ」と仕事の割り振りに効く([GDD08 §3.3](08-household-and-decision.md))。

## 2. 雇用の増減

- 生産が需要に追いつかない状態が続くと、親方は職人か徒弟を雇おうとする(Need「労働力不足」、[GDD02 §8.4](02-economy.md))
- 資金が続かなければ解雇する。解雇された職人は §3 の供給プールに戻る

### 2.1 徒弟のレイオフ

**破産([GDD02 §6.3](02-economy.md))の前段階のコスト削減策として、親方が徒弟を解雇できるようにする。**

- **季節ごとの決算を判断の基準にする**(日次で判断させると解雇と再雇用が振動する)
- 徒弟は給金を受け取らない(§1)ので、**削減されるのは生活費であり、失われるのは労働力係数 300‰** である
- **「食い扶持を減らすか、生産能力を保つか」という形の意思決定になる**

> **解雇された徒弟の行き先が要るので、§2 の雇用市場より先には入れられない。** M0 で入れなかったのはこのためである。

## 3. 破産した親方の行き先

**[GDD02 §6.3](02-economy.md) の④「廃業して職業を変える」が、雇用市場を経由する形になる。**

```
M0(雇用なし): 破産世帯の職業を、担い手の最も薄い職業へ付け替える(世界側の処理)
v1.0(雇用あり): 破産した親方は職人として供給プールに戻り、別の親方に雇われる
```

**構造は同じで、経路だけが違う** — どちらも「破産は退場ではなく職業の変更である」を満たす。

> **雇用が入ると [GDD02 §6.3](02-economy.md) の付け替え規則(担い手世帯数の `argmin`)は不要になる。** 職業分布は雇用市場の需給で決まるようになり、**「最後の1世帯は付け替えない」という供給消滅の防止策も、親方の座が空いても別の職人が昇格することで自然に満たされる。**
>
> 史実ではギルドが親方昇格を統制していた(分冊07)。**誰が空いた親方の座に就けるかは、経済ではなく組織の問題である。**

## 4. 立地のコントラストは徒弟の移動で表す(**方向の決定**)

**都心と周辺で条件が違うこと自体はリアルであり、消したくない。** [GDD02 §4.3](02-economy.md) は世帯が区画を移らないと決めている(移住を許すと全世帯が中心に集まり、空間の摩擦が消える)。**世帯を動かさずに立地の差を表現する担い手が徒弟である。**

- 立地の良い工房は徒弟を集め、条件の悪い工房は徒弟を手放す。**動くのは世帯ではなく人手**
- 徒弟が増えれば労働力(§1)が増え、**生産量で立地の差が現れる**
- 機会費用の低い徒弟が居ることは、遠い店が候補に入ることでもある([GDD08 §7.2](08-household-and-decision.md))

> **M0 では初期配置で徒弟数を固定するので、立地の差は価格差としてのみ現れる**([GDD02 §12-4](02-economy.md))。

## 5. データモデル

**M0 の時点から `World` に雇用関係を持たせる**([GDD02 §7](02-economy.md))。
