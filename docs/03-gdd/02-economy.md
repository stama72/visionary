## 1. 設計方針

1. **経済は摩擦のためにある。** これが第一原理である。NPC が完璧に動く経済ではプレイヤーの価値がゼロになる。[idea/008](../idea/008-NPCと職業.md) §3.1 の「AI職人は工房から動かない」を**仕様として明文化する**(§4)
2. **観測可能性を最優先する。** The Guild 3 化(観測不能な複雑さ)の回避は企画段階からの制約である。プレイヤーが「なぜこの価格なのか」を追えなくなった時点で、経済の精巧さは価値を失う。**追えなくなる複雑さは、面白さの有無に関わらず入れない**
3. **閉じた経済にしない。** 都市の外を明示的にモデル化する([GDD02d](02d-external-market-and-money.md))。閉じた系は貨幣量が固定され、価格の絶対水準が動かせない
4. **NPC は満足化する。最適化しない。** 最適化する NPC はプレイヤーの介在余地を消し、かつ挙動が読めなくなる
5. **数値は初期値。** 構造と依存関係だけを固定する

## 2. 品目とレシピ

### 2.1 構成(**決定**)

**3層・最大2段。** 層と段を区別する:

- **層** = 品目の位置(1次産品 / 中間財 / 最終財)。**3層に固定する**
- **段** = 1次産品からの変換回数。**制約すべきはこちら**。段が深いほど価格の因果が追えなくなる(方針2)

品目数を増やしても段が浅ければ因果は追える。逆に段が深いと品目数が少なくても追えない。**したがって制約するのは段であり、段は2に抑える。**

> **段は「品目をどの層に置くか」で調整できる。** 木炭は当初 `木材→薪→木炭` の中間財としたため工具が3段になったが、**1次産品(炭焼き)に置き直すと工具は1段になる**(§2.2)。史実に沿わせた結果として制約も満たした例である。

**都市の賑わいは、品目ではなく職業で出す。** 生産以外の職業(サービス業・物流業・貿易商)を置くことで、レシピを増やさずに都市の味が出る。**M0 では採らない**(§9)。

### 2.2 品目表(**決定**)

**M0 は9品目。品目 Id は下表の順に 0〜8** — 品目に対する決定論の列挙順はこの採番による([ADR-0002](../adr/0002-time-model-and-determinism.md) の列挙順規約)。

| Id | 層 | 品目 | レシピ | 分類 | 供給 |
| -- | -- | ---- | ------ | ---- | ---- |
| 0 | 1次 | 穀物 | — | 生産の入力 | **都市外市場**([GDD02d §10](02d-external-market-and-money.md)) |
| 1 | 1次 | 木材 | — | 生産の入力 | **都市外市場** |
| 2 | 1次 | 鉄鉱石 | — | 生産の入力 | **都市外市場** |
| 3 | 1次 | 木炭 | — | 生産の入力(金属加工専用) | **都市外市場** |
| 4 | 中間 | 小麦粉 | 穀物 → | 生産の入力 | 水車小屋番 |
| 5 | 中間 | 薪 | 木材 → | **必需**(家庭の暖房)+ 生産の入力(パン・ビール) | 木材加工 |
| 6 | 最終 | パン | 小麦粉 + 薪 → | **必需** | パン屋 |
| 7 | 最終 | ビール | 穀物 + 薪 → | **嗜好** | 醸造 |
| 8 | 最終 | 工具 | 鉄鉱石 + 木炭 → | **耐久**(摩耗する、[GDD02a §5.3](02a-production.md)) | 鍛冶 |

**この9品目が、[GDD02c §8.2.1](02c-price-and-budget.md) の予算の母数の段階と利潤上限をすべて実行する** — 利潤上限(生産の入力: 1次〜中間)、流動資金(必需: パン・薪)、流動資金 − 必需の取り置き(耐久: 工具)、余剰資金(嗜好: ビール)。**どれか1つでも対応する品目を落とすと、その段階が W2 で一度も実行されない。**

> **削ってよい下限は「母数の段階すべてと利潤上限が実行されること」である。** **5品目まで削ると上のうち少なくとも1つが実行されない** — 最も残せる選び方(鉄鉱石・木炭・工具・木材・薪)でも嗜好の上限が落ち、パン系列を残す選び方なら嗜好と耐久の2つが落ちる。**[企画書 §6](../02-project-proposal.md) の M1 は当初「品目5種」だったが、[ADR-0007](../adr/0007-m1-scale-follows-economic-model.md) で9種へ改訂した** — 5という数は本書の予算の構造が決まる前に置かれた見積もりだった。**[ADR-0006](../adr/0006-issue-driven-task-management.md) が問題にした M0 > M1 の順序反転は、品目数・NPC 数とも等号で解消している。**

**燃料は2系統ある。用途が分かれ、故障モードも分かれる。**

| 燃料 | 用途 | 供給 | 止まる条件 |
| ---- | ---- | ---- | ---------- |
| **薪** | 家庭の暖房、食品加工(パン・ビール) | **都市内**(木材加工が木材から作る) | 木材の価格が跳ねる / 木材加工が止まる |
| **木炭** | **金属加工のみ**(工具) | **都市外**(炭焼き) | 都市外市場の価格が跳ねる(= 季節性、[GDD02d §9](02d-external-market-and-money.md)) |

**故障モードが違うことに価値がある。** 単一の隘路より、2つの独立した供給不安があるほうが、プレイヤーの介入機会が多様になる。冬の暖房需要([GDD02d §9](02d-external-market-and-money.md))は薪だけを圧迫し、木炭には効かない。

#### 木炭は1次産品である(**決定**)

**中世の炭焼きは森の奥深くで原木を蒸し焼きにする作業であり、都市内の工房で行うものではない。** したがって木炭は、木材や鉄鉱石と同じく**都市の外から持ち込まれる1次産品**として扱う。

**この置き方が3つの問題を同時に解く**:

1. **史実性。** 製鉄・鍛造には木炭が要る。薪では温度が足りず不純物も多い。「炭が切れた鍛冶屋」は [idea/008](../idea/008-NPCと職業.md) §3.1 が挙げた場面そのものである
2. **段数。** 中間財(`木材→薪→木炭`)に置くと工具が3段になるが、**1次産品に置けば `鉄鉱石 + 木炭 → 工具` は1段**である。§2.1 の制約を満たす
3. **対称性。** 金属加工は `鉄鉱石 + 木炭` で揃う

> **旧版では木炭を廃し、金属加工の燃料を薪に統一していた。** 廃した理由は「段が3になる」「燃料が2種で対称性が崩れる」だったが、**どちらも木炭を中間財に置いたことの帰結**であり、1次産品に置き直すと両方とも消える。**却下理由の前提が、置き場所を変えたことで崩れた**([process/03](../process/03-corrections.md) 規則6)。

### 2.3 レシピの形

```
レシピ = { 出力[(品目, 数量)], 入力[(品目, 数量)], 所要労働 }
```

- **出力は複数を許す**(M0 の5レシピはいずれも単一出力だが、構造としては許す)
- **1レシピ1段**。中間財を経ずに原料から最終財を作る近道は置かない
- 数量はすべて int。歩留まり・端数は**切り上げ**([GDD01 §2.3](01-trust-and-conversation.md) の全体規約)
- **入力を持たないレシピを許す。M0 には該当する職業が無い**(1次産品はすべて都市外市場から来る)が、構造としては残す — [GDD02c §8.1.1](02c-price-and-budget.md) の原価の分岐がこれに対応し、[GDD11](11-external-trade.md) の貿易商と [GDD12](12-countryside-and-fairs.md) の農村職業が戻ったときに発火する

### 2.4 規模 — 職業・世帯・NPC(**決定**)

**都市5職業 × 2世帯 = 10世帯、1世帯2人、NPC 20体。** 9区画に1〜2世帯で収まる。

| Id | 職業 | レシピ |
| -- | ---- | ------ |
| 0 | 水車小屋番 | 穀物 → 小麦粉 |
| 1 | パン屋 | 小麦粉 + 薪 → パン |
| 2 | 醸造 | 穀物 + 薪 → ビール |
| 3 | 木材加工 | 木材 → 薪 |
| 4 | 鍛冶 | 鉄鉱石 + 木炭 → 工具 |

**職業 Id は上の表の順に 0〜4。** [GDD02b §6.3](02b-consumption-and-household.md) と [GDD08 §9](08-household-and-decision.md) の「同値なら職業 Id 昇順」はこの採番による。

**規模を決めているのは「1品目につき売り手2世帯を別区画に置けること」である。** `Market` は「品目 × 売り手 → 提示価格」なので、**売り手が1人なら市中価格が1つしか存在せず、§8-4「区画間の価格差が消えない」が消えるのではなく最初から存在しない**。[GDD06 §3](06-trade-and-negotiation.md) の店の選択も比較対象を持たない。

**同じ職業の2世帯は必ず別の区画に置く。これは値ではなく構造の制約である。** §4.3 の密度(1区画1〜2世帯)だけでは同居を防げず、同居すると当該品目の売り手が1区画に集まって区画差が消える。

**§4.3 の密度(1区画1〜2世帯・空区画を作らない)は、情報の摩擦の側にも効いている。** 10世帯を9区画に上限2・下限1で置くと配置は「8区画に1世帯・1区画に2世帯」しかあり得ず、**中心に隣接する4区画(Id 1/3/5/7)は必ず埋まる**。隅の区画(Id 0/2/6/8)はいずれもそのうち2つと隣接するので、**隅の世帯にも「買いに行く先」が必ず存在する** — これが §4.2 の観測の広がりの前提である。

> **これでも「必ず観測する」にはならない。** 隣接区画に売り手が居ても、その売り手が扱う品目をその世帯が買わない日は移動が起きない。**構造が排除できるのは「行く先が無い」配置までであり、残りは §8-7 が測る。**

**初期配置はマスターシードから振る。** 上の構造制約(同職業は別区画・密度)を満たす配置は一意ではなく、どの世帯がどの区画に入り、どの世帯がどの職業に就くかは `RandomStream.WorldGen` から決まる。**同一シードなら同一配置、違うシードなら違う配置になる。** [TDD01 §4.1](../04-tdd/01-sim-core-and-m0.md) の「条件あたり10反復」はこれにより実際に10通りの地理を見ることになり、§8-4(区画間の価格差が消えない)が特定の1つの配置の産物ではなくなる。ADR-0002 の共通乱数法により、A/B の2条件は同一シードなら同一配置で揃う。

#### 世帯構成と NPC 数(**決定**)

**世帯構成は親方1・徒弟1の2人を初期値とする。** [GDD08 §2.1](08-household-and-decision.md) が世帯に含めうる役割(親方・主婦・子ども・徒弟)を定めているが、**M0 で何人置くかは本書が初期値として持つ**(構造は GDD08、値は本書という分け方は [GDD02d §9](02d-external-market-and-money.md) 季節係数と同じ)。

| | 世帯数 | NPC数(2人 × 世帯数) |
| -- | -- | -- |
| 都市 | 10 | **20** |

**親方と徒弟の2人に絞るのは、M0 が労働力について見たいのが「階層で係数が違うこと」だけだからである**([GDD02a §5.2](02a-production.md))。主婦は家事の外部化([GDD08 §3.2](08-household-and-decision.md))と、子どもは世代交代(§7)と対になって意味を持つ役割であり、どちらも M0 のスコープ外である。**職人は自分の家計を持つ別世帯であり**([GDD08 §2.1](08-household-and-decision.md))、雇用([GDD10](10-employment.md))とともに M0 の外に出る。

> **人数は調整対象である。** ただし「世帯が複数の階層を含む」という構造は GDD08 §2.1 の決定であり、動かさない。世帯内で流動資金を共有すること([GDD02b §6.2](02b-consumption-and-household.md))と、買い物に行く者の機会費用が階層で違うこと([GDD06 §2](06-trade-and-negotiation.md))は、2人でも成立する。

## 3. 職業

### 3.1 職業一覧の正は本書が持つ

[idea/008](../idea/008-NPCと職業.md) は**原典のアイデアメモ**であって仕様ではない。**M0 の職業一覧の正は本書 §2.4 が持ち、拡張で加わる職業は各分冊が持つ**(貿易商・運送労働者は [GDD11](11-external-trade.md)、農村職業は [GDD12](12-countryside-and-fairs.md)、サービス業・質屋・武器職人などは §9)。**どの分冊にも属さない職業は置かない。**

**理由**: 職業 = レシピ + 家計 + 労働力であり、3つとも本書の §2・[GDD02a §5](02a-production.md)・[GDD02b §6](02b-consumption-and-household.md) が持つ。レシピを持たない職業(商業・サービス・物流)も、**経済における役割**として定義される以上ここに属する。

**境界**:

| 何を | どこが持つか |
| ---- | ------------ |
| 職業の一覧・役割・レシピ | **本書 §2.4** |
| 個体の1日の行動(いつ買いに行くか) | **本書 §4**(時間の摩擦の仕様) |
| 親方 / 職人 / 徒弟の**雇用関係** | [GDD10](10-employment.md)。**M0 では雇用を実装しない** |
| 貿易商 | [GDD11](11-external-trade.md) |
| 農村の職業 | [GDD12](12-countryside-and-fairs.md) |
| ギルド・教会・領主という**組織** | 分冊07。**職業とは別の軸**である(鍛冶職人はギルドの一員だが、ギルドは職業ではない) |
| プレイヤーの店と従業員 | 分冊04 |

### 3.2 粒度(**決定**)

**経済的な役割が異なるものだけを分ける。** [idea/008](../idea/008-NPCと職業.md) はより細かい区分を挙げている(海上貿易商とスパイス貿易商の分離、金銀細工師、道化師など)が、経済的役割が重複するものは統合する。

**職業の追加は品目の追加より安い。** レシピを持たない職業(サービス・物流・商業)は品目数も段数も増やさないため、方針2の観測可能性を損なわない。**粒度を上げる拡張は、M0 後の「賑わいが足りない」という所感に応じて足す**(§9)。

## 4. 摩擦 — プレイヤーの価値の源泉

**本書で最も重要な節。** [idea/008](../idea/008-NPCと職業.md) §3.1 を仕様化する。

| 摩擦 | NPC の制約 | プレイヤーの機会 | 実装上の要点 |
| ---- | ---------- | ---------------- | ------------ |
| **空間** | 職人は工房のある区画から動かない。生産物は自分の区画にしか並ばない | 区画をまたぐ運搬でサヤを抜く | **都市を 3×3 の9区画に分け**、価格差の単位にする(§4.3)。**区画ごとに価格が違う** |
| **時間** | 経済は日次で回り、買い出しは生産のあとにしか起きない。入力が切れても即座には補充しない。**外出は時間を奪い、翌日の生産を減らす** | 「今すぐ要る」に応えて割増で売る | 生産システムは入力不足で**減速・停止する**。停止は Need を生む |
| **情報** | NPC は自分が観測した価格しか知らない([GDD01 §4.1](01-trust-and-conversation.md)) | 相場を知っていること自体が資本 | 既に GDD01 が設計済み。**02 はそれを経済的に意味あるものにする側** |

### 4.1 摩擦を消してはならない

**この3つを効率化する施策は、すべて本作の価値を削る。** 具体的には以下を作らない:

- NPC 同士の自動的な物流(木材加工へ木材が自動で届く)
- **全 NPC が共有する市場価格表(中央の板)。M0 には例外を1つも置かない。** 都市外市場([GDD02d §10](02d-external-market-and-money.md))も中心区画に並ぶ1つの売り手として扱い、視界半径([GDD06 §3.1](06-trade-and-negotiation.md))の外からは見えない
- 入力切れを即座に解消する自動発注

**逆に言えば、経済の「効率が悪い」ことは不具合ではなく仕様である。** レビューや調整でここを「改善」しないよう、本節を根拠として参照すること。

> **例外を1つも置かないことが、M0 でのこの節の強さである。** 例外は「一貫性のために」他へ広げたくなる圧力を常に持つ。[GDD11](11-external-trade.md)(定期市の周知)や [GDD12](12-countryside-and-fairs.md)(季節市)が例外を必要とするなら、**それは各分冊が自分の理由で正当化する。**

### 4.2 ただし、詰みは作らない

摩擦が強すぎて都市が餓死しては困る。**M0 の下限は都市外市場([GDD02d §10](02d-external-market-and-money.md))が担う。** 中心区画には1次産品が常に並び、都市生産品の余剰は常に引き取られる。**プレイヤーが何もしなくても都市は回るが、遅く・高く回る** — 窓口は中心にしか無いので移動費が乗り、しかも売値と買値の開きが大きい([GDD02d §10.2](02d-external-market-and-money.md))。プレイヤーはその差分を取る。

**下限を担うもう一方は [GDD06 §3.1](06-trade-and-negotiation.md) の観測の広がりである。** 「その日に居た区画から距離 R 以内」で観測が生まれるので、**買い物に行くこと自体が知識を外へ広げる**。店の所在は公開なので、価格を知らない品目があれば世帯は床の見積もりで外出し([GDD06 §3](06-trade-and-negotiation.md))、着いた先の価格を翌日から知る。隅の区画(Id 0/2/6/8)の世帯も、中心の窓口へ1次産品を買いに行く日に中心を観測する。Need(遠方在庫)は立つが、**M0 では履行する主体を置かない**([GDD11](11-external-trade.md) の行商人・運送労働者は M0 の外)。

> **観測の広がりは「必ず届く」保証ではない。** 外出は余剰が費用を上回るときにしか起きない([GDD06 §3](06-trade-and-negotiation.md))。需要が小さく遠い世帯では、床の見積もりによる余剰が外出の費用に届かない日が続き、**価格を知らない品目を抱えたまま回り続ける**ことがありうる。所在を知っていても価格は知らないので、見積もりが外れ続ける可能性は残る。
>
> **構造が保証するのは「買いに行く先が必ず存在し、行く理由が必ず立つ」ことまでである**(所在の公開と床の見積もり)。**残りは §8-7 が測る失敗モードである** — 需要のある品目について価格を知っている店が0件の世帯の割合が高止まりするなら、外出の費用に対して余剰が小さすぎる。

### 4.3 区画と距離(**決定**)

**9区画を 3×3 のグリッドとして扱い、区画間の距離はマンハッタン距離とする。**

```
距離(a, b) = |行(a) − 行(b)| + |列(a) − 列(b)|      ← 0〜4
移動時間   = 距離 × 1区画あたりの移動時間(初期値 1時間) × 2   ← 往復
```

- **区画 Id は行優先で 0〜8。** Id から行・列が定まるので、距離表というデータを持たない
- 距離は**視界半径 R** にも使う([GDD06 §3.1](06-trade-and-negotiation.md))。**起点は「その日に居た区画」であって自宅とは限らない**。**R は値ではなく構造であり、実データを見て調整する軸ではない**
- 距離は外出の費用と労働損失に乗る([GDD06 §2](06-trade-and-negotiation.md))。**世帯は外出で得る余剰が費用を上回るときだけ出て、移動した時間は翌日の労働力から引く。これが空間の摩擦の数値表現である**
- 買い手の区画は世帯の区画、店の区画は売り手の工房の区画。**都市外市場の区画は中心(Id 4)に固定する**([GDD02d §10](02d-external-market-and-money.md))

> **隣接グラフや 9×9 の距離行列を持たないのは、調整軸を増やさないためである**(方針2)。距離行列なら36個の軸が増え、**区画間の価格差が「機構の帰結」か「距離表の設定」かを切り分けられなくなる** — §8-4 がまさにその価格差を判定に使う以上、これは致命的である。
>
> 城壁・川・門といった不整形をグリッドで表せないのは承知の上である。**M0 の目的は価格機構の検証であって都市の地理ではない。** 複数都市(§9)へ進むときに再訪する。

#### 世帯は区画を移らない(**決定**)

**世帯の区画は初期配置で決まり、以後変わらない。**

- **世帯密度は 1区画あたり1〜2世帯。** 同じ職業が1区画に詰まって競合することがなく、かつ空区画も出ない薄さである
- 世帯の区画Id は不変。`Household` の定数であって状態ではない

> **移住を許すとホテリングの法則で全世帯が中心区画に集まる。** 中心は全区画への距離が最小なので外出の費用と労働損失([GDD06 §2](06-trade-and-negotiation.md))で有利になり、周辺に留まる動機が無い。**都市外市場が中心にあること([GDD02d §10](02d-external-market-and-money.md))がこの圧力をさらに強める。** 集まった瞬間に §4 の空間の摩擦が消滅し、§8-4「区画間の価格差が消えない」が構造的に不通過になる。
>
> **決定論の側でも効く。** 区画Id が不変なら「どの世帯がどこに居るか」は状態ではなくなり、移動判定の順序やタイミングが状態ハッシュ([TDD01 §3.8](../04-tdd/01-sim-core-and-m0.md))に乗らない。§8-4 は**価格機構の帰結だけ**を見ることになる。

> **立地のコントラストは、v1.0 では徒弟の移動で表す** — 立地の良い工房は徒弟を集め、条件の悪い工房は徒弟を手放す。**動くのは世帯ではなく人手**である。これは雇用の一部なので [GDD10](10-employment.md) が持つ。**M0 では初期配置で徒弟数を固定し、立地の差は価格差としてのみ現れる。**

## 5. 現金と利潤 — 2つの尺度(**決定**)

**帳簿が記録するのは現金の動きであり、生産の判断が見るのは利潤である。この2つを混ぜない。** 現金は「続けられるか」を、利潤は「続ける価値があるか」を答える。答える問いが違うので、片方でもう片方を代用すると、どちらかの問いに誤った答えを返す。

| | **現金**(キャッシュフロー) | **利潤** |
| -- | -------------------------- | -------- |
| 何を測るか | 貨幣の移動。世帯の流動資金の増減 | 生産活動が費用を上回る価値を生んだか |
| 日次の式 | `流動資金 += 販売収入 − 仕入支出 − 生活費 − 耐久財の購入` | `利潤 = 売上 − 売上原価`。売上原価は投入財の移動平均単価に**摩耗**を足したもの |
| 都市全体で | `Σ増減 = 輸出 − 輸入`。**世帯間の売買は移転であり、貨幣量を変えない** | Σ が正でも貨幣は増えない。**利潤は移転であって貨幣量の増加ではない** |
| 何を駆動するか | 破産中フラグ、必需の取り置きと運転資金と余剰資金、予算の現金上限(用途ごとの母数 ÷ 1日分)、輸出入の収支 | 提示価格の原価、生産の入力の仕入上限(最低利幅)、生産の継続判断、価格に応じた生産調整(将来) |
| どこが持つか | [02b](02b-consumption-and-household.md) 家計、[02d](02d-external-market-and-money.md) 貨幣 | [02a](02a-production.md) 原価、[02c](02c-price-and-budget.md) 仕入上限 |

**3つの帰結**:

1. **「儲かっている世帯が多い」はインフレの兆候ではない。** 都市の貨幣量を動かすのは輸出入だけである(02d)。利潤の合計が正であることは、貨幣が都市内で偏って移転していることを意味するに過ぎない。**貨幣量の判定は Σ流動資金の推移で行い、利潤の合計では行わない**(§8-6)
2. **既に持っている在庫は、売値が原価を下回っても売る。** 取得原価は埋没費用であり、売る時点の判断には入らない。**提示価格の床は原価ではなく外部買値である**(02c) — 窓口に持ち込める値より安く並べる理由が無いという機会費用の床であって、原価の床ではない。原価が効くのは**これから作るか**の判断、すなわち入力の仕入上限(02c)である
3. **摩耗は利潤側の費用である。** 現金側には工具を買った日にだけ現れるが、利潤側では実行ごとに、投入した労働量に比例した摩耗費が立つ(02a)。**原価にこれを含めないと、工具代を回収できない値付けが「利益が出ている」と判定される**

> **現金で生産を判断すると、黒字倒産と逆の誤りが起きる。** 資金が潤沢な工房は赤字の生産を続け、資金が細った工房は黒字の生産を止める。**利潤で生存を判断すると、黒字倒産が起きる** — 明日の仕入に要る金を遊興に回す(02b 運転資金)。**2つの尺度を分けて、それぞれの問いに当てる。**
>
> **M0 で式として持つ利潤の使い道は、提示価格の原価と仕入上限の2つだけである。** 生産量そのものを利潤で動かす(雇用の増減、生産財への資本投下、家事や輸送の外部化)のは生産関数の分冊([issue #92](https://github.com/stama72/visionary/issues/92))が持ち、M0 では `生産量 = 生産能力` である(02a)。

## 6. 雇用 → [GDD10](10-employment.md)

**M0 では雇用を実装しない。** 親方 / 職人 / 徒弟の3階層、給金、雇用の増減、解雇された職人の行き先は [GDD10](10-employment.md) が持つ。

**M0 で固定されるのは労働力である** — 雇用の増減が無いので世帯の構成員と階層が変わらず、労働力合計‰ が 1300 で動かない([GDD02a §5.2](02a-production.md))。M0 で見たいのは価格機構であり、雇用は変数を増やすだけである。

> **設備は固定しない。** 工具は摩耗し([GDD02a §5.3](02a-production.md))、設備係数が動くので生産量も動く。**工具は M0 で唯一の耐久財**であり、耐久の予算([GDD02c §8.2.1](02c-price-and-budget.md) の `min`)と「工具切れ」の Need([GDD02b §8.4](02b-consumption-and-household.md))を検証する唯一の経路なので、ここを固定すると M0 の検証項目が1本落ちる。

**ただしデータモデルには雇用関係を最初から持たせる。** 後付けは `World` の区分追加になり、決定論ハッシュの更新([TDD01 §3.8](../04-tdd/01-sim-core-and-m0.md))が要るため。

## 7. NPC の一生(**決定**)

**M0 では NPC を不死とし、世代交代を実装しない。**

**根拠となる整理**: [GDD01 §6](01-trust-and-conversation.md) 検証項目2 の 36,000日は、**300年の物語ではなく価格機構の耐久試験である。** 混同すると人口動態が M0 のスコープに引きずり込まれる。耐久試験に人口動態は要らない。

**検証地平は 36,000日のまま据え置く**([TDD01 §5.4](../04-tdd/01-sim-core-and-m0.md) の判定基準を変更しない)。

> **短縮は残された調整弁である。** 発散・硬直が起きるなら数十年で兆候が出るはずなので、原理的には 3,600日(30年)でも検証は成立する。**W2 の調整サイクルが実測で遅すぎた場合に限り、短縮を再検討する。** 先回りして基準を緩めない。

**世代交代を入れるなら以下が連動する**(M0 では触らない): 信用([GDD01 §2.1](01-trust-and-conversation.md))は死亡でリセットされる / 相続で資産と工房が引き継がれ、徒弟→職人→親方の昇格([GDD10](10-employment.md))が生きる / 決定論ハッシュ([TDD01 §3.8](../04-tdd/01-sim-core-and-m0.md))の区画が増える。

## 8. M0 での検証項目

[GDD01 §6](01-trust-and-conversation.md) と重複しない、**経済側の**検証項目。

| # | 検証内容 | 判定基準 |
| - | -------- | -------- |
| 1 | 価格が安定するか | 信用なし条件で長期実行する。**判定対象は都市生産5品目である** — 1次産品の提示価格は外部売値そのもの([GDD02d](02d-external-market-and-money.md)。都市内に売り手が居ない)なので、外れようがない。**(a) 5品目の約定価格に [TDD01 §5.2](../04-tdd/01-sim-core-and-m0.md) の発散・硬直の判定関数を適用する**(閾値の定量化はそちらが持つ)。**硬直の判定は、提示価格が床(外部買値)に一致し、かつその日に輸出が発火した売り手日を除く** — 余剰の錨は硬直ではない([GDD02d §4.5](02d-external-market-and-money.md))。**床に居るが輸出していない売り手日は除かない** — 相場基準を持たず床に固定された売り手([GDD02c §1.2](02c-price-and-budget.md))がそこに落ちる。あわせて**「相場基準を持たない売り手日の割合」を日次メトリクスに持つ**([issue #41](https://github.com/stama72/visionary/issues/41))。**(b) あわせて、02d の成立条件 `輸入含有原価 < 外部買値` が実行時に保たれているかを見る** — 破れれば輸出が一度も発火せず、貨幣が流出し続ける(#6 に出る)。**上限側の条件は置かない。** 貨幣の流入が過剰かどうかは #6 が有界性で見る |
| 2 | 貨幣が枯渇しないか | 困窮状態の**世帯**が全体の一定割合を超えない。**困窮は破産中フラグ([GDD02b](02b-consumption-and-household.md))が立っている状態を指す** |
| 3 | 生産チェーンが止まらないか | 各レシピの生産停止([GDD02a](02a-production.md))が常態化しない。**一時的な停止は仕様**(§4)。**醸造が成立するか**(必要運転資金の控除が嗜好需要を細らせないか。余剰資金の規則は [GDD02b](02b-consumption-and-household.md))をここで見る |
| 4 | **摩擦が残っているか** | **工具を除く都市生産4品目(小麦粉・薪・パン・ビール)について、区画別の約定価格(中央値)の差が長期的に 0 へ収束しない。** 差を作る機構は、外出の余剰が費用に届かない買い手が地元の高い店で買うこと([GDD06 §3](06-trade-and-negotiation.md))と、遠い世帯の労働損失が生産を減らすこと([GDD02a §2](02a-production.md))である。**旧版のように距離が単価に直接乗るのではないので、差は薄くてよい。0 でなければ摩擦は働いている。** 0 に収束するなら、全売り手が余剰を持って床に張り付いているか、相場基準を持たずに床に固定されている([GDD02d §4.5](02d-external-market-and-money.md)、[GDD02c §1.2](02c-price-and-budget.md))。後者は倍率では直らないので、**先に「相場基準を持たない売り手日の割合」で切り分ける。** 前者の一次対処は需要の区画間の偏り(初期配置・区画ごとの世帯数)と校正 (a) の倍率の両方であり、どちらが効くかは実測で決まる。 工具を除くのは、鍛冶 2 世帯 × 1 個/日 に対して需要 1 個/日で床に張り付くと先に分かっているためである。閾値は [TDD01 §5.2](../04-tdd/01-sim-core-and-m0.md) が持つ。**1次産品は都市外市場が中心区画でのみ売るので対象外**([GDD02d](02d-external-market-and-money.md)) |
| 5 | 床が効いているか | **外部買値を下回る提示価格が継続しない**([GDD02c](02c-price-and-budget.md) の床)。原価を下回ることは §5 の帰結2のとおり正常であり、判定しない |
| 6 | **自動調節が働くか** | **貨幣総量(= Σ世帯の流動資金)が有界に留まる。** 長期的に減少し続けない(輸出が発火していない、または #1(b) が破れている)し、増加し続けない(02d の校正が外れ、余剰が毎日そのまま換金されている)。**季節による年内の振れは正常**(薪の消費が季節で動く、[GDD02d](02d-external-market-and-money.md)) |
| 7 | **知識が広がるか** | **需要のある品目について「価格を知っている店が0件」の世帯の割合が、初期の過渡期を過ぎて高止まりしない**([GDD06 §3.1](06-trade-and-negotiation.md))。店の所在は公開なので「知っている店が0件」は構造的に起きず、測るのは価格の側である。M0 は行商人も運送労働者も置かないので、**観測の広がりが摩擦の下限の一方を担う**(§4.2) |

**#4 が本書固有の判定である。** 価格が安定していても区画差が消えていたら、それは「プレイヤーのいらない経済」であり、**経済として成功でもゲームとして失敗**である。**ただし #4 は「摩擦が実装されているか」ではなく「摩擦が価格に現れるほど強いか」を測る。** 実装が正しくても、全売り手が余剰を持てば価格は床に釘付けされ、差は消える。落ちたときに直すのは機構ではなく、需要の偏りと校正の倍率である。**#1 と #4 が対で倍率の帯を挟めるかどうかは、挟める帯が存在するかを含めて実測待ちである。**

**#6 は 02d の機構が机上の理屈で終わっていないかを見る。** 自動調節を設計に組み込んだ以上、それが実際に働くことを確かめないと、外部価格が調整不能な地雷になる。**M0 で貨幣から需要へ通じる経路は、予算の現金上限(用途に使える資金 ÷ 1日分。02c)だけである** — 上限はゲートとして効くので、貨幣が減ると母数の小さい用途から買い手が脱落する形で需要が落ちる。経路が細いので、#6 の成否は 02d の校正にも大きく依存する。**校正で通したのか機構で通したのかを、判定と併せて記録する。**

### 9.1 M0 の外に置いた品目と職業(**参考**)

**下の表は仕様ではなく、M0 の外に置いたものの記録である。** どの分冊にも属さない品目・職業をここに残しておかないと、**外した理由(段数・対称性・史実性)ごと失われる。**

| 層 | 品目 | レシピ | 担い手 | 外した理由 |
| -- | ---- | ------ | ------ | ---------- |
| 1次 | 羊毛 | — | 羊飼い([GDD12](12-countryside-and-fairs.md)) | 衣服の系列ごと |
| 1次 | 肉 / 皮 | 肉屋 → 肉 + 皮 | 肉屋 | **都市内で産する唯一の1次品。** 家畜を品目にすると段が増えるので、レシピを持たず2品目を産出する形に抽象化してある |
| 中間 | 毛糸 | 羊毛 → | 紡ぎ手 | 衣服の系列ごと |
| 中間 | なめし皮 | 皮 → | 皮職人 | 靴の系列ごと |
| 最終 | 衣服 | 毛糸 → | 仕立て屋 | **全 NPC 共通の耐久財。** M0 では耐久が工具しか無い(下記) |
| 最終 | 靴 | なめし皮 → | 靴職人 | 同上 |
| 最終 | 武器 / 甲冑 | 鉄鉱石 + 木炭 → | 武器職人 | **需要源が領主(衛兵)だけ**なので、[GDD09](09-treasury-and-tax.md) の財政と同時にしか入らない |

**レシピを持たない職業**: 酒場の主人(パン+ビール+肉 → 即時消費)/ 宿屋(薪+パン+ビール → 即時消費)/ 質屋・両替商。**サービス業は「最終財を買って在庫にしない」ことに意味がある** — 都市内に最終財の需要の受け皿ができ、生産が家計消費だけに依存しなくなる。**品目としては持たない**ので品目数も段数も増えない。ただし [GDD08 §3.2](08-household-and-decision.md) の家事の外部化が需要源なので、**主婦を置かない M0 では買い手が存在しない。**

**M0 の中で採らなかった拡張**(品目・調整軸が増えるため):

- 上の品目を戻す。**靴と衣服は「全 NPC 共通の耐久財」という役割を持つ** — M0 では耐久の予算(`min`)が生産職の工具でしか検証されず、「徒弟も靴を買える」([GDD02c §8.2.1](02c-price-and-budget.md))が確かめられない
- 耐久財を工具以外へ広げる(農具・ツルハシ・厨房設備)。**現在工具のみに絞っているのはスコープ膨張の回避であって、リアリティ上の判断ではない**
- **1回の移動で運べる数量の上限。** [GDD11 §5.1](11-external-trade.md) が持つ。**運送労働者とプレイヤーの荷運びに優位性を与える前提**であり、運び手と同時にしか入れられない。**採るときは [GDD02d §10.2](02d-external-market-and-money.md) の輸出規則を運搬として書き直す必要がある**(現行は移動も費用も持たない)
- 職業の粒度を [idea/008](../idea/008-NPCと職業.md) に近づける。**レシピを持たない職業は段数を増やさないので安い**
- 腐敗。パンと肉は本来腐る。M0 では [GDD02b §8.2.2](02b-consumption-and-household.md) の在庫上限倍率で代用している
- 設備係数の連続化([GDD02a §5.3](02a-production.md))。あわせて [GDD02a §5.2](02a-production.md) の `ApplyPermille` を切り下げへ直す
- 複数都市。[GDD02d §10.3](02d-external-market-and-money.md) の分業の利益は、都市ごとの性格づけに繋がる
