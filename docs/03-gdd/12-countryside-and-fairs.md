## 1. 農村の職業

**都市の外に住み、季節に一度だけ都市に来る**(§3)。

| 職業 | 産出 |
| ---- | ---- |
| 農民 | 穀物 |
| きこり | 木材 |
| 炭焼き | 木炭 |
| 鉱夫 | 鉄鉱石 |
| 羊飼い | 羊毛 |

**1次産品は都市で生産されない。** 都市は加工と商業に特化する。これは史実的にも正確であり、**原料在庫が季節で大きく振れる**という設計([idea/008](../idea/008-NPCと職業.md) §1.5)を成立させる。

**農村職業はレシピに入力を持たない。** したがって [GDD02c §1](02c-price-and-budget.md) の**「財の投入が無い職業の原価 = 機会費用 × 所要労働」**を実行する主要な経路になる。**農村世帯を世帯として持つ理由の一つがこれである** — 世帯をやめて抽象化すると、売り手側の値付け規則がもう1本必要になる。

**農村世帯は都市の区画に住まない。** 都市の外に住み、来訪中だけ中心区画(Id 4)を距離の起点として扱う。

- **区画Id は「農村」を表す専用の値で固定する。** [TDD01 §3.2](../04-tdd/01-sim-core-and-m0.md) の「区画Id は不変」は揺らがない
- **来訪しているかどうかは暦から決まる**ので状態ではない
- **[GDD02 §4.3](02-economy.md) の世帯密度(1区画1〜2世帯)は都市世帯にだけ適用する**

## 2. 季節市

### 2.1 開催期間と開催日

```
農村職業 j の季節市 = 季節の初日 + 開催日オフセット[j] から 開催日数(初期値3日)

値域(構造の制約): 0 ≤ 開催日オフセット ≤ 季節日数 − 開催日数 (= 30 − 3 = 27)
```

**値域は値ではなく構造の制約である。** 市が季節境界をまたぐと、季節次の納税([GDD09 §1.2](09-treasury-and-tax.md))と財政の季節口座([GDD09 §2.3](09-treasury-and-tax.md) の「残り日数」)の区切りと噛み合わなくなる。

**3日間あれば、来訪初日に売れなくても翌日以降に売り直せる。** 1日だけの開催だと、農村世帯が同日中に来訪・換金・納税・購入まで済ませられるかが移動時間([GDD02 §4.3](02-economy.md))との兼ね合いで詰まりうる。

> **オフセットを構造として持たせるのは、市をずらすかどうかが実験でしか決まらないためである。** 農村の各職業は1品目を売るので、**職業ごとのオフセットはそのまま品目ごとの開催日になる**。初期値を全 0 にしておけば挙動は同時開催のままであり、**値を変えるだけで比較実験ができる。**
>
> **ずらす動機は2つある。** ゲーム側では、市というイベントが季節に1回まとめて来るより数日おきに来るほうが、プレイヤーの関与点が増える。シミュレーション側では、**各職業の仕入支出の波と農村世帯からの需要が分散する** — 同時開催では、全1次産品の供給と農村世帯の購買力が年4回の同じ3日間に集中する。
>
> **オフセットを 0 以外にすると納税の時点を決め直す必要がある**([GDD09 §1.2](09-treasury-and-tax.md))。来訪日と納税日が最大27日ずれ、比例課税の課税ベースが「換金後の現金」から「換金前のほぼ空の財布」に変わる。

### 2.2 季節市は視界半径の明示的な例外である

**1次産品の売り注文だけは、開催中に限り距離によらず全世帯の「今日の知覚」に含まれる**([GDD06 §3.1](06-trade-and-negotiation.md))。

- **これは記憶ではなく知覚の例外であり、当日から買える。** そうでなければ「木材加工が搬入日に木材を仕入れられる」が成立しない
- 同時に見た売り注文は通常どおり観測(`PriceObservation`)としても記録されるので、市が閉じたあとは保持期間の範囲で記憶として残る
- 1次産品の `相場基準`([GDD02c §1](02c-price-and-budget.md))は観測から作る(売り手ごとに最新1件の平均)ので、**ここを取り違えると値付けが変わる**

> **例外を置かないと、生産チェーンの根が初期配置の運で切れる。** 1次産品は中心区画で季節に一度しか並ばない。視界 R = 1 では隅の4区画(Id 0/2/6/8)から中心は距離2で見えず、**その日にたまたま近所へ買い物に行った世帯しか観測できない**。木材加工が隅に置かれれば木材を知る経路が無く、**薪が止まり、パンとビールが同時に止まる。**
>
> **定期市は公的に周知される行事であり、これがこの例外の設定的根拠である。** [GDD02 §4.1](02-economy.md) は M0 で例外を1つも置かないと宣言しているので、**本書が例外を必要とすることは、本書が自分の理由で正当化する。**
>
> **普段の店の情報の摩擦は R = 1 のまま保たれる。** 例外は1次産品の売り注文だけであり、都市生産品と貿易品は従来どおり足で稼ぐ。

**保持期間の構造制約**: [GDD06 §3.1](06-trade-and-negotiation.md) の観測の保持期間は**来訪間隔(1季 = 30日)より長く**しなければならない。短いと**次の季節市が開く前に `相場基準` が消えて**値付けが原価下限に落ちる。**オフセットを入れても各品目の来訪間隔は1季のままなので、この制約は変わらない。**

## 3. 来訪サイクルと農村世帯の消費

**農村 NPC の1回の来訪サイクル**(3日間で1日ごとに順に行う。1日で3工程すべてを終える必要はない):

1. 生産物を都市に持ち込み、**都市内の提示価格で換金する**
2. **納税する**([GDD09 §1](09-treasury-and-tax.md))
3. 残った資金で都市の物資(衣服・靴・工具・塩)を購入し、消費する

**この構造が2つの役割を果たす**:

- **1次産品の供給源。** 都市は1次品を生産しない(§1)
- **貨幣シンクの相殺。** 農民の生産は**ゼロから資源を生む**。それが都市内価格で換金され、納税で吸われ、残りが都市の最終財の需要になる。**税で消えた貨幣が、農村の生産を通じて都市に戻る**

### 3.1 来訪期間外の消費は自給として扱う(**決定**)

**農村世帯が都市で買い物をできるのは季節に一度の3日間だけである。** 日次消費([GDD02b §1](02b-consumption-and-household.md))をそのまま適用すると、**消費は毎日進むのに補充の機会が30日に3日しか無い** — パン(目標在庫3日分)も薪も、残り27日は在庫が尽きたまま消費を続けることになり、**在庫の意味が定義されない。**

**したがって農村世帯は、農村で自給できる財(パン・薪)を都市で買わず、その消費を都市の在庫・需要として扱わない。** 都市の需要になるのは、**都市でしか手に入らない財(塩・工具・衣服・靴)、滞在中および帰路の食料、そして滞在中の嗜好品**である(上のサイクル3と同じ集合)。

> **これは困窮の偽陽性の問題ではない。** 破産は**金銭**で判定する([GDD02b §3.3](02b-consumption-and-household.md))ので、資金を持ったまま市から離れている農村世帯は破産にはならない。**壊れるのは在庫と消費の側であり、[GDD02 §8-3](02-economy.md)(生産チェーン)と §8.2.2(在庫圧力)の入力である。**

### 3.2 自給に倒せない品目が残る

**塩は都市でしか手に入らない必需品である**([GDD11 §1](11-external-trade.md))。目標在庫は2週間分([GDD11 §1](11-external-trade.md) が値を持つ)、来訪間隔は30日なので、**各季およそ16日間、農村世帯の塩が尽きる。**

**素直な解は農村世帯の目標在庫を来訪間隔ぶんに取ることだが、それは [GDD02c §2.1](02c-price-and-budget.md) の目標在庫に「世帯の種別」という新しい次元を入れることになる。**

**あわせて決めるべきこと**:

- 滞在中に買うパンの日数(5日分程度が候補)
- 塩の目標在庫を来訪間隔でどう取るか
- **農村世帯を世帯として持ち続けるか**

> **この未決は農村世帯の日次予算そのものに波及する。** `必要運転資金`([GDD02c §2.1](02c-price-and-budget.md))は `余剰資金` を通じて**毎日の嗜好・奢侈の予算の母数**を決める。**滞在中のパンの日数と塩の目標在庫が決まらないと、農村世帯の予算が定まらない。**
>
> **農村世帯では必要運転資金が小さくなる。** レシピに入力を持たないので「生産の入力」の項がゼロになり、必需も都市で買うのは限られる。**手持ちの多くが余剰資金として扱われるが、これは意図した挙動である** — 収穫を売った農民が市で散財するのは中世都市の定期市の姿であり、醸造(ビール)の需要源にもなる。

## 4. 都市外市場からの置き換え

**[GDD02d](02d-external-market-and-money.md) の都市外市場は、1次産品を無限に・常時・固定価格で売る。本書はそれを有限・季節的・内生的な供給へ置き換える。**

| | 都市外市場([GDD02d](02d-external-market-and-money.md)) | 農村 NPC(本書) |
| -- | -------------------- | ---------------- |
| 供給量 | 無限 | **生産量に依存する(有限)** |
| 供給の時期 | 常時 | **季節に一度の3日間** |
| 価格 | 外部価格(世界側の定数) | **[GDD02c §1](02c-price-and-budget.md) の提示価格**(原価 = 機会費用) |
| 季節性の表れ方 | 外部価格が季節で動く | **供給量が季節で振れる**(§1) |
| 買い手としての役割 | 都市生産品を外部買値で引き取る(輸出) | **都市の最終財を買う**(サイクル3) |

**置き換えると、[GDD02 §8-1](02-economy.md)(価格の安定)の錨が1次産品から消える。** 都市外市場が無くなるなら、価格の絶対水準を決めるのは [GDD11](11-external-trade.md) の港の外部価格帯だけになる。**したがって本書と [GDD11](11-external-trade.md) は、少なくとも片方が入っていないと [GDD02d §1](02d-external-market-and-money.md) の「閉じた経済にしない」が満たされない。**

> **順序としては [GDD11](11-external-trade.md) の港を先に入れるほうが安全である。** 港が錨を引き継いでから農村 NPC に切り替えれば、錨が一度も外れない。
