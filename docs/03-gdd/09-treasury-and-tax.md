## 1. 課税

### 1.1 課税の主体は世帯である(**決定**)

**資金が世帯にしか無い以上、払えるのも払えなくなるのも世帯である**([GDD02b §3](02b-consumption-and-household.md))。

```
季節次: 流動資金 −= ApplyPermille( 流動資金 , 税率‰ )
                    = 切り上げ付きの 流動資金 × 税率‰ ÷ 1000
```

**流動資金への比例課税を採るのは、税が自己制限的だからである。** 資金ゼロの世帯は 0 を払うので、**税が直接破産を誘発しない**。切り上げ規約([GDD01 §2.3](01-trust-and-conversation.md))により資金が 1 以上の世帯は最低 1 を払うが、**自己制限性は「資金ゼロなら 0」で保たれる**。

> **世帯あたり定額の戸別賦課にすると、税率が調整不能な地雷になる。** 定額は資金の無い世帯を機械的に破産へ押し出すため、「税率を上げても貨幣量が枯渇に向かわない」という保証が「税率次第で枯渇する」に変わる。
>
> **残る歪みは許容する。** 比例課税は課税時点の現金保有量に依存するので、投げ売り([GDD02b §4](02b-consumption-and-household.md)②)の直後に換金した世帯が重く当たる。中世都市として不自然ではなく、調整軸を増やさないことを優先する。

### 1.2 納税の時点

**税は季節次に、季節境界日に処理する。** これは [ADR-0003](../adr/0003-calendar-structure.md) の暦(1年 = 4季 × 30日)に乗る。

> **[GDD12](12-countryside-and-fairs.md) の季節市が季節境界からずれると、課税ベースが変わる。** 農村世帯は来訪日に生産物を換金するので、来訪日と納税日が離れるほど「換金前のほぼ空の財布」に課税することになる。**季節市の開催日オフセットを 0 以外にするなら、納税の時点を決め直す必要がある。**

## 2. 財政還流

### 2.1 税収はできるだけ都市内に還流させる(**決定**)

**シンクだけがある系は貨幣が枯渇する**([GDD02d §1](02d-external-market-and-money.md))。税を入れた時点で、対応するソースか還流が必須になる。

**財政政策として、好況時に貯め、不況時に支出を拡大する。** これにより景気変動が緩和される。

### 2.2 支出先

| 支出                   | 需要が向かう先               |
| ---------------------- | ---------------------------- |
| **建設事業**     | 大工の賃金 + 資材(木材・薪)  |
| **衛兵**         | 賃金 +**武器・甲冑**   |
| 領主・聖職者自身の消費 | 奢侈品(ワイン・香辛料)、衣服 |

> **これが武器・甲冑という品目の存在理由である。** 市民は武器を買わない。**領主が衛兵に装備させることが唯一の需要源**であり、武器職人の存在は財政支出に依存する。**財政が縮むと武器職人が困窮する** — 経済の連関が体感される設計である。
>
> 建設事業も同様に、大工と木材加工に需要を作る。**不況時の支出拡大が、最も困窮しやすい職業を支える**構造になっている。

**支出先の職業はいずれも [GDD02 §2.4](02-economy.md) の職業表に無い。** 大工・衛兵・武器職人を職業として置くことが本書の前提であり、**それぞれ [GDD10](10-employment.md)(賃金)と品目の追加を伴う。**

### 2.3 財政を主体として実装する形

**財政は `World` 側の主体であり、世帯ではない。** 在庫・帳簿・区画を持たない。

```
財政残高(World の区分)

季節次:
    財政残高 += その季節に徴収した税の合計(§1.1)
    支出予算   = ApplyPermille( 財政残高, 還流率‰ )
    財政残高  -= 支出予算
    支出予算を口座(建設・衛兵・領主)へ配分比‰ で分割する
        残差の口座は `min` で負にならないように取る
    各口座をさらに対象品目へ分割する(端数は品目 Id 昇順に1ずつ乗せる)

日次(Trade の中で、世帯間取引が確定したあとに実行する):
    残り日数 = その季節の残り日数(今日を含む)
    各(口座, 品目)の組について:
        日次上限   = CeilDiv( 品目口座残高, 残り日数 )       ← 季節内で均す。初日に使い切らせない
        相場基準_財政 = 今日 Market に並ぶ当該品目の全売り手の提示価格の平均
                        (個人の観測を経由しない)
        留保単価   = ApplyPermille( 相場基準_財政, 許容乖離‰ )
        対象売り手 = 提示価格 ≤ 留保単価 である売り手全員(世帯Id昇順)
        日次上限を対象売り手へ均等に配分する(端数は世帯Id昇順に1ずつ乗せる)
        各売り手への購入量 = min( floor(配分額 ÷ 提示価格) , その売り手の販売在庫 )
        品目口座残高 -= 実支出額  ← 日次上限ではなく実支出額。買えなかった分は翌日へ繰り越す
    使い切れなかった品目口座残高は次季の財政残高へ繰り戻す(消えない)
```

- **貨幣総量には品目口座残高も含める。** `貨幣総量 = Σ世帯の流動資金 + 財政残高 + Σ品目口座残高`。季節次に財政残高から口座へ資金が移るだけで、貨幣は消えも生まれもしない
- **財政は「世帯外 Id」で取引する。** Id は非負 int([TDD01 §3.2](../04-tdd/01-sim-core-and-m0.md))で、既存の世帯 Id と衝突しない値を予約する

### 2.4 財政は測定器を壊しうる(**未検証のリスク**)

**財政の日次購入は、区画間の価格差を財政自身が消しうる。** 最安値の売り手だけを毎日浚うと、[GDD02 §8-4](02-economy.md) が判定する区画間の価格差が機構の帰結ではなく財政の裁定の帰結になる。

**留保単価と対象売り手への均等配分(§2.3)はその歯止めとして設計したが、有効性は実測していない。** `許容乖離‰` の値次第で、価格差が一定以上広がると財政が安い側からしか買わなくなり、元の問題に戻りうる。

> **財政の日次購入は on/off できる実験軸として実装し、[GDD02 §8-4](02-economy.md) を両条件で比較すること。** これは [GDD02 §4.1](02-economy.md)「全 NPC が共有する市場価格表を作らない」に対して財政が例外を要求することの代償でもある — 財政は NPC ではなく世界側の主体であり、徴税網が全区画に及ぶという設定的根拠を持つが、**その根拠は測定器を濁らせない理由にはならない。**

**日次上限は季節内での平滑化を目的とするが、売り注文が数日間しか立たない品目とは相性が悪い。** [GDD12](12-countryside-and-fairs.md) の季節市でしか流通しない1次産品(木材など)を建設事業の対象にすると、日次上限の前提(毎日買える)が成立しない。**1次産品向けに季節単位で均す規則を別途持つか、対象を都市内で毎日供給される品目に絞るかを決める必要がある。**

## 3. 自動調節への寄与

**税と財政は、[GDD02d §4](02d-external-market-and-money.md) の price-specie-flow と並走する第2の負のフィードバックである。**

```
税による通貨量の減少
  → 財政残高の増加
  → 季節次の支出予算(財政残高 × 還流率‰)の増加
  → 建設事業・衛兵・領主消費への購入増
  → 該当世帯の流動資金の回復
```

**税収の還流だけでは貨幣のソースにならない。** 財政残高は税(徴収時点で既に世帯間の貨幣を動かしただけ)を溜めて配るだけなので、**系全体の貨幣総量は変えない**。**したがって、貨幣のソース/シンクは [GDD02d](02d-external-market-and-money.md) の都市外市場(v1.0 では [GDD11](11-external-trade.md) の貿易)が担い続ける。** 本書が担うのは**分配**であって**総量**ではない。

## 4. 破産した世帯の再建策(**設計の記録。採用していない**)

**[GDD02b §4](02b-consumption-and-household.md) の④は「最後の1世帯」を職業維持で保護するが、保護された世帯には資金の回復経路が無い。** 財政がそこへ運転資金を貸す案を検討したが、**採らなかった。**

**引き継ぐべき既知の欠陥は2つある**:

1. **販売職に届かない。** 貸付額を `必要運転資金 − 流動資金`([GDD02c §2.1](02c-price-and-budget.md))にすると、**レシピを持たない職業(貿易商)には仕入資金が1枚も入らない** — 走査範囲が「生産の入力」と「必需の消費」だからである。仕入量を決めるのは `出荷目標在庫`([GDD02c §1](02c-price-and-budget.md))という売り手側の軸であり、別の項を足す必要がある
2. **債権放棄がほぼ発火しない。** 放棄の判定を④のゲート(販売在庫が尽きている)の配下に置くと、**貸付で立ち直った世帯は再び倒れた日には販売在庫を持っている**のが普通なので、条件が成立しない。判定はゲートの外に出す必要がある

**あわせて、救済経路そのものに反対理由がある。** [GDD02 §8-2](02-economy.md)(困窮世帯の割合)と §12-6(貨幣総量)は、「経済が回っているか」ではなく「財政の救済力」の関数になりうる。**測定が目的の段階では救済を入れない。**

> **v1.0 では掛け売り([GDD02b §4](02b-consumption-and-household.md)③)と質屋・両替商が同じ役割を担う。** 雇用([GDD10](10-employment.md))と与信が揃えば、財政を貸し手にする必要はない。**本節は「検討して却下した」記録であり、仕様ではない。**
