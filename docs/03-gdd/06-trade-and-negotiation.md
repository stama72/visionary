## 1. 便益と費用を分ける

**取引の意思決定は2つの量の比較である。**

| | 予算 | 実効価格 + 外出の費用 |
| -- | ---- | ---------- |
| 何を表すか | **便益**。その品をどれだけ欲しいか | **費用**。手に入れるのに実際いくらかかるか |
| 決まり方 | 需要のみ(相場項 × 在庫圧力。現金上限と利潤上限で切る) | 提示価格 + 信用(店ごと)、移動(区画ごと、1日1回) |
| いくつあるか | **1つ** | 実効価格は**店ごとに1つ**、外出の費用は**行き先の区画ごとに1つ** |

```
買う条件:
  ① その日に居た区画(自区画と外出先)の店のうち、実効価格が最も安い
  ② その実効価格が予算以下である
外出するかどうか、どこへ行くかは、その外出で得る余剰と外出の費用の比較で決まる(§3)
```

**①だけでは「一番マシな店でとにかく買う」になり、②だけでは「どこでもいいから予算内なら買う」になる。両方が要る。** 移動は品目ごとではなく外出ごとに払う — 同じ区画で小麦粉と薪を買っても、行くのは1回である。

## 2. 実効価格と外出の費用

```
実効価格_店       = ApplyPermille( 提示価格_店 , 1000 − α‰ × 信用 ÷ 100 )     ← GDD01 効果1。1段の ‰ に畳む
往復移動時間(d)   = 距離(自区画, d) × 1 時間/区画 × 2                            ← GDD02 §4.3。0〜8 時間
外出の費用(d)     = 往復移動時間(d) × 委託先の機会費用                            ← 貨幣。1回の外出につき1度。§3 の外出の判断にだけ使う
外出の労働損失‰(d) = CeilDiv( 委託先の労働力係数‰ × 往復移動時間(d) , T )          ← 翌日の労働力から引く(GDD02a §2)。T = 可処分時間(12)
```

- **移動は時間を奪う。だから労働力から引く。** 隅の世帯が毎日中心へ通えば、翌日の生産がそのぶん減る。徒弟(300‰)が往復4時間行けば `CeilDiv(300 × 4, 12) = 100‰` で、パン屋の実行回数は 8 から 7 に落ちる。親方が行けば 334‰ で 6 に落ちる。**旧版は移動を貨幣に換算して単価に乗せるだけで時間を消費しなかったので、機会費用を払いながらその時間で働けるという二重取りになっていた**
- **外出の費用は行くかどうかを決めるための換算値であり、帳簿には載らない。** 実際に失うのは翌日の労働であって現金ではない。換算に使う委託先の機会費用は [GDD08 §5](08-household-and-decision.md)・[GDD02c §2.4](02c-price-and-budget.md)(M0 は職業 × 階層の固定値。親方 10 / 徒弟 2 貨幣/時間)
- **移動は外出ごとに1回払う。品目ごと・単位ごとには払わない。** 旧版は「1回の移動費を目標在庫で割って1単位あたりに割り戻す」近似を採っていたが、緩衝日数を上げて目標在庫が大きくなるほど摩擦が薄まり、距離1と距離2の差が切り上げで消えていた。**固定費は固定費として扱い、外出の判断(§3)で1回だけ比較する**
- **距離**は買い手の区画と店の区画のマンハッタン距離(0〜4)で、定義は [GDD02 §4.3](02-economy.md) が持つ。**往復で数える** — 買いに行った者は帰ってくる
- **委託先**は世帯構成員のうち機会費用が最小の者([GDD08 §7.2](08-household-and-decision.md)。M0 では徒弟)。労働損失もその者の労働力係数‰ で数える
- **信用は §5 の「店の信用」を使う**(店主と応対店員の平均)

### 2.1 待ち時間は費用に入れない

**待ち時間を実効価格にも外出の費用にも加えてはならない。**

買い物に行くまでの時間には他の仕事ができるので、**実際に時間が奪われるわけではない**。待ちを費用として数えると、存在しないコストを二重に課すことになる。

**時間の緊急性は予算の側に入る。** [GDD02b §5.1](02b-consumption-and-household.md) が、在庫圧力を「買い物に行く時点で**予想される**在庫」から計算する。行くまでに食べてしまうなら予想在庫が減り、在庫圧力が上がり、予算が増える。

> **摩擦は「偽の費用」ではなく「本物の緊急性」として表す。** 空間の摩擦は外出の労働損失へ(移動は実際に時間を奪う)、時間の摩擦は予算へ(緊急性が便益を上げる)。**それぞれ1か所だけに置く。**

## 3. 外出 — 行く価値があるときだけ行き、行く価値のある区画へ行く(**決定**)

**世帯は、その外出で得る余剰が外出の費用を上回るときだけ買い物に出る。** 回数は決めない。行く価値のある区画が2つあれば2回行き、無ければ行かない。買えるのは自区画と、その日に行った区画の店だけである。

```
需要リスト = 予算 > 0 の (用途, 品目)
候補区画   = { 需要リストの品目を売る店が所在する区画 }(所在は公開。§3.1)。自区画は行かなくても買える

店 d で品目 i を価格 p で買うときの余剰:
    p      = 価格を知っている店ならその価格(§3.1)。知らない店なら床(外部買値。GDD02d §3)で見積もる
    q      = 線形解の購入量(GDD02b §5.2。基礎値と予想在庫 s から)
    w(s)   = ApplyPermille( 基礎値 , 在庫圧力‰(s) )              ← いま1単位目に払ってもよい値
    余剰_i = FloorDiv( q × (w(s) − p) , 2 )                        ← 需要が線形なので三角形。q = 0 なら 0

外出 d の価値 = Σ_i( 余剰_i(d の最安店) − 余剰_i(自区画の最安店) ) − 外出の費用(d)
                 自区画に店の無い品目は第2項を 0 とする

外出の決め方(貪欲):
    価値が最大の区画へ行く。価値 ≤ 0 なら行かない。同値は区画 Id 昇順
    行った区画で買った品目を需要リストから外し、繰り返す
    往復移動時間の合計が T(可処分時間 12)を超える外出はしない

購入(走査順に (用途, 品目) を回す):
    候補店 = 自区画とその日に行った区画の店で、その品目の売り注文があるもの。価格はその日の提示価格(着けば見える)
    店     = argmin( 実効価格_店 ) over 候補店。同値は売り手 Id 昇順
    実効価格_店 ≤ 予算 なら買う。数量は §4
```

- **余剰は線形解から出る。新しい値は増えない。** 線形解は「価格 p で q まで買う」を決めており、q 単位目の支払意思がちょうど p である。1単位目の支払意思 w(s) から p までの三角形が、その買い物で得る余剰である。**費用は既存の機会費用、便益は既存の需要関数で、比較だけを足した**
- **在庫が目標に近い日は行かない。** 余剰が小さいので外出の費用に届かない。在庫が減るほど w(s) が上がり、q が増え、余剰が二乗で伸びる。**消耗品は数日に1回、入力は量が多いのでほぼ毎日**、という頻度が値から出る(GDD02d §4.4 の値で、隅から中心の外出の費用は 12。パンは目標 6 に対して在庫 4 で余剰 10 → 行かず、在庫 3 で 20 → 行く。小麦粉は目標 24 に対して在庫 16 で余剰 50 → 行く)
- **買い物が生産を食いつぶさない。** 1回ごとに費用を超える余剰が要るので、余剰の小さい外出は切られる。それでも往復時間の合計は T で頭打ちにする — 1日に 12 時間以上は歩けない
- **価格を知らない店は床で見積もる。** 相場項が無い品目は基礎値が現金上限(資金 ÷ 1日分。[GDD02c §2.1](02c-price-and-budget.md))なので w(s) が大きく、余剰が費用を軽く超える。**したがって価格を知らない品目があれば、世帯は自然にその店へ出る** — 探索を別の規則として持たない。所在が公開(§3.1)なのは、この見積もりの行き先を知るためである
- **自区画の店との差で数える。** 自区画で買える品目は、外出しても得るのは価格差の余剰だけである。差で数えないと、自区画で足りる品目のために外出してしまう
- **行った区画の店の価格はその日の提示価格で決まる。** 記憶の価格と床の見積もりは行くかどうかを決めるための材料であり、着けば店先の値札が見える。見積もりより高ければ買わずに帰ることもあり、そのときは翌日から記憶に残る
- **選ぶ店は1つで、足りなくても次善の店へは回らない。** 買える数量は `min( 購入量(§4), 資金上限([GDD02b §3.2](02b-consumption-and-household.md)), その店の残りの販売在庫 )` で切り詰め、その品目はそこで終わる
- **在庫の無い店は候補に入らない。** `Market` に売り注文が出ていること自体は「その日の朝の販売在庫が1以上だった」ことしか意味しない。同じ日のうちに先に来た買い手が買い切ることはある
- **輸出のための外出は同じ規則で数える。** 売り手が余剰を窓口へ持ち込む([GDD02d §2.3](02d-external-market-and-money.md))のは、その日に中心へ行っていれば同じ外出であり、そうでなければ別の外出として労働損失を払う。1次産品を買う職業(水車小屋番・醸造・鍛冶)は中心へ行く日が多いので、輸出の移動は多くの日で無料になる

**帰結**:

| 現象 | なぜ起きるか |
| ---- | ------------ |
| 遠い店は不利 | 外出の費用が価値から引かれ、翌日の労働が減る |
| **まとめ買いのできる区画が選ばれる** | 需要リストの品目が多く揃う区画ほど余剰の合計が大きい。**中心は都市外市場が1次産品をすべて売るので、生産職の行き先になりやすい** |
| **在庫が減ってから買いに行く** | 余剰が在庫の減りで二乗に伸びる。発注点と発注量の在庫政策が、規則としてではなく帰結として現れる |
| **信用の高い店は「行く価値がある」** | 効果1 の割引が実効価格を下げ、余剰を増やす |
| **通りすがりの信用0のプレイヤーは選ばれにくい** | 割引が無いので実効価格で負ける |
| **地道に信用を上げれば逆も成立する** | 遠くても選ばれるようになる |
| 徒弟に行かせるほど遠くへ行ける | 費用も労働損失も 300‰ 基準で数えられ、親方の 1000‰ より安い |

> **旧版は品目ごとに店を選び、品目ごとに移動費を単価に割り戻し、1日に何区画でも回れ、しかも時間を消費しなかった。** 移動が本物の制約になっていなかった。**外出を「便益と費用の比較」にすることで、いつ・どこへ・何回行くかが世帯の判断になり、その代償が翌日の生産に出る。** 商人系職業を入れたときに「相場を調べに行く」判断は、余剰の側に観測の価値を足すだけで同じ形に乗る(§3.1 末尾)。

### 3.1 「知っている店」の定義(**決定**)

**店の所在は公開情報であり、価格は観測でしか知らない。** 2層に分ける。

```
店の所在(公開)   = 全世帯が、どの区画のどの世帯が何を売る職業かを知っている。窓口(中心)も含む
価格を知っている店 = 今日の知覚 ∪ 有効な記憶

今日の知覚 = 自区画から距離 R 以内に出ている売り注文(その日の提示価格)
有効な記憶 = 保持期間内の PriceObservation がある売り注文(前日まで)

観測(PriceObservation)が生まれる範囲
           = その日に居た区画すべてから距離 R 以内の売り注文
             居た区画 = { 自区画 } ∪ { その日に行った区画すべて }
             生まれた観測は翌日から「有効な記憶」になる

R = 視界半径(初期値 1)
```

- **所在を公開するのは、詰みを構造的に消すためである。** 旧版は所在も観測で知る形だったので、視界 R = 1 の中に買う相手が一度も現れない世帯は、買い物に出る理由が無く、永久に中心を観測しなかった — 隅のパン屋で隣接区画がパン屋と鍛冶なら、初期工具が新品で工具の需要も立たず、詰んでいた。**所在が公開なら、価格を知らない品目の店は床で見積もられ、余剰が大きいので外出(§3)が立つ。** 中世都市でパン屋の場所を知らない者は居ない。知らないのは今日の値段である
- **公開するのは所在だけである。** 価格は行かなければ分からない。[GDD02 §4.1](02-economy.md)「全 NPC が共有する市場価格表を置かない」はそのまま守られる — 本作の USP「相場表のない経済シム」は価格の摩擦であって、地図の摩擦ではない
- **知覚と記憶を分けることが、日内の相互参照を切る。** 外出の判断は「価格を知っている店」に依存する。生成した観測を当日使えることにすると循環するので、記憶は前日までとする
- **今日の知覚は当日すぐ使える。** 近所の店先は目の前にある。**外出先の店も着けば見える**(§3)
- **保持期間は「その品目が売られる間隔より長い」。これは構造の制約である。** 間隔以下だと**次に売られる前に相場基準が消えて** [GDD02c §1](02c-price-and-budget.md) の値付けが床に落ち、[GDD02c §2.1](02c-price-and-budget.md) の予算が現金上限だけになる。**「N日以上」ではなく「間隔より長い」と定義する**のは、境界で失効の判定が包含/排他の取り方に依存する余地を無くすためである
  - **M0 で「間隔」が確実に1日なのは1次産品だけである**(都市外市場が中心区画に常時並べる)。都市生産品の売り手は各2世帯しか無く、生産停止・投げ売り・職業付け替えで売り注文が途切れる日がある
  - 季節に一度しか売られない品目を入れる [GDD12](12-countryside-and-fairs.md) では、来訪間隔(1季 = 30日)が下限として効く
- **距離の起点は「その日に居た区画」であって自宅だけではない。** 自宅を起点に固定すると、知識は永久に自宅の R 以内に閉じる
- **広がった知識は保持期間で失効する。** 行かなくなった区画の相場は忘れる。**これが情報の摩擦の実体**であり、知識が単調に増えて中央の板になることを防ぐ
- **どの構成員の観測で決めるかは世帯主(親方)に固定する。** 帰宅時共有([GDD08 §8.1](08-household-and-decision.md))で世帯内の観測は同一になるので情報量は減らない。**固定しないと、買いに行く者が誰かで候補集合が変わる** — [GDD02c §1.2](02c-price-and-budget.md) が相場基準について同じ理由で世帯主に固定したことが、店の選択の側から破れる
- **走査は売り手世帯 Id 昇順、`argmin` の同値は Id 最小を採る**([ADR-0002](../adr/0002-time-model-and-determinism.md) の列挙順規約)
- **観測は「見た」時点で生まれる。** 買わなくても、視界に入った売り注文は記録される
- **M0 に視界半径の例外は1つも無い**([GDD02 §4.1](02-economy.md))。**都市外市場([GDD02d §2](02d-external-market-and-money.md))は `Market` に実体を持たないが、店の候補としては中心区画(Id 4)に居る1人の売り手と同じに扱う** — 所在は公開、価格は距離 R の外からは見えない。**売り手 Id はどの世帯 Id よりも大きい予約値**なので、上の Id 昇順の走査では最後に来る。**定期市を視界の例外にする規則は [GDD12 §2.2](12-countryside-and-fairs.md) が持つ** — 例外を必要とする分冊が、自分の理由で正当化する
- **自分の売り注文は自分の観測(`PriceObservation`)に入れない。** 観測は「他人の売り注文を見た記録」である。売り手の値付けが自分の前日の約定単価を混ぜる規則は [GDD02c §1.2](02c-price-and-budget.md) が持つ

> **視界半径 R は値ではなく構造である。** R = 0 なら自区画の店先しか見えず、外出先で見た店だけが記憶に入る。R = 2 なら中心区画の世帯が最初から全区画の価格を見通す。**「誰が何を知りうるか」が R で変わるので、W2 の実データで調整する値として扱ってはならない。**

**これで初日が動く。** 全世帯が視界内の売り注文を見て買い、視界に無い品目は所在をたどり、床の見積もりで外出に出る。**初日の予算は相場項が無いので現金上限だけである**([GDD02c §2.1](02c-price-and-budget.md))。

> **予算は当日の観測を反映しない。前日までの観測から計算する。** そうしないと「見た瞬間に相場基準が立つ」ため初日から相場項が立ち、現金上限だけで動く初日の設計が空振りする。**[GDD08 §6.3](08-household-and-decision.md) が機会費用に対して採った1日遅延の成層化と同じ扱いであり**、情報の摩擦の一形態でもある。

#### それでも買えないとき

**所在は公開なので「知っている店が0件」は起きない。** 起きるのは、行った先で売り注文が無かった(在庫切れ・生産停止)か、価格が予算を超えていたか、余剰が外出の費用に届かず行かなかった場合である。このとき買わずに **Need を立てる**:

| 条件 | Need 種別 / 理由コード |
| ---- | ---------------------- |
| その日に買えず、予想在庫が目標在庫を下回る | **在庫不足 / 遠方在庫**([GDD02b §8](02b-consumption-and-household.md)) |

**新しい Need 種別を足していない。** [GDD02b §8](02b-consumption-and-household.md) の表は既に「区画をまたぐ運搬が要る → 在庫不足 / 遠方在庫」を持っている。

**これは [GDD08 §7.4](08-household-and-decision.md) のゲートの特例である。** §7.4 は `min(世帯内の機会費用) × 所要時間 > 外注コストの見込み` を Need の唯一の絞りとするが、買えなかった日はその式の「所要時間」が既に払われている。買えなかったときは §7.4 を通さずに Need を立てる。

> **M0 ではこの Need を履行する主体を置かない。** 行商人も運送労働者も [GDD11](11-external-trade.md) へ出してある。Need は「まだ届いていない」という信号として立つだけでよく、v1.0 で行商人と運送が履行する。
>
> **区画に役割は無い。** [GDD02 §4.3](02-economy.md) の9区画はいずれも同格であり、**中心(Id 4)が特別なのは距離が最小であることと都市外市場がそこに居ることだけである**。[GDD11](11-external-trade.md) で港を入れるときも「港区画」は作らず、貿易商がどこに居るかだけが効く。

> **長期的には、価格の観測そのものを外出の便益に組み込む。** いまの余剰は買う品目の分しか数えない。知っている店が1軒あれば、その店が高くても、他所の値段を調べに行く価値は数えられない。商人系職業([GDD11](11-external-trade.md))は相場を調べることで初めて商売が成り立つので、そのときに「観測の価値」を外出の価値に足す形へ広げる。M0 では入れない — 観測の価値を金額にするには、観測から得られる利益の見込みが要り、それは商人の分冊が持つ。

## 4. いくつ買うか

**式は [GDD02b §5.2](02b-consumption-and-household.md) の線形解による。** 本書が持つのは、その入力に**どの店の実効価格を使うか**である:

```
購入量 = f( 選ばれた店の実効価格, 予想在庫, 目標在庫, 基礎値 )
```

**店を選んでから量を決める。** 逆順(量を決めてから店を選ぶ)にはしない — 実効価格が店ごとに違う以上、量は店に依存するためである。**外出の費用は数量に入らない。** 行くと決めた時点で払っており、着いてからいくつ買うかには関係が無い(埋没費用)。§3 の余剰の見積もりに使った q と、着いてから解く購入量は、価格が見積もりどおりなら一致する。

## 5. 店に対する信用

信用は個人が持つ([GDD01 §2.1](01-trust-and-conversation.md))ので、「あの店は信用できる」を表すには導出が要る。

```
取引時の信用 = ( 親方(店主)への信用 + 応対した店員への信用 ) ÷ 2
```

- **信用の変化も両方に効く。** 良い取引は店主と店員の双方の信用を上げる
- **実体を持たせない。** これは導出値であり、`TrustScore` は個人間のままである

**帰結**: 店主や番頭が大口取引に出る理由が生まれる([GDD08 §3.3](08-household-and-decision.md))。店主が応対すれば信用は店主に二重に乗る。

> **プレイヤーの店にも同じ規則が適用される**(分冊04)。従業員を雇うと、**その従業員への信用がプレイヤーの店の信用を薄める**。誰に応対させるかが判断になる。

## 6. M0 のスコープ

| 要素 | M0 | v1.0 |
| ---- | -- | ---- |
| 予算と費用の分離(§1) | **入れる** | |
| 実効価格と外出の費用(§2)、余剰と費用の比較による外出と店の選択(§3)、購入量(§4) | **入れる** | |
| 価格の観測そのものを外出の動機にする(§3.1 末尾) | **入れない** | 商人系職業と同時に |
| 店の信用(§5) | **入れる** | |
| **妥結価格** | **提示価格をそのまま妥結価格とする** | 交渉を入れる |
| 商談フロー、提示と応答、留保価格 | **入れない** | §7 |
| 掛け売りの運用 | **入れない**(困窮時の与信は [GDD02b §4](02b-consumption-and-household.md)③ が概念だけ持つ) | §7 |

> **M0 で妥結を作らないのは、価格機構の検証に不要だからである。** [GDD02c](02c-price-and-budget.md) が測るのは価格の安定・貨幣の循環・摩擦の残存であり、いずれも提示価格で成立する。**交渉を入れると調整軸が増え、価格が動いた原因が機構か交渉かを切り分けられなくなる。**
