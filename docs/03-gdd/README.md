## 執筆ルール

- 数値は初期値として書き、調整対象であることを明記する。固定すべきは構造と依存関係
- **各分冊に「未決定事項」節を置かない。** 判断待ちは [GitHub の issue](https://github.com/stama72/visionary/issues) が持つ([ADR-0006](../adr/0006-issue-driven-task-management.md) 論点2)。分冊が持つのは「今の仕様」だけである
- [idea/](../idea/) のメモが原典の場合はリンクする
