> **本書が持つのは、都市の外との貨幣の出入りと、外部価格が都市内の価格に与える帯(天井と床)である。** 貨幣が需要に効く式は [02c](02c-price-and-budget.md) が持ち、季節係数の値は [GDD03 §2](03-seasons-and-city.md) が持ち、窓口を港・行商人・貿易商に置き換える拡張は [GDD11](11-external-trade.md) が持つ。
>
> **本書の中心は §4 の校正である。** M0 では生産能力・需要量・外部価格がすべて定数であり、貨幣量を有界に保つ負のフィードバックは細い([GDD02 §8](02-economy.md)-6)。**したがって貨幣の収支は、機構ではなく事前の校正で合わせる。** 無計画な値で実験に回さない。

## 1. なぜ閉じた経済にしないか

[GDD01 §6](01-trust-and-conversation.md) の M0 検証項目2 は「長期実行して価格が発散・硬直しないか」である。**この判定を通せるかは、貨幣のソースとシンクの設計でほぼ決まる。**

- **完全に閉じた系**(貨幣総量が一定): 価格の絶対水準が動かない。錨が無いので、すべての価格が相互参照だけで決まり、**どこへ漂流しても「安定している」と読めてしまう**
- **シンクだけがある系**: 貨幣が枯渇し、全 NPC が困窮する

**M0 は都市外市場を1つだけ置くことで、錨とソースとシンクを同時に得る。**

> **旧版はこの錨を片側にしか置いていなかった。** 都市生産品には床(外部買値)だけがあり、上側は無かった([issue #87](https://github.com/stama72/visionary/issues/87))。**片側の錨では、上の1つ目の箇条書きが言う漂流がそのまま起きる** — 提示価格も予算も価格と相場基準の**比**しか含まず(価格について0次同次)、相場基準は価格そのものの平均なので、系全体が上へ漂流しても誰も気付けない。[issue #120](https://github.com/stama72/visionary/issues/120) は 60 日で床の 67 倍という形でこれを踏んだ。**§3 の天井は、この箇条書きが元から要求していた錨のもう半分である。**

## 2. M0 の都市外市場(**決定**)

### 2.1 主体

**`World` 側の主体である。世帯ではない。** 在庫・帳簿・流動資金・家計を持たず、**無限の相手方**として振る舞う。区画は**中心(Id 4)に固定**する([GDD02 §4.3](02-economy.md))。

**売り注文を `Market` に実体化しない。** [TDD01 §3.2](../04-tdd/01-sim-core-and-m0.md) の `Market` のキーは売り手**世帯**であり、**都市外市場は世帯ではないのでそこには入らない**。代わりに、**買い手の店選択([GDD06 §3.1](06-trade-and-negotiation.md))が、中心区画について外部価格から候補を1件合成する。**

- **`Market` の型と決定論ハッシュの契約が動かない。** 外部価格は設定と暦から決まる定数であって状態ではないので、レシピ表や距離と同じくハッシュの対象外である([TDD01 §3.8](../04-tdd/01-sim-core-and-m0.md))。**実体化すると「`Market` は含める / 窓口は含めない」という二重定義が生まれ、しかもどちらに実装しても同一設定の2回実行は一致するので CI が検出しない**
- **売り手 Id を予約する。** `PriceObservation` の売り手欄([TDD01 §3.6](../04-tdd/01-sim-core-and-m0.md))に、**既存の世帯 Id と衝突しない非負 int を1つ、どの世帯 Id よりも大きい値で**窓口用に予約する
- **走査順は [GDD06 §3.1](06-trade-and-negotiation.md) の売り手 Id 昇順に従い、合成した候補は最後に来る。** したがって**実効価格が同値なら都市内の売り手が選ばれる** — 窓口は最後の手段であるという位置づけと一致する
- **[GDD11 §2](11-external-trade.md) の行商人はこの解では済まない。** 行商人は**区画を巡回する**ので居場所が状態になり、設定からの合成では表せない。そちらは分冊が自分で解く

| | 都市外市場の振る舞い | 貨幣 |
| -- | -------------------- | ---- |
| **1次産品**(穀物・木材・鉄鉱石・木炭) | **外部売値**で無制限に**売る**。中心区画の売り手の候補として常時現れる | 都市の**外へ出る**(輸入) |
| **都市生産品**(小麦粉・薪・パン・ビール・工具) | **外部買値**で無制限に**買い、外部売値で無制限に売る**。1次産品と同じく中心区画の売り手の候補として常時現れる | 買えば**外へ出る**(輸入)、売れば**中へ入る**(輸出) |

外部価格の初期値は §4.4 の校正表が持つ。**季節係数が掛かる**(§5)。

> **都市生産品も窓口が売る、というのは [issue #87](https://github.com/stama72/visionary/issues/87) の「都市生産品は外部買値だけを持つ」の反転である**([issue #120](https://github.com/stama72/visionary/issues/120) の決定7)。**反転した理由は、都市生産品の価格に名目の天井を与えることではなく、不足に供給を応答させることである。**
>
> M0 の生産量は `min(生産能力, 入力で賄える回数)` であり、**価格がいくら上がっても生産能力は動かない**([02a](02a-production.md))。したがって都市の供給は生産能力で頭打ちの垂直線で、左へしか倒れない。**価格の天井だけを置いて窓口が売らない形では、天井に押し付けられても供給が増えず、不足は買い手の在庫が尽きて消費を諦めるまで解けない。** 窓口が実際に売って初めて、不足に対する応答が系に入る。価格について右上がりの供給関数を都市の側に作るのは [issue #92](https://github.com/stama72/visionary/issues/92)(生産関数)であり、M0 のスコープ外である。
>
> **代償は、都市内生産の希少性が薄れることである。** 窓口が無限に売る世界では、都市の職人が作れない量を窓口が埋める。**引き換えに得るのは2つ** — 不足に対する供給の応答と、**中心区画にしか窓口が無いことから生まれる裁定余地**(下記 §2.4・§3)である。

### 2.2 買う側(輸入)は、通常の店選択がそのまま働く

**合成された候補は、中心区画に居る1人の売り手とまったく同じに扱う。** 買い手側に分岐は入らない:

- 買い手は [GDD06 §3](06-trade-and-negotiation.md) の店選択をそのまま適用する。**移動費(中心までの距離)が乗る**
- 観測(`PriceObservation`)も通常どおり生まれる。**視界半径の例外は置かない**([GDD02 §4.1](02-economy.md))。隅の区画の世帯は、隣接区画へ買い物に行った日に中心を観測する([GDD06 §3.1](06-trade-and-negotiation.md))
- **売り手の在庫圧力([GDD02c](02c-price-and-budget.md))は適用しない。** 提示価格は外部売値そのものであり、無限在庫なので在庫比が定義できない
- **窓口の価格を知らない世帯の 1次産品 の見積もりは 1(最小の正の価格)である。** [GDD06 §3](06-trade-and-negotiation.md) の見積もりは「今日の知覚 → 有効な記憶 → 床」の順に当てるが、1次産品は外部買値を持たない(§3)ので床が無い。**都市生産品はこの例外に入らない** — 床(外部買値)を持つので、通常どおり床で見積もる。**床の役割は「知らない店を楽観的に見積もらせて探索を起こす」ことである**(GDD06 §3)から、代わりに最小の正の価格を置く。0 にはしない — 予算のゲート([02c §2.1](02c-price-and-budget.md))と資金上限([02b §3.2](02b-consumption-and-household.md))はどちらも実効価格が 1 以上であることに立っている。中心へ一度行けば記憶が入り、翌日からは実価格で見積もる

**外部売値が価格の天井になる。** 1次産品は都市内に売り手が居ないので、天井は同時に**実勢価格**でもある。**都市生産品では、天井は実勢ではなく上限として働く** — 都市内の売り手が外部売値より安く並べている限り [GDD06 §3](06-trade-and-negotiation.md) の店選択は都市内を選び、窓口は現れない。

> **天井は clamp ではなく、店選択から創発する。** [02c §1](02c-price-and-budget.md) の提示価格の式に上限の項を足さない。売り手は今までどおり `max(床, 相場基準 × 価格係数)` で並べ、**その値が外部売値を上回った日に買い手が窓口を選ぶ**だけである。式を1本も増やさずに帯が閉じる。
>
> **したがって天井は区画ごとに柔らかい。** 窓口は中心区画にしかなく、そこへ行くのは外出であって翌日の労働力を奪う(§2.3・[02a §2](02a-production.md))。**周縁の区画では、窓口へ行く手間のぶんだけ都市内の売り手が外部売値を上回っても選ばれ続ける。** これは欠陥ではなく、[GDD02 §8](02-economy.md)-4 が測る区画間の価格差([issue #29](https://github.com/stama72/visionary/issues/29))が潰れずに残る経路であり、**プレイヤーが商人として「中心で仕入れて周縁で売る」を成立させる余地そのもの**である。

### 2.3 売る側(輸出)— 床に張り付いた在庫だけを窓口へ持ち込む

**輸出も中心区画の窓口で行う。** 売り手は余剰を中心へ運び、外部買値で売る。買いに行くときと同じく**外出であり、時間を奪う** — その日に中心へ行っていなければ別の外出として労働損失を払う([GDD06 §2・§3](06-trade-and-negotiation.md)、[02a §2](02a-production.md))。

```
係数*‰      = CeilDiv( 外部買値 × 1000 , 相場基準 )                   ← 窓口の値は、提示価格式のどの価格係数にあたるか
在庫比*‰    = clamp( 2 × (1500 − 係数*‰) , 0 , 2000 )              ← 価格係数式 係数 = 1500 − 在庫比 ÷ 2 の逆関数(02c)
輸出の閾在庫 = CeilDiv( 出荷目標在庫 × 在庫比*‰ , 1000 )
              相場基準が無い日は 輸出の閾在庫 = 出荷目標在庫

日次の Trade(順5)で世帯間の取引が確定したあと、売り手ごとに:
    超過分 = max( 0 , 販売在庫 − 輸出の閾在庫 )
    超過分を外部買値で売る(中心へ持ち込む。外出の労働損失は 02a §2)
        流動資金 += 外部買値 × 超過分
        販売在庫 −= 超過分
```

**意味は「提示価格が床に張り付いている在庫だけを、床の値で外に流す」である。** 提示価格は `max(床, 相場基準 × 価格係数(在庫比))` で決まり([02c](02c-price-and-budget.md))、床は外部買値である。在庫が輸出の閾在庫を超えると価格係数の項が床を下回り、都市内で並べても窓口と同じ値にしかならない。**その在庫を持ち続ける理由は無い。** 逆に閾在庫より下では都市内の提示価格が窓口を上回るので、都市の買い手のために取っておく。

- **輸出量は外部買値と相場に応答する。** 都市の相場が窓口より高ければ閾在庫は出荷目標在庫より高くなり、輸出は減る。相場が窓口の 2 倍以上なら閾在庫は 2倍に張り付き(係数* ≤ 500‰ で在庫比* が clamp される)、相場が窓口の 2/3 を下回れば閾在庫は 0 になって全量を持ち込む。**輸出の供給関数が、提示価格の逆関数として自然に出る。** 出荷目標在庫は在庫比の物差しとして残るが、輸出を決める定数ではなくなる
- **閾在庫が変えるのは手元に置く緩衝の量であって、定常状態の流量ではない。** 定常状態で都市内に売れなかった分は、閾在庫がいくつであれ毎日外へ出るか積み上がるかのどちらかである。**§4.4 の校正は流量で行うので、この規則の影響を受けない**
- **原価と比べない。** 既に持っている在庫の取得原価は埋没費用であり、売る時点の判断に入らない([GDD02 §5](02-economy.md) 帰結2)。外部買値が原価を下回っていても、窓口に持ち込める値より安く都市内に並べる理由は無く、持ち続ける理由も無い。**「損切りしない」という規則は置かない**
- **逆関数の等価性は、[02c §1.1](02c-price-and-budget.md) の「売れなかった日は値上げしない」が効く日には成り立たない。** その日の価格係数は 1000‰ で頭打ちになるので、係数*‰ が 1000 を超える売り手(= 外部買値が相場基準を上回っている売り手)は、**閾在庫より下でも提示価格が床に落ちる**。上の「意味は」の段落が言う「閾在庫より下では都市内の提示価格が窓口を上回る」は、この場合だけ外れる。**輸出の量は変わらない**(閾在庫の式は動かない)ので、ずれるのは都市内の並び値だけである
- **丸めの向き**: 係数*‰ の `CeilDiv` は提示価格式の在庫比‰ と同じく品薄側に寄せる。閾在庫の `CeilDiv` は都市に残す側に寄せる
- **相場基準が無い日に閾在庫を 0 にしない。** その日の提示価格は床そのものなので全量が「床に張り付いて」いるが、全量を持ち込むと都市の買い手の前から在庫が消える。出荷目標在庫で代用する
- **持ち込みの外出は買い物と同じ規則で数える。** その日に中心へ行っていれば同じ外出で済み、そうでなければ別の外出として翌日の労働力から引く。**その日の往復時間の合計が T(可処分時間。[GDD06 §3](06-trade-and-negotiation.md))を超える日は持ち込まない** — 買い物の外出と同じ上限を、買い物の往復時間を含めた合計で数える。**持ち込んだ日は中心に居たことになるので、窓口と中心区画の売り注文の観測が生まれる**(§2.2、[GDD06 §3.1](06-trade-and-negotiation.md)「居た区画 = 自区画 ∪ その日に行った区画すべて」)。ただし**その日に中心で買うことはできない** — 輸出は世帯間の取引が確定したあとに走るので、買い物は既に終わっている。1次産品を中心で買う職業(水車小屋番・醸造・鍛冶)は多くの日で無料になり、パン屋と木材加工は輸出のたびに時間を払う。**移動を貨幣で割り引いて床を区画ごとに変える形は採らない** — 床が区画で違うと区画間の価格差に輸出の成分が混じる。区画の差は労働損失として生産量に出る
- **破産中フラグ([02b §3.3](02b-consumption-and-household.md))が立っている売り手は、その日の輸出の閾在庫を 0 にする。** 困窮の段階②「在庫を投げ売る」の窓口側である — 都市内では相場の半値で並べ([02c §1.4](02c-price-and-budget.md))、残りは全量を床で現金に換える

> **旧版は「外部買値 ≤ 原価なら売らない」を置き、輸出の閾を出荷目標在庫の定数にしていた。** 前者は現金と利潤の混同である([GDD02 §5](02-economy.md)) — 損失は仕入れた時点で確定しており、売らないことで消えはしない。**売らない規則は、原価が外部買値を上回った工房の在庫を恒久に凍らせ、輸出が止まって貨幣が流出し続ける経路を作っていた。** 後者は「窓口の値がいくらでも同じ量を出す」規則であり、外部買値を動かしても輸出量が応答しなかった。

**世帯間の取引が消えるわけではない。** 輸出規則は世帯間の取引が**確定したあと**に走り、対象は**閾在庫を超えた分だけ**である。都市内の買い手は毎日その手前にアクセスできる。

### 2.4 裁定者にしないための制約

**中央の板と同じ危険がある** — 窓口が最安値を毎日浚えば、[GDD02 §8](02-economy.md)-4 が判定する区画間の価格差を窓口自身が消してしまう。**抑えているのは次の2つである**:

1. **窓口は能動的に買わない。** 輸出規則は**売り手が余剰を持ち込む**形であり、窓口が店を選んで回ることはない。**これが主たる歯止めである**
2. **窓口が買うのは出荷目標在庫を超えた分だけである。** 都市内の買い手が先にアクセスできる範囲は毎日残る

**売る側(§2.1 の反転)には、この2つの歯止めが効かない。** 窓口は中心区画で全品目を無制限に並べており、買い手が来れば必ず売る。**売る側を抑えているのは、中心区画にしか窓口が無いことだけである** — 周縁の世帯にとって窓口は「外出1回ぶん遠い店」であり、その手間が都市内の売り手の取り分になる。**前提4([issue #120](https://github.com/stama72/visionary/issues/120) の決定7)はここに掛かる。** 窓口が区画間の価格差を平準化しきってしまうかは [GDD02 §8](02-economy.md)-4 が実測する([issue #29](https://github.com/stama72/visionary/issues/29))。**#29 の判定は、窓口が売る側に回ったことで負荷が上がっている。**

**買って売り戻す裁定は、§3.1 の成立条件 (f) が閉じている。** 窓口で外部売値で買い、同じ窓口へ外部買値で売り戻すと、`外部買値 < 外部売値` のぶんだけ必ず損をする。**この不等式が破れると、外出の費用を払ってでも無限に回る経路ができる。**

**輸入も輸出も、窓口が中心区画にしか無いことで抑えられている。** 中心への外出は時間を奪う([GDD06 §2](06-trade-and-negotiation.md)・§2.3)ので、輸入で近所の店と競合するのは中心付近だけであり、遠い売り手ほど輸出のたびに翌日の生産を失う。

> **輸出の床そのものは全区画で同じ外部買値である。** 区画の差は床ではなく労働損失(生産量)に出る。窓口が区画間の在庫圧力を平準化する側に働くかどうかは [GDD02 §8](02-economy.md)-4 が実測する([issue #29](https://github.com/stama72/visionary/issues/29))。

> **天井が効くたびに、都市の貨幣が減る。** 天井は clamp ではなく買い手が窓口を選ぶことで働く(§2.2)ので、**都市内の提示価格が天井を超えた日の需要は、都市内の売り手ではなく窓口へ向かう。** 閉じた経済なら「高い店を避けて安い店へ移る」は世帯間の再分配で済むが、**窓口は都市の外にあるので、同じ移動が都市からの純流出になる。**
>
> **[issue #120](https://github.com/stama72/visionary/issues/120) の実測(シード1・60日)で、この経路が支配的だった。** 窓口への輸入 28,500 のうち **必需品(パン 13,176・薪 8,500)が 76%** を占め、生産の入力(1次産品 4,052 + 小麦粉 1,904)は 21% にとどまった。連鎖はこうである — **入力が買えず生産が落ちる → 都市内の供給が減る → 提示価格が天井を超える → 買い手が窓口を選ぶ → 貨幣が流出する → 資金がさらに細る。** パン屋の生産は day 1 の 12 回から day 11 に 0 へ落ち、都市内のパンの最安提示は day 3 に 139(天井 108)へ達した。

> **連鎖の起点は生産の低下だけではない。** [issue #210](https://github.com/stama72/visionary/issues/210) の再測(#170 後・30日・5シード)では、**生産が能力どおりだった day 1〜4 から、都市内の提示が天井以上になって需要が窓口へ漏れていた。** 窓口で買った約定の約 76% は、買い手が都市内の売り手を窓口以上と見ていた(実際に、または記憶の中で)日に起きており、品切れは 4% だった。起点は値付けの側にあり、[02c §1.3](02c-price-and-budget.md) の出荷日数で**狭めた**(薪とパンの輸入は約7割減)。**塞いではいない** — 外出の費用で窓口を選ぶ分(約 17%)と、最初の5日の流出([issue #220](https://github.com/stama72/visionary/issues/220))は残る。
>
> **これは §2.1 の反転(決定7)が受けた代償の一部である。** 却下理由として記録したのは「都市内生産の希少性が消える」だけだったが、**不足に供給を応答させる経路は、同時に不足のたびに貨幣を抜く経路でもある。** 窓口が無限に深いこと自体は歯止めの問題ではない(上の2つと中心区画の制約は効いている)。**効かないのは、天井が「価格を抑える」と同時に「需要を都市外へ逃がす」ことである。**
>
> **[GDD02 §8](02-economy.md)-6(貨幣総量が有界に留まる)の判定は、この経路を「輸出が発火していない」と読み違えうる。** 実測では輸出は正常に発火していた。**切り分けは「窓口からの購入が約定に占める割合」を品目別に見る**([issue #41](https://github.com/stama72/visionary/issues/41) のメトリクス。§8-4 が区画別に持っているものと同じ量である)。

## 3. 外部価格が定める帯 — 天井と床(**決定**)

| 層 | 外部価格 | 都市内価格との関係 |
| -- | -------- | ------------------ |
| 1次産品 | 外部売値 | **天井であり実勢**。都市内に売り手が居ないので、仕入単価はここに固定される |
| 都市生産品 | 外部買値 | **床**。提示価格の下限([02c](02c-price-and-budget.md))であり、輸出の値でもある |
| 都市生産品 | **外部売値** | **天井**。都市内の提示価格がこれを上回ると、買い手は中心区画の窓口を選ぶ(§2.2)。**提示価格の式に上限の項は無く、店選択から創発する** |

```
外部売値[都市生産品] = ApplyPermille( 外部買値 , 1000 + 交易マージン‰ )     交易マージン‰ = 1000(初期値。§4.4)
帯 = [ 外部買値 , 外部売値 ] = [ 床 , 床 × 2 ]
```

> **帯の幅は「世帯が直面しうる生活費は最大で床価格の2倍」と読める。** [§4.4](#44-校正表初期値) の生活費 225/日 は床価格の消費バスケット(パン 108 + 薪 40 + ビール 72 = 220)そのものなので、**全品目が天井に張り付いた日の生活費は 440/日 = 収支ゼロの水準のちょうど2倍になる。** 困窮([02b §4](02b-consumption-and-household.md))はこの帯の中で届く。
>
> **上側の錨が無かった旧版では、帯の上端は現金上限(初期資金 2,400 ÷ 1日分)= 床の 22 倍だった。** そこへ到達したときが経済の死である([issue #120](https://github.com/stama72/visionary/issues/120) の実測。資金が1戸へ集中し、他の世帯が1次産品を買えなくなる)。**旧版に名目の錨が床と貨幣量の2本しか無かったことが #120 の発散の構造的な原因であり、この表の3行目がその穴を塞ぐ。**
>
> **交易マージン‰ を 1000 にした理由**(却下した値は [issue #120](https://github.com/stama72/visionary/issues/120) の決定8)。(1) 帯 2.0 倍は §4.3 (e) の非対称なケース(出力が床・入力が天井)を全レシピで満たすので、**価格側から生産が止まることが無い**。(2) 相場基準が床に張り付く([§4.5](#45-床への張り付き予測))定常状態では、品薄の売り手の提示価格は 1.5 × 床 であり天井に届かないので、**価格係数の 1500‰ が clip されず希少性は完全に表現できる**。**ただし出荷日数 1([02c §1.3](02c-price-and-budget.md))では、1500‰ に届くのは生産 0 の日(売る物が無い日)だけなので、この理由はほぼ空になった。** 1000 の決定は (1)・(3) で保たれる。(3) [issue #120](https://github.com/stama72/visionary/issues/120) の帯の検出器の `BandMultiplier` がこの値そのものになる。

### 3.1 成立条件: 輸入含有原価 < 外部買値

**都市生産品ごとに、1単位を作るために都市の外へ出て行く貨幣(輸入含有原価)が、その1単位を外に売って入ってくる貨幣(外部買値)より小さいこと。**

```
輸入含有原価[1次産品]  = 外部売値
輸入含有原価[都市生産品] = CeilDiv( Σ_j( 必要数量_j × 輸入含有原価[入力 j] ) , 出力数量 )
成立条件:  輸入含有原価[i] < 外部買値[i]     都市生産品 i すべてについて
```

- **購入原価ではなく輸入含有量で数える。** パン屋が小麦粉に払う値には水車小屋番の利幅が乗っているが、それは都市内の移転であって流出ではない。都市の外へ出るのは穀物と木材の代金だけである
- **破れると、世帯として正しい行動が都市として貨幣を漏らす。** 余剰を持つ世帯は埋没費用を無視して外部買値で売る(§2.3)のが正しい。しかしその1単位を作るために出て行った貨幣のほうが多ければ、輸出のたびに都市の貨幣が減る。**この条件は世帯の合理性では守れず、外部価格の側で守るしかない**
- **貨幣の流入の側に条件は置かない**(§3.2 の `外部買値 < 外部売値` は価格の帯を閉じる条件であって、流入の条件ではない)。旧版は `外部買値 < 原価下限` を流入側の上限として置き、「売れ残りが毎日確実に利益に変わって貨幣が過剰に流入する」ことを恐れた。**しかし利潤は移転であって貨幣量の増加ではなく**([GDD02 §5](02-economy.md))、貨幣が都市に入る量は輸出量 × 外部買値であって利幅ではない。流入が過剰かどうかは §4 の収支で見るものであり、価格の不等式では決まらない。**旧版の上限は、貨幣から需要へ通じる経路が無かったことの代替だった** — その経路はいま予算の現金上限([02c](02c-price-and-budget.md))が持つ

### 3.2 成立条件: 外部買値 < 外部売値(**都市生産品**)

**窓口で買って同じ窓口へ売り戻したとき、必ず損をすること。**

```
成立条件:  外部買値[i] < 外部売値[i]     都市生産品 i すべてについて
```

- **破れると、外出の費用を払ってでも無限に回る経路ができる。** 窓口は無限の相手方(§2.1)なので、1周の利鞘が正なら回数に上限が無い。**これは世帯の合理性が正しく働いた結果として起きる** — §3.1 と同じく、外部価格の側で守るしかない
- **式の形で守る。** 外部売値[都市生産品] は独立した値ではなく `ApplyPermille(外部買値, 1000 + 交易マージン‰)` で導く(§3)。**交易マージン‰ が正である限り、この条件は構成によって成り立ち、破りようがない。** 独立した値として表に置き、検査で守る形は採らない — 検査は値を動かした PR でしか働かないが、導出なら**そもそも不整合な組を表現できない**
- **1次産品には要らない。** 窓口は1次産品を買わない(外部買値を持たない。§2.1)ので、売り戻す先が無い
- **交易マージン‰ は [GDD11](11-external-trade.md) で都市内の貿易商の利益になる**(§5 の末尾)。M0 では担い手が居ないので、単に帯の幅である

## 4. 貨幣の収支と自動調節

### 4.1 恒等式(**決定**)

```
都市の貨幣総量の日次変化 = 輸出額 − 輸入額            世帯間の売買は移転であり、消える
Σ_世帯( 世帯の日次収支 )   = 輸出額 − 輸入額            同じ量を世帯の側から見たもの
```

**2行目が校正の要である。** 全世帯の収支を足すと、都市内の売買は売り手の収入と買い手の支出で相殺され、残るのは外との出入りだけになる。したがって:

- **貿易収支が均衡していれば、世帯は平均して収支ゼロである。** 全世帯が同時に貯め込む定常状態は存在しない。ある世帯が貯めるなら別の世帯が減っている
- **都市内価格が床を上回る分は、世帯間の再分配である。** 工具が高くなれば鍛冶が潤い、他の全員がそのぶん減る。合計は変わらない。**ただし床を上回るのは、地元の需要が日産を超える売り手だけだと予測する**(§4.5)
- **逆に、貿易が黒字なら都市全体が貯まり、赤字なら都市全体が減る。** [GDD02 §8](02-economy.md)-6 が「有界に留まる」で見ているのはこの量である

### 4.2 M0 で働く自動調節(price-specie-flow)

```
輸入(1次産品の仕入)で貨幣が流出
  → 都市内の流動資金が減る
  → 予算の現金上限(用途に使える資金 ÷ 1日分。母数の小さい嗜好から順に。02c)が閉じる
  → 買い手がゲートで脱落し、都市生産品が売れ残る
  → 販売在庫が出荷目標在庫を超える
  → 輸出が発火し、貨幣が流入する
```

**これは正貨流出入メカニズム(price-specie-flow)そのものである。** 歴史的にも実在した調節機構であり、**外部価格という「神の値」を、経済的に正当な錨として使える**ことを意味する。

> **ただし M0 でこの経路は細い。** 消費量は定数で、上限はゲートとしてしか効かない(超えなければ数量は相場基準の線形解が決める。[02c](02c-price-and-budget.md))ので、貨幣が減っても買い手が脱落するまでは需要が動かない。**生産能力も定数**なので供給側の応答も無い(生産関数は [issue #92](https://github.com/stama72/visionary/issues/92))。**したがって M0 の貨幣量は、主として §4.3 の校正で有界に保つ。** 機構は校正の周りの小さな揺れを戻す役でしかない。[GDD02 §8](02-economy.md)-6 の判定では「校正で通したのか機構で通したのか」を記録する。

### 4.3 均衡の条件(**決定**)

**初期値の組は、次の5条件を満たすように事前に校正する。** 実験に回してから探さない。

| # | 条件 | 破れたときに起きること |
| - | ---- | ---------------------- |
| (a) | **都市生産品ごとに、年平均の余剰 ≥ 0**(生産能力 ≥ 需要)。これが硬い条件で、機械で守る。**校正の狙いとしては需要の 1.2 倍前後に置く**が、これは条件ではない — 薪は季節の振れを受ける側なので 1.1 弱、工具は鍛冶 2 世帯 × 1 個/日 に対して需要 1 個/日で 2.0 に固定される(整数の世帯数と N から出る比で、倍率では動かせない) | 余剰が負なら構造的な不足で両売り手が毎日売り切る。**出荷日数 1([02c §1.3](02c-price-and-budget.md))では、能力どおり作って売り切る売り手の係数は需要の大きさによらない** — 自家消費しない品目(小麦粉・工具)は 1000‰ で提示価格が上がらず、不足分が天井で輸入される。自家消費する品目(パン・ビール・薪)は s/p ぶん上がり(冬の薪で 1.11 倍/日)、天井を超えると需要が窓口へ漏れる([issue #221](https://github.com/stama72/visionary/issues/221) / [#222](https://github.com/stama72/visionary/issues/222))。余剰が大きいほど全売り手が床に張り付きやすい(§4.5) |
| (b) | **輸入含有原価 < 外部買値**(§3.1) | 輸出のたびに貨幣が漏れる |
| (c) | **床価格で評価した各職業の世帯収支が 0 ± 生活費の 2%**(売上 − 仕入 − 摩耗 − 生活費。都市内価格をすべて外部買値と置いて計算する。許容幅は整数化の残差ぶんで、初期値では年 ±540 = ±4.5/日) | 大きく負の職業は、都市内価格が床から離れる再分配で補えず、④の職業付け替え([02b](02b-consumption-and-household.md))が構造的に発火する。**(c) を全職業で満たせば、§4.1 の恒等式により貿易収支は自動的に均衡する** |
| (d) | **初期資金 ≥ 必需の取り置き + 運転資金 + 嗜好の 1 日分**([02c §2.1](02c-price-and-budget.md)) | 初日から仕入が切り詰められるか、嗜好が初日から閉じて校正のビール需要が立たない |
| (e) | **レシピごとに、季節の最高値で評価した相場での原価 ≤ 許容原価合計**(床価格・最低利幅で評価。[02c §2.3](02c-price-and-budget.md))。利潤上限は相場基準に比例配分するので、「全入力について 利潤上限_j ≥ 相場基準_j」は「許容原価合計 ≥ Σ(相場基準_k × 必要数量_k)」1本と同値である | 穀物や木炭が季節で上がるたびに仕入が止まり、その職業が季節ごとに停止と再開を往復する。(a)〜(d) は現金の年平均収支しか見ないので、これを足さないと素通りする。**[GDD03 §2](03-seasons-and-city.md) が季節係数を置くときの制約でもある** |
| (f) | **都市生産品ごとに、外部買値 < 外部売値**(§3.2)。外部売値を `外部買値 × (1000 + 交易マージン‰)` で導き、**交易マージン‰ > 0 を検査する**(値の組ではなく導出の形で守る) | 窓口で買って窓口へ売り戻す無限の裁定ができる |

**天井((f) と §3)は (a)〜(e) の解を動かさない。** (c) は都市内価格をすべて外部買値と置いて解く方程式であり、**天井が効くのは価格が床を離れたときだけ**だからである。(e) だけは天井に依存する — 下の「(e) の非対称なケース」を参照。

**(c) は線形方程式である。** 生産量と消費量が定数なら、5職業の収支 = 0 は外部買値5つについての5元1次方程式であり、一意に解ける。**したがって校正の手順は「レシピの数量と生産能力を (a) で決め、外部買値を (c) から解き、整数に丸めて (b)〜(e) を検算する」で機械的に終わる。** 解が (b) を破るか負になるなら、(a) の数量を見直す。**丸めの残差が (c) の許容幅に収まらないときも数量側を動かす** — 薪のように単価が小さく数量が多い財は、床の整数化が収支に大きく効き(薪 10 と 11 で木材加工の収支が 30 動く)、丸め方では消せない。

> **(c) を「収支 > 0」ではなく「≈ 0」にするのは、§4.1 の帰結である。** 全職業を正にすると貿易は黒字になり、貨幣が単調に増える。定常状態の世帯は平均して収支ゼロであり、貯まる世帯と減る世帯の差は都市内価格の再分配で決まる。**それがプレイヤーの見る「儲かる職業・儲からない職業」である。**
>
> **機械で守れるのは (a) の非負条件・(b)・(c) の許容幅・(d)・(e) である。** `WorldDefinition` の初期値から定常状態の収支とレシピごとの許容原価を計算して検査するテストを置けば、値を動かした PR で落ちる。**守れないのは (a) の「1.2 倍前後」という狙いと、床に張り付いた売り手がどれだけ居るか(§4.5)である。** 前者は品目ごとに理由付きで外れる(薪・工具)ので検査にならず、後者は配置に依存するので実測([GDD02 §8](02-economy.md)-4)でしか分からない。実装は後続の impl issue が持つ。

### 4.4 校正表(初期値)

**レシピの数量は小さいまま、所要労働‰ で 1日の実行回数を作る。** 1日あたりの平均実行回数 = 労働力合計‰ ÷ 所要労働‰([02a §1](02a-production.md) の進捗‰ により切り下げない)なので、所要労働‰ を下げるほど 1日に多く実行する。**この形を採るのは、労働と入力の粒度を保つためである** — 徒弟(300‰)が抜ければ実行回数が減り、入力が端数しか無ければ端数ぶんだけ実行して残りは減速として現れる。1回の実行を大きくして 1実行/日に固定すると、生産能力は 0 か 1 になり、労働力不足の Need も入力不足による減速も表せない。**摩耗はこれに合わせて実行回数ではなく労働量(人日)に比例させる**([02a](02a-production.md))。実行回数で数えると職業間で 12 倍の差が出る。

- **床が需要の 1.5 倍で校正したときの約 2 倍になるのは、輸出量が減ったぶん同じ輸入を少ない輸出で賄うからである。** 生活費も 2 倍になるが、収支の構造は変わらない。**木材の外部売値を 8 でなく 9 にし、木材加工を 12 実行にしたのは、(c) の整数化の残差を ±1 に収めるためである**(8 と 11 実行では木材加工だけ −13 になり、薪を 11 に丸めても +16 で消えない)
- **工具が高いのは仕様である。** 需要が 1 個/日しか無いので、鍛冶が生活費を賄うには 1 個あたりの利幅が大きくなければならない。中世の工具が高価な耐久財だったことと整合する。摩耗の費用(約 29/日)は他の全職業に乗り、鍛冶の生活費を全員で分担する形になる
- **(d) の初期資金**: 運転資金はパン屋が最大で、小麦粉 6 × 緩衝日数 3 × 56 + 薪 6 × 3 × 10 = 1,188。必需の取り置きは冬の消費で パン 6 × 54 + 薪 56 × 10 = 884、嗜好の 1 日分 72 を足して 2,144。**2,400 を全世帯の初期値**とし、残り約 250 を緩衝にする。旧値の 200 ではどの職業も初日から切り詰めが起きる
- **入力の緩衝日数 D = 3**(目標在庫 = 1 日の投入量 × D。[02a](02a-production.md))。D は運転資金と価格・在庫の更新の速さと、外出の頻度(在庫が目標を下回る日の数)を決める。**D ∈ {2, 3, 5} の比較は実験で見る**([issue #93](https://github.com/stama72/visionary/issues/93))
- **すべて初期値であり調整対象**([GDD02 §9.2](02-economy.md))。ただし**動かすときは (a)〜(e) を検算し直す**。1つの値だけを動かせる構造にはなっていない

> **摩耗の N は 13 人日(工具 1 個が親方 1 人の 13 日ぶんの労働で尽きる)とする。** 全世帯が毎日 1.3 人日を投入するので、工具 1 個が 10 日もち、都市全体の需要が 1 個/日になる。旧値の「30 実行」では都市全体の工具需要が 3 日に 1 個で、鍛冶が 2 世帯居る意味が無かった。N は [02a](02a-production.md) の値だが、校正の入力なのでここで併せて決める。鍛冶も所要労働 1300‰ を 1 回/日 実行して 1.3 人日を投入するので、都市の工具需要は `(10 × 1.3) ÷ 13` = 1.0 個/日 である(鍛冶の所要労働が 1000‰ だった旧版は 0.95 個/日)。

> **[02c §1.3](02c-price-and-budget.md) の販売在庫の留保は、この校正を動かさない。** 鍛冶の摩耗は元から自分の工房在庫から引かれていて市場を経由しない。留保が変えるのは**鍛冶が手元に残す在庫の下限**だけで、市場に出る量は輸出が閾在庫まで調整する(§2.3)。**定常状態の販売在庫は留保の有無で同じである。** なお表の工具の需要 1 個/日 は鍛冶2戸ぶんを含む概数で、**市場を通る需要は `(8 × 1.3) ÷ 13` = 0.80 個/日**、都市の日産のうち市場に出るのは `2 − (2 × 1.3) ÷ 13` = 1.80 個/日 である。

### 4.5 床への張り付き(**予測**)

**余剰を持つ売り手の提示価格は、定常状態で床に張り付くと予測する。** 輸出の閾在庫は「係数項 = 床」となる在庫(§2.3)であり、翌朝はそこに日産が乗るので係数項は床を下回り、`max` で床になる。床を離れるのは、**朝の販売在庫が出荷目標在庫を下回る**とき(生産が能力を割った日と、自家消費する品目で前日の売れ残りが自家消費量に満たない日)と、他の売り手の高い提示を錨に取り込むときだけである。**自家消費しない品目(小麦粉・工具)は、地元の需要が日産を超えて売り切れても、能力どおり作っていれば係数は 1000‰ で床から離れない**(出荷日数 1。[02c §1.3](02c-price-and-budget.md) の代償)。これは開放小国の帰結そのものであり、輸出できる財の都市内価格は世界価格に釘付けされる。

- **床を離れるかどうかを決めるのは、都市集計の倍率ではなく区画ごとの需要の偏りである。** 需要が2売り手にほぼ均等に割れるなら、1.2 倍でも 1.1 倍でも両方が余剰を持ち、両方が床になる。倍率が決めるのは「売り切るのに要る偏りが +20% か +50% か」という閾値だけである
- **工具は構造的に床に張り付く。** 鍛冶 2 世帯 × 1 個/日 に対して需要 1 個/日で、倍率は 2.0 から動かない。区画間の価格差は工具には出ない
- **相場基準を持たない売り手も床に張り付く**([02c §1.2](02c-price-and-budget.md)。相手の売り手を保持期間内に観測していない配置)。これは余剰の錨ではなく盲目であり、倍率でも需要の偏りでも直らない。[GDD02 §8](02-economy.md)-1 はこの売り手日を床の除外から外し、メトリクスで割合を測る
- **これはシムを1回回せば観測できる。** 区画別の約定価格の中央値は [GDD02 §8](02-economy.md)-4 が測る量であり、予測が外れたときに直すのはこの節であって判定ではない。**判定の読み方(床の期間を硬直から除く、#4 は工具を除く4品目で測る、落ちたときの対処)は [GDD02 §8](02-economy.md) が決定として持つ**

## 5. 季節との接続(**決定**)

**本書が値を持つと二重管理になる。** 値は [GDD03 §2](03-seasons-and-city.md) が持ち、**本書は構造(どの価格・どの消費が季節に依存するか)だけを持つ。**

| 何が | 季節に依存するか | 値の所在 |
| ---- | ---------------- | -------- |
| 薪の家計消費 | **する**(冬に急増) | [GDD03 §2](03-seasons-and-city.md)。消費側は確定済み |
| 穀物の外部売値 | **する**(収穫直後が最安、次の収穫前が最高) | [GDD03 §2](03-seasons-and-city.md) |
| 木炭の外部売値 | **する**(炭焼きは農閑期の仕事。農繁期に細る) | [GDD03 §2](03-seasons-and-city.md) |
| 木材・鉄鉱石の外部売値 | **しない** | — |
| 都市生産品の外部買値 | **しない** | — |
| 都市生産品の**外部売値**(天井) | **しない**。外部買値から導く(§3)ので、外部買値が季節に依存しない以上こちらも動かない | — |
| 生産(レシピ) | **しない**。M0 に1次産品の生産者は居ないので、生産側に季節係数は掛からない。**季節性は都市外価格が担う** | — |

- **係数は千分率の整数で、年平均が 1000‰ になるように置く。** §4.4 の校正は年平均で成立させており、係数の年平均が 1000‰ から外れると貿易収支が構造的に黒字か赤字になる
- **年内で貨幣は振れる。** 冬は薪の需要が増えて薪の余剰が減り、輸出が減る。穀物が高い季節は輸入額が増える。**この振れは正常であり、[GDD02 §8](02-economy.md)-6 は年をまたいだ趨勢だけを見る**
- **都市生産品の外部買値に季節を掛けない。** 床が動くと提示価格の床([02c](02c-price-and-budget.md))が季節で動くことになり、区画間の価格差([GDD02 §8](02-economy.md)-4)に季節の成分が混じって切り分けられなくなる。**天井は床から導く(§3)ので、同じ理由で季節に動かない** — 冬の薪の輸入平価が上がるほうが交易としては自然だが、**床と天井が同時に季節で動くと、価格の帯そのものが季節で伸縮し、[issue #120](https://github.com/stama72/visionary/issues/120) の帯の検出器が何を測っているのか読めなくなる。** 季節を入れるなら帯の検出器を季節別に引き直すのが先であり、M0 では入れない

> **1次産品の季節性を「価格」として表すのは、M0 で供給側が抽象化されていることの帰結である。** 穀物が秋に安く春に高いなら、**次の収穫までの在庫繰りがゲームになる。保存と投機**は本作の商人像と非常に相性がよい。**供給量の季節変動として表す形は [GDD12](12-countryside-and-fairs.md) が持つ**(農村 NPC が季節に一度だけ売りに来る)。

> **v1.0 では、この窓口が [GDD11](11-external-trade.md) の港・行商人・貿易商に置き換わる。** 構造(外部価格帯が錨であり、輸出入が貨幣の出入りである)は同じで、**担い手が世界側の抽象から NPC へ変わる。** スプレッド(外部売値と外部買値の差)が都市内の貿易商の利益として残るのが、そのときの拡張である。
