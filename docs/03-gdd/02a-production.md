> **本書が持つのは「作る側」の規則である。** 日次の生産、労働力、設備(工具)と摩耗、生産の入力の目標在庫、原価と利潤の計測、そして生産量が価格に応答する将来の生産関数への接続点。品目とレシピの一覧は [GDD02 §2](02-economy.md)、入力を買う予算は [02c](02c-price-and-budget.md)、買う数量は [02b](02b-consumption-and-household.md) が持つ。
>
> **M0 では `生産量 = 生産能力` である。** 価格に応じて生産量を変える経路(雇用の増減・生産財への投資・家事や輸送の外部化)は生産関数の分冊([issue #92](https://github.com/stama72/visionary/issues/92))が持ち、本書は §6 でその接続点だけを固定する。

## 1. 日次の生産

各生産者は日次で、自分のレシピについて:

```
生産能力(実行回数)   = floor( floor(労働力合計‰ × 設備係数‰ ÷ 1000) ÷ 所要労働‰ )      §2・§3
入力から作れる回数   = min_j( floor( 工房在庫[入力j] ÷ 必要数量_j ) )
                       入力が0件のレシピ([GDD02 §2.3](02-economy.md))は、この項では制約しない
生産量(実行回数)     = min( 入力から作れる回数, 生産能力(実行回数) )

  工房在庫[入力j] −= 必要数量_j × 生産量
  工房在庫[出力o] += 出力数量_o × 生産量
  累積摩耗         += 所要労働‰ × 生産量                                          §3
```

- **入力が足りなければ、足りるぶんだけ実行する。** 生産は 0 か全量かではなく、**入力の端数まで減速する**。入力の在庫が細るほど実行回数が減り、出力の在庫が減り、出力の提示価格が上がる — 原材料の価格転嫁はこの減速を通って下流へ届く([02c §2.3](02c-price-and-budget.md))
- **生産量が 0 の日は停止であり、不足している入力について Need を生成する**([02b](02b-consumption-and-household.md) Need への接続。理由コード「生産停止」)。**一時的な停止は仕様である**([GDD02 §4](02-economy.md) 時間の摩擦)。常態化するかは [GDD02 §8](02-economy.md)-3 が見る
- **これらの除算はすべて切り下げる。** [GDD01 §2.3](01-trust-and-conversation.md) の全計算式切り上げの原則の**意図的な例外**である — 端数の労働力・端数の入力ではレシピを1回完成できないため、切り上げると存在しない労働力や入力で生産したことになる

## 2. 労働力(**決定**)

**労働は入力の一種として扱う。** レシピの `所要労働‰`(**レシピ1回の実行**に必要な労働力。1000‰ = 親方1人日相当)に対し、その工房に従事する世帯構成員の**労働力係数‰の合計**(労働力合計‰)が生産能力を決める。

> **「出力1単位あたり」ではなく「レシピ1回の実行あたり」である。** [GDD02 §2.3](02-economy.md) が複数出力を許すと決めているので、多出力レシピでは「出力1単位」が指すものが無い。単一出力でも同じで、木材加工(`木材1 → 薪3`)を出力1単位あたりと読むと生産能力1が薪1個を指すことになり、**木材 1/3 個**という存在しない入力を要求する。

**労働力係数‰(初期値)**:

| 階層 | 係数‰ | M0 |
| ---- | ----- | -- |
| 親方 | 1000 | **居る**(各世帯1) |
| 徒弟 | 300 | **居る**(各世帯1) |
| 職人 | 800 | 居ない([GDD10](10-employment.md)。職人は別世帯) |
| 主婦 | 300 | 居ない([GDD02 §2.4](02-economy.md)) |
| 子ども | 100 | 居ない |

```
労働力合計‰(当日) = max( 0 , Σ( 構成員の労働力係数‰ ) − 前日の外出の労働損失‰ )
外出の労働損失‰   = CeilDiv( 委託先の労働力係数‰ × 往復移動時間 , T )       T = 可処分時間 12(GDD08 §3.1)
                     その日の外出すべての合計(買い物 [GDD06 §3](06-trade-and-negotiation.md)、輸出 [02d §2.3](02d-external-market-and-money.md))。往復時間の合計は T が上限
```

**M0 の世帯の構成員の係数の合計は 1300‰ で固定である**(親方1000 + 徒弟300)。雇用が無いので構成員が増減せず、階層も変わらない。**そこから前日の外出で失った時間を引く** — 移動は時間を奪うので、貨幣ではなく労働で払う。買い物は生産(順1)より後(順5)に起きるので、引くのは翌日である。徒弟が往復4時間出れば 100‰ で、パン屋は 6 実行が 5 実行に落ちる。外出するかどうかは、その外出で得る余剰と費用の比較で世帯が決める([GDD06 §3](06-trade-and-negotiation.md))ので、労働損失は上限 T の範囲で日ごとに変わる。**M0 では家事・時間配分を分けて計算しない**([GDD08 §9](08-household-and-decision.md))ため、家業に振り向けられる時間の按分を行わず、**構成員全員の労働力係数‰をそのまま合算する。** 時間配分を入れる v1.0 では [GDD08 §4.2](08-household-and-decision.md) のとおり実際に家業へ充てた時間の比率を乗じる形に戻す。

**所要労働‰ は小さく置き、1日に複数回実行する。** 値は [02d §4.4](02d-external-market-and-money.md) の校正表が持つ(水車小屋番 185 / パン屋 216 / 醸造 216 / 木材加工 108 / 鍛冶 1000)。

| 労働力合計‰ | 水車小屋番 | パン屋 | 醸造 | 木材加工 | 鍛冶 |
| ----------- | ---------- | ------ | ---- | -------- | ---- |
| 1300(親方 + 徒弟) | 7 | 6 | 6 | 12 | 1 |
| 1200(前日に徒弟が往復4時間) | 6 | 5 | 5 | 11 | 1 |
| 1000(親方だけ) | 5 | 4 | 4 | 9 | 1 |
| 650(工具なし、§3) | 3 | 3 | 3 | 6 | 0 |

> **1回の実行を大きくして 1実行/日に張り付かせる形は採らない。** 生産能力が 0 か 1 になり、徒弟が居ても居なくても同じ出力になって労働力の階層が意味を失い、入力が1回分に満たない日は全停止して §1 の減速が表せない。**労働と入力の粒度を保つために、回数で規模を作る。**

**これにより [GDD08 §4.2](08-household-and-decision.md)「1時間あたり出力」の式は M0 では使わない。** あの式はレシピに無い `標準出力/時間` を要求し、かつ時間配分(M0 では入れない)を前提にしている。GDD08 §4.2 は熟練度・時間配分を入れる v1.0 のための式として残し、**M0 の生産量は §1 の式が正**とする。

「労働力不足」は [GDD01 §3.2](01-trust-and-conversation.md) の Need 種別として、**労働力合計‰ × 設備係数‰ ÷ 1000 が所要労働‰ に満たない**場合に発生する。**M0 の初期値では鍛冶にだけ起きる。経路は2つある。**

| 経路 | 条件 | 扱い |
| ---- | ---- | ---- |
| 工具切れ | 設備係数‰ が 500 に落ちる(上表の 0) | [02c §1.3](02c-price-and-budget.md) の留保が塞ぐ。通常の走行では発火しない |
| 外出の労働損失 | 前日の外出損失‰ が **300 を超え**、労働力合計‰ が 1000 を割る | **仕様として残す。** 鍛冶の能力はちょうど 1 回/日 なので、この境界の上に座っている |

> **外出の側は塞がない。** 翌日には労働力合計‰ が 1300 へ戻るので停止は1日で終わり、詰みにならない([GDD02 §4.2](02-economy.md))。塞ごうとすると設備係数‰ か所要労働‰ を動かすことになり、§3 が採らないと決めた2案に戻る。**一時的な停止は仕様である**([GDD02 §4](02-economy.md))。

## 3. 設備 — 工具と摩耗(**決定**)

**工具は生産の必要条件ではなく、生産性を上げる財である。** 稼働可能な工具が1個以上あれば設備係数‰ は 1000、無ければ **500**(初期値)。

```
設備係数‰ = 工具在庫 ≥ 1 ? 1000 : 500
```

**工具が無くても生産が続くのは、生産能力が 2 以上ある職業だけである。** 二値の設備係数と §1 の切り下げでは、能力 1 の職業の「半分」は 0 にしかならない。

```
工具なしでも能力 ≥ 1 である条件 = 労働力合計‰ × 設備係数‰ ≥ 所要労働‰ × 1000
M0 の初期値(労働力合計 1300‰、設備係数 500‰)では   所要労働‰ ≤ 650
```

**M0 でこれを満たさないのは鍛冶(所要労働 1000‰)だけであり、鍛冶は工具を失うと生産能力が 0 になる。** §2 の表の「650(工具なし)」の行で鍛冶だけが 0 なのはこのためである。**設備係数‰ を 770 以上へ上げれば鍛冶も 1 を保つが、そのとき鍛冶の能力は工具あり 1・工具なし 1 で、工具の価値が消える。所要労働‰ を 650 以下へ下げれば半減は素直に成立するが、工具ありの能力が 2 以上になり [02d §4.4](02d-external-market-and-money.md) の校正が解き直しになる。どちらも採らない。**

**鍛冶が工具を失う経路そのものは [02c §1.3](02c-price-and-budget.md) の留保が塞ぐ。** 鍛冶の出力である工具は、上の判定が見る在庫と**同じ欄**である。留保が無ければ鍛冶は自分の設備を売り注文に出し、売り切った翌日から能力が 0 になって復帰しない。**詰みを作らない**([GDD02 §4.2](02-economy.md))のを担保しているのはその留保であって、設備係数の 500‰ ではない。

- **旧版は工具が無ければ 0(生産停止)としていた。** それは「工具を買えない鍛冶が工具の供給を止め、設備係数がやがて全工房で 0 に落ちる」自己参照の詰みを作っていた。500 なら、**能力が 2 以上ある4職については**詰まない — 工具が尽きた工房は収入が半減し、必需の予算が細って困窮へ向かうが、その経路は生産性低下 → 収入減 → 困窮という自然なものである。**鍛冶だけは半減が 0 になるので、この段落は鍛冶に対しては成り立たない**(上記)
- **2段階に留めるのは、摩耗度に比例して連続的に下がる形が調整軸を増やすからである**(方針2 観測可能性)。連続化は生産関数の分冊([issue #92](https://github.com/stama72/visionary/issues/92))が「生産財への資本投下」として扱う
- **工具の購入は必需の次に決済する**([02b](02b-consumption-and-household.md) の走査順)。10 日に 1 個の安い支出で入力の効率が倍になるので、入力より先に払う

### 3.1 摩耗は労働量に比例する

**摩耗を入れる。ただし確率ではなく決定的に。** 乱数を増やさないぶん因果が追える。

```
累積摩耗(‰人日) += 所要労働‰ × 生産量(実行回数)        毎日、§1 の生産のあとに
累積摩耗 ≥ N × 1000 のあいだ:
    工具在庫 −= 1
    累積摩耗 −= N × 1000                                   端数は次の工具へ持ち越す
工具在庫が 0 なら累積摩耗を 0 に戻す                       尽きたときに残った摩耗は捨てる

N = 13(人日。初期値)。工具1個は親方1人が 13 日働くぶんの労働で尽きる
```

- **実行回数ではなく労働量で数える。** 所要労働‰ が職業で 108 から 1000 まで違うので、実行回数で数えると木材加工は鍛冶の 12 倍の速さで工具を消費する。労働量なら、毎日 1300‰ 近くを投入する工房はどれも 10 日に 1 個で揃う(鍛冶は 1000‰ しか投入しないので 13 日)。**都市全体の工具需要が 1 個/日になり、[02d §4.4](02d-external-market-and-money.md) の校正がこれに立っている**
- **端数を次の工具へ持ち越す。** 日ごとに端数を捨てると、投入が N × 1000 に届かない日が続く工房の工具が永久に減らない
- **工具が尽きたときに残った摩耗は捨てる。** 繰り越すと、次に買った工具が買ったその日に壊れうる([02b](02b-consumption-and-household.md) の消費の規則と同じ扱い)
- **摩耗の累積は在庫から復元できないので、世帯の状態として持つ。** `耐久値 = 工具在庫 × N × 1000 − 累積摩耗`(‰人日)が [02b](02b-consumption-and-household.md) の言う耐久財の在庫であり、耐久の目標在庫はこの導出値を見る

> **摩耗する耐久財を工具のみに限っている**のは意図的なスコープ制約である。農具・ツルハシ・厨房設備なども同型に扱えるが、品目と調整軸が増える([GDD02 §9](02-economy.md))。

## 4. 生産の入力 — 目標在庫と仕入れ(**決定**)

**生産の入力の目標在庫は「1日の投入量 × 緩衝日数 D」とし、1日の投入量は生産能力(工具あり)から定める。**

```
1日の投入量_j = 生産能力(実行回数。労働力は構成員の係数‰の合計(§2)、設備係数は 1000‰ で評価) × 必要数量_j
目標在庫_j    = 1日の投入量_j × D          D = 3(日。初期値)
```

- **実際の実行回数からではなく生産能力から定める。** 実績で定めると、入力が尽きた日は投入量が 0 になり、目標在庫も 0 になって「もう要らない」と判定され、恒久停止する。生産能力は労働力と設備から決まるので、停止中の工房でも「まだ目標に届いていない」と正しく判定される。**設備係数は 1000‰ で評価する** — 工具が無い日に目標在庫まで半減させると、工具を買い戻して能力が戻った日に入力が足りない。**労働力も外出の労働損失(§2)を引く前の値で評価する** — 損失は日ごとに動くので、引くと目標在庫という物差しが外出のたびに揺れる
- **生産量が可変になる v1.0 では、生産能力を計画生産量に置き換える。下限は 1 回分である**(0 に落とすと同じ恒久停止が戻る)
- **D は「仕入れ間隔」ではない。** 買い物は在庫が目標を下回った日に毎日起きる([02b](02b-consumption-and-household.md) の線形解が目標まで買い戻す)ので、D が決めるのは訪問の頻度ではなく**緩衝の厚さ**である。運転資金([02c §2.1](02c-price-and-budget.md))は D に比例し、価格と在庫の更新は D が小さいほど速い。**D ∈ {2, 3, 5} の比較は [issue #93](https://github.com/stama72/visionary/issues/93)**
- **買った入力は工房在庫へ入る。** 薪はパン屋にとって生産の入力であると同時に家庭の必需でもあり、在庫は2本に分かれる([GDD08 §2.2](08-household-and-decision.md) / [TDD01 §3.2](../04-tdd/01-sim-core-and-m0.md))。走査の単位が(用途, 品目)の組である以上、行き先も用途で決まる — 品目だけで振り分けると、暖房用に買った薪が工房在庫に入り、生産用の薪の在庫圧力が下がって仕入が止まる
- **仕入の予算は [02c §2](02c-price-and-budget.md)、数量は [02b](02b-consumption-and-household.md) の線形解による。** 入力にだけ利潤上限があり、相場で作って利幅が残らない日は相場より安くしか買わない。**それが §1 の減速を起こし、価格転嫁の経路になる**

## 5. 原価と利潤の計測(**決定**)

**原価は提示価格に使わない**([02c §1](02c-price-and-budget.md)。床は外部買値)。**残る使い道は利潤の計測であり、利潤の側の判断([GDD02 §5](02-economy.md))が参照する。**

```
原価[レシピ1回]   = Σ_j( 仕入れ移動平均単価_j × 必要数量_j ) + 摩耗費[1回]
摩耗費[1回]       = CeilDiv( 仕入れ移動平均単価[工具] × 所要労働‰ , N × 1000 )
原価[出力1単位]   = CeilDiv( 原価[レシピ1回] , 出力数量 )
日次の利潤        = Σ( 約定単価 × 約定数量 ) − 原価[レシピ1回] × 生産量
```

- **摩耗費を原価に含める。** 現金側には工具を買った日にだけ現れるが、利潤側では1回の実行ごとに費用が立つ。含めないと、工具代を回収できない値付けが「利益が出ている」と判定される([GDD02 §5](02-economy.md) 帰結3)。[02c §2.3](02c-price-and-budget.md) の利潤上限はこの摩耗費を許容原価から先に引く
- **出力1単位あたりの原価の除算は切り上げる。** 切り上げても利潤が小さく出る方向にしか効かず、保守的である
- **財の投入が無い職業**(M0 には無い。[GDD11](11-external-trade.md) の貿易商・[GDD12](12-countryside-and-fairs.md) の農村職業)の原価は投入した労働の機会費用 `ApplyPermille(機会費用_親方(1時間あたり) × 可処分時間T, 所要労働‰)` とする。旧版はこの分岐を「原価 0 が提示価格を 0 に固定する」問題の回避のために置いていたが、床が外部買値になったのでその問題は無い。**利潤の計測を分冊間で割らないために残す**

### 5.1 仕入れ移動平均単価の更新

**約定のたびに、その品目の仕入れ移動平均単価を再帰形(指数移動平均)で更新する。**

```
新しい移動平均 = CeilDiv( 旧移動平均 × (1000 − 平滑化係数‰) + 約定単価 × 平滑化係数‰ , 1000 )
```

- **更新するのは「生産の入力として買った」約定と、耐久として買った工具だけである。** 必需・嗜好で買った分は混ぜない — 原価は工房が投入した財の値であって、世帯が食べたパンや暖房に焚いた薪の値ではない。品目だけで振り分けると、暖房用に高値で買った薪が焼成の原価に乗る
- **窓付き(直近 N 件の平均)を採らない。** 窓は「品目ごとの直近 N 件」という履歴を世帯の状態として持つことになり、決定論ハッシュ([TDD01 §3.8](../04-tdd/01-sim-core-and-m0.md))の対象が件数ぶん増える。**再帰形なら既存の1欄を上書きするだけで済み、調整軸も平滑化係数‰ の1つで足りる**
- **丸めは最後に1回だけ掛ける。** 2項をそれぞれ `ApplyPermille` で丸めてから足すと両方が切り上がり、価格が動いていない日でも移動平均が1ずつ上がり続ける
- **約定数量で重みを付けない。** 数量で重み付けすると「在庫も数量も 0 の日に分母が消える」枝が新たに要るうえ、平滑化係数‰ の意味が仕入頻度に依存して読めなくなる
- **初期値は初期在庫の取得原価である。** 初日は標本が無いので、これが無いと原価が 0 から始まる

> **原価が価格の経路から外れたので、この移動平均の精度は価格の安定に効かない。** 効くのは利潤上限の摩耗費([02c §2.3](02c-price-and-budget.md))と、プレイヤーが見る「この工房は儲かっているか」だけである。

## 6. 生産関数への接続

**M0 の生産量は §1 の `min(入力, 生産能力)` で決まり、価格に応答するのは入力の仕入(§4)だけである。** 生産能力そのものが価格に応答する経路は 3 本あり、いずれも本書の外である。

| 経路 | 動く量 | 持つ分冊 |
| ---- | ------ | -------- |
| 雇用の増減 | 労働力合計‰(§2) | [GDD10](10-employment.md) |
| 生産財への資本投下(工具の追加・更新) | 設備係数‰(§3。2段階から連続へ) | 生産関数([issue #92](https://github.com/stama72/visionary/issues/92)) |
| 機会費用による家事・輸送の外部化 | 家業へ充てる時間の比率([GDD08 §4.2](08-household-and-decision.md)) | [GDD08](08-household-and-decision.md) / 生産関数 |

**本書が固定する接続点は §1 の式である。** 3 本の経路はいずれも `労働力合計‰`・`設備係数‰`・`所要労働‰` のどれかを動かす形で入り、§1 の式そのものは変えない。**仕入れは生産量に追随する** — §4 の目標在庫が計画生産量から定まる形になれば、入力の側に別の規則は要らない。
