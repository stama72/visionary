## 却下した設計案(フェーズ1)

- **購入量 0 の理由を min の argmin で決める** — 採らない。相場項と現金上限がともに実効価格を下回る日に argmin を採ると、**金が無限にあっても相場項で買わなかった世帯が「資金不足」に数えられる**。[GDD02b §3.2](../03-gdd/02b-consumption-and-household.md) が名指しした「破産中フラグが価格ショックの検出器に化ける」経路そのものである。固定順(相場 → 利潤上限 → 現金上限)で最初に当たったものを採り、同点は相場に倒す。**この理由は #39 がフラグを実際に読むようになっても変わらない** — むしろ読み手が付いた時点で初めて影響が出る。

- **`OfferPrice.UnitCost` / `CostFloor` を「いつか使う」として残す** — 採らない。残る `UnitCost` は [GDD02a §5](../03-gdd/02a-production.md) の現行の `原価[レシピ1回]` と**違う式**(摩耗費を含まない)であり、原価を最初に読む #41 がそれを正だと思って使う。**読み手が居ない古い式は、器ではなく罠である。** #41 が読み手と一緒に 02a §5 の式で書く。

- **段5 に `store.UnitRealCost` を残したまま #98 を待つ** — 採らない。新しい予算は移動費を一切含まない([GDD02b §7](../03-gdd/02b-consumption-and-household.md))ので、移動費を割り戻した単価をぶつけると**空間の摩擦が二重計上**になる。#98 の範囲は「店の選び方」であって「選んだ後の判定」ではない。**この分離を先にやっておくと、#98 は `StoreChoice` だけを触れば済む。**

- **買い手用の相場基準を `OfferPrice.TryMarketReference` の引数(`hasOwnPreviousPrice: false`)で兼ねる** — 採らない。現行はそれで動いていたが、**買い手は「売り手ごとに最新 1 件」ではなく「全観測の平均」に変わった**ので、畳み方そのものが違う。引数で分岐させると、有効性の判定(保持期間・当日の除外・自分の除外)と畳み方が 1 つの関数に混ざり、**片方の速さだけを変えたときに [GDD02c §1.2](../03-gdd/02c-price-and-budget.md) の天井が黙って消える。** `MarketReference` へ出して、共通の判定を `private` に 1 つだけ置く。

- **`NoPurchaseReason` を `HouseholdState` の欄にする** — 採らない。読み手は同じ手順の中の `UnaffordableNecessityCount` の加算だけで、日をまたいで読む者が居ない。[TDD01 §3.2](../04-tdd/01-sim-core-and-m0.md) の「使わない状態を器に残さない」に当たる。

## 停止の理由 — `SPEC-OUTSIDE`(フェーズ1 へ差し戻し)

**タスク仕様に穴がある。** [GDD02a §5.1](../03-gdd/02a-production.md) は「更新するのは『生産の入力として買った』約定**と、耐久として買った工具**だけである」と要求しているが、`TradeSettlement` は `DemandPurpose.ProductionInput` しか更新しない。タスク仕様は `TradeSettlement` を「作るもの」に挙げておらず、それどころか「`UpdatedAcquisitionCost` は残す。呼び出し側(`TradeSettlement`)が生きており、本タスクの利潤上限が摩耗費の材料として読む」と書いて**材料は取れていると読ませている**。

**規則は #85 の中で反転している**(履歴を引かないと見えない):

| コミット | 規則 |
| -------- | ---- |
| `13e274a`(#85 #88) | 「生産の入力として買った約定**だけ**。必需・嗜好・**耐久**で買った分は混ぜない」 |
| `50cf648`(#85 #89、現行) | 「生産の入力として買った約定**と、耐久として買った工具だけ**」 |

つまり現行の `TradeSettlement` は**一世代前の仕様の正確な実装**である。放置すると摩耗費が初期値に固定され、利潤上限が工具価格に応答しなくなる([GDD02c §2.3](../03-gdd/02c-price-and-budget.md) の歯止めが効かない)。
