## 却下した設計案(フェーズ1)

- **検出器に自動テスト(fixture コーパス + ランナー)を新設する** — 採らない。fixture を `src/` `tests/` に置くと**検出器自身の走査対象に入って件数を汚す**。外へ置くには「走査対象を差し替える引数」を足すことになり、**CI 外の、手で叩く道具に契約の面を1つ増やす**。対象は awk 数十行である。**失う保護**: フェンス対応と一覧の回帰は、以後 `mutator` を明示的に回さない限り誰も測らない(今回の M-1〜M-3 が唯一の実測になる)
- **集計行に `RESOLVED <K>` を足して「0 件が保証する範囲」を自動で数えられるようにする** — 採らない。#117 が決めた契約の変更は**UNRESOLVED の一覧化だけ**で、集計行の形を変えると `2>&1 | tail -1` で集計を取る使い方が同時に動く。**失う保護**: 保証範囲の件数(1020)は手で数え直す必要が残る — **数え方のコマンドを冒頭コメント(4.(f))に書いて補った**
- **一覧で「引き継ぎ打ち切り」由来(`タスク仕様` / `ADR-` / `#<数字>`)に別のタグを付ける** — 採らない。#117 の前提どおり**一覧は人が追うための材料**であり、分類の誤りが機械の顔をして出るほうが高い。**失う保護**: 66 件を読む人は、GDD/TDD の節でないものを自分で見分ける必要がある
- **字下げされたフェンス記号もフェンスと見る**(CommonMark の 3 スペースまでを含む) — 採らない。**本物の見出しを飲み込むと STALE の偽陽性になる**。0 件を要求する検査に偽陽性が混じると「0 でなくてよい検査」に変わる(W2-09 の判断)。**失う保護**: 列0 以外で開いたフェンスの中に列0 の見出しがあると、いまも幻の節を作れる — **穴6 に残ると明記させた**

> **裸の `§` 48 件の書き換え**と**枝番 `-N` の照合**も採らないが、これは #117 決定1-1 と #118 決定1-2 が理由ごと持っている。issue に残るのでここには書かない。
