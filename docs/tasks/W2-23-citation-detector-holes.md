## 作るもの

### 1. UNRESOLVED の一覧化(#117 決定1-1)

**いまは件数しか出ないので、69 件の中身が監査できない。** 振り直しのときに人が読む材料を出す。

#### 新しい入出力の契約

```
$ bash scripts/check-doc-citations.sh
<STALE の行。標準出力。形式・順序ともに変更なし>
UNRESOLVED<TAB>src/Visionary.Sim/Determinism/StateHasher.cs:123<TAB>§3.8   ← 標準エラー
UNRESOLVED<TAB>src/Visionary.Sim/Determinism/StateHasher.cs:123<TAB>§3.3   ← 同一行の2件目
...
STALE 0 / UNRESOLVED 66                                                    ← 標準エラー。最後の1行
$ echo $?
0
```

- **1件1行。** 行頭は固定文字列 `UNRESOLVED`、以下タブ区切りで `path:line`、`§<番号>`
- **順序は標準出力と同じ規則**(path:line 昇順。同一行に複数あれば左から右)。走査順がそのまま昇順になる(`find … | sort`)ので、**並べ替えの処理を足さない**
- **集計行は最後の1行のまま。** 形式 `STALE <N> / UNRESOLVED <M>` も変えない — `2>&1 | tail -1` で集計を取る使い方を壊さない
- **一覧の行数は必ず `<M>` に一致する**(確認 #2)
- **標準出力と終了コードは変えない。** UNRESOLVED は終了コードに影響しない
- **引き継ぎが打ち切られたもの**(`タスク仕様` / `ADR-` / `#<数字>` が間に現れた形)**も同じ一覧に入れる。区別のタグは作らない** — GDD/TDD の節かどうかの判断は、人が file:line を開いて行う(**決定: フェーズ1**。タグを増やすと契約の面が増え、分類の誤りが機械の顔をして出る)

**実測(bc60efe)**: UNRESOLVED 69 件(うち打ち切り由来は `M0CalibrationTests.cs:9` の1件)。**本タスクの3件の書き換え後は 66 件になる**(下記 3.)。

### 2. 見出し収集のコードフェンス対応(#118 決定1-3 = 残る穴6)

**対象は見出し収集の awk(スクリプトの「1.」のブロック)だけである。** 引用側の走査(「2.」)は触らない。

- **フェンスの開始**: **列0** から始まる `` ``` ``(バッククォート3つ以上)または `~~~`(チルダ3つ以上)の行。開始行の**文字種と個数を覚える**
- **フェンスの終了**: **列0** から始まり、**開始と同じ文字種**で、**個数が開始以上**で、**その後ろが空白以外を含まない**行。情報文字列の付く行(`` ```jsonc ``)は終了として扱わない
- **フェンスの中の行は見出しとして採らない。** 中に現れた別の文字種のフェンス記号も無視する(`~~~` の中の `` ``` `` で閉じない)
- **閉じないままファイルが終わったら、そこまでが中**(CommonMark と同じ)。**状態はファイルごとにリセットする**(見出し収集はファイルごとに awk を起動しているので自然にそうなる。まとめて1回にしない)
- **列0 以外で始まるフェンス記号はフェンスと見ない。** 理由 — 見出しの収集は `^#{2,6}` すなわち**列0 の行しか採らない**ので、字下げされたフェンスが隠せる見出しは事実上無い。逆に字下げされた `` ``` ``(コード例の中に書かれたマークダウンなど)をフェンスと見ると、**そこから後の本物の見出しを飲み込み、STALE の偽陽性を大量に作る**。**偽陽性のほうが有害である**(W2-09 の判断。0 件を要求する検査に1件でも偽陽性が混じると「0 でなくてよい検査」に変わる)。**残る穴として冒頭コメントに書く**(下記 4.(e))

**実測(bc60efe)**: GDD / TDD のフェンスは **13 ファイル・78 ブロック**で、**開始・終了とも全て列0**。`~~~` は **0 件**。フェンス内の `^#{2,6}[ \t]+[0-9]` は **0 件**。**したがって本変更で見出し集合は変わらず、STALE / UNRESOLVED の件数も動かない**(確認 #1)。**検出力は fixture を当てて測る**(核心 M-1)。

```
