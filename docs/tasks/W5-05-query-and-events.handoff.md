# W5-05 引き継ぎメモ

**この文書は PR 説明へ転記して削除する。**

## 却下した設計案(フェーズ1)

- **`Query` が全 Need を返す** — 開示されない理由(困窮など)が描画側へ漏れ、GDD01 §6.1 の「会話で開示する」が描画の自制だけで守られる形になる。代償: #264 は開示されない Need の件数を `Query` から測れない(要るなら `World` を読むテスト側で測る)
- **`Query` が居合わせた世帯の Need だけを返す** — `AskNeeds` と重なり、#264 が全世帯の件数と持続を測れない。代償: 描画が聞く前の Need を出せてしまう(#47 が自制する)
- **`DrainEvents` が `EventLog` を消す** — 追記専用(TDD01 §3.4)に反し、2つ目の読み手(例: `events.jsonl`)が取れなくなる。代償: `EventLog` は走行中ずっと伸びる。M0 はプレイヤーの売買だけなので件数は小さい
- **台本に `SimHost` をそのまま渡す** — 台本が `Advance` を呼べると、Godot の「ポンプするだけ」と別の時間の流れ方を測ることになる。代償: 台本は待ちを「何もしない時刻」で表すしかない
- **窓口との売買をイベントから外す** — 帳簿に残らない売買を辿れる場所が無くなる(TDD01 §3.2)
- **`DomainEvent` を `KindCode` の struct のまま使う** — 感謝の段階・Need の Id など判定の文脈を持てない(TDD01 §3.6 の仮決め表)
