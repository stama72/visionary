  **代償: 呼び出し側が `trust: 0` の定数を 2 か所(段5a・段5b)に持つ。** 式は #5 が踏むが、**「呼び出し側が 0 以外を渡したときに何が起きるか」はどのテストも踏まない。** #44 は 2 か所とも直す必要があり、片方だけ直しても緑のまま通る。

## `SPEC-OUTSIDE` の内容(フェーズ2 の自己申告)

**[GDD06 §3](../03-gdd/06-trade-and-negotiation.md) の「外出 d の価値」の式が、同じ節の散文と食い違っている。散文が意図で、式が誤りである。**

### 現行の式(GDD06 §3、コードブロック内)

```
外出 d の価値 = Σ_i( 余剰_i(d の最安店) − 余剰_i(既に居る区画の最安店) ) − 外出の費用(d)
                 既に居る区画に店の無い品目は第2項を 0 とする
```

**候補側(第1項)が `{d}` 単独である。**

### なぜ 2 区画目が立たないか

1 周目が全候補中の argmax として区画 X を選んだとする。任意の Y について `価値₁(X) ≥ 価値₁(Y)`、すなわち

```
Σ余剰({Y}) − Σ余剰({X}) ≤ Cost(Y) − Cost(X)
```

2 周目で Y を評価するとき、baseline は `{自区画} ∪ {X}` に広がっており、最安を取る集合が広がるので価格は下がり **`余剰(i, {自区画,X}) ≥ 余剰(i, {X})`**。したがって

```
価値₂(Y) = Σ余剰({Y}) − Σ余剰({自区画,X}) − Cost(Y)
        ≤ Σ余剰({Y}) − Σ余剰({X})       − Cost(Y)
        ≤ ( Cost(Y) − Cost(X) )          − Cost(Y)   =  −Cost(X)  ≤ 0
```

**`Cost(X) > 0` なら厳密に負。** 品目構成にも距離にも価格にも依存しない。

### 節の中の他の記述はすべて複数回の外出を前提にしている

| 行 | 記述 |
| -- | ---- |
| §3 冒頭 | 「行く価値のある区画が2つあれば**2回行き**」 |
| §3 貪欲 | 「往復移動時間の**合計**が T を超える外出はしない」(1 回なら上限は無意味) |
| §3 論点「既に居る区画の店との差で数える」 | 「1回目で最安になった品目は**差が 0 になって**自動的に落ち、かつ**もっと安い3つ目の区画があればその差だけは残る**」 |
| §3 論点「労働損失は外出ごとに切り上げ」 | 「`Σ_d CeilDiv(…)`」「**2回に分けたほうが損失が大きくなる**」 |
| [GDD02a §2](../03-gdd/02a-production.md) | 「その日の外出**すべての**合計」 |

**とりわけ「差が 0 になって落ちる」は、現行の式では成り立たない。** d にその品目の店が無ければ第1項が 0 になり、差は 0 ではなく**負**(baseline の余剰ぶん丸ごと)になる。

### 訂正案(フェーズ1 が判断すること)

**候補側も baseline を含んだ集合にする。**

```
既に居る区画 = { 自区画 } ∪ { ここまでに行くと決めた区画 }
外出 d の価値 = Σ_i( 余剰_i( (既に居る区画 ∪ {d}) の最安店 ) − 余剰_i( 既に居る区画の最安店 ) ) − 外出の費用(d)
```

これで散文の 2 つの主張が両方そのまま成立する。「d が高ければ差 0」「3つ目がもっと安ければその差だけ残る」。現行の式の 2 行目(「既に居る区画に店の無い品目は第2項を 0 とする」)は不要になって吸収される。

**1 回目の外出では観測できない誤りである。** 1 回目は差が負でも「価値 ≤ 0 なら行かない」に吸収されるため、結果が一致する。2 区画目で初めて表面化する。
