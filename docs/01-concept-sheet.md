## ハイコンセプト(1文)

**中世都市に暮らす、ひとりの商人のリアリティ。**
生きた都市で、生きた暮らしができるゲーム。中近世の都市を自分の足で歩き、人々のニーズを見つけて商いをし、信用を元手に、生きた経済の中で一介の行商人から都市を動かす豪商へ成り上がる。

※マーケティングの第一声(フック)は「**相場表のない経済シム。情報は足で稼げ**」を用いる。アイデンティティとフックの二層構成([検討資料02a](02a-identity-and-positioning.md)で決定)。

## ジャンル / プラットフォーム / 価格帯

- ジャンル:商人ライフシム × エージェントベース経済シミュレーション
- 視点:2Dトップダウン(主人公目線で街を歩く。俯瞰マップ・神視点UIを持たない)
- プラットフォーム:PC(Steam)。**早期アクセスで開始**し1.0を目指す / 想定価格:EA 1,400〜1,800円、1.0で改定余地
- グラフィック:ピクセルアート(既存アセット+AI生成を活用し、独自制作は最小限)

## ターゲット

- 一次:経済・経営シム好きのコアPCゲーマー(Moonlighter、Potion Craft、大航海時代、Anno系のプレイヤー)
- 二次:生活シム・スローライフ系プレイヤー(Stardew Valley層)のうち、経営要素に惹かれる層

## 最小構成要素

> **困りごとを取引で解決し、感謝される。**

ゲームとしては取引、プレイ体験としてはニーズを聞き出して満たし、感謝される会話である。**取引と会話だけで完結し、信用を要らない。** これが楽しくなければ、何を足しても失敗する。

最小構成要素は、[世界観設定書 §1.1](02b-world-setting.md) の b(成長)と c(絆)の交点を取引1件の粒度まで縮めたものである。02b は b × c を「差別化を生む」組み合わせと書いている。下のコアループの「信用を築く・広げる」は、この最小のゲームを**繰り返しゲーム**へ発展させる要素であり、M1 で入れる。

### やること・やらないこと

- **やること: 人と人、需要と供給をつなぐ。**
- **やらないこと: プレイヤー自身による生産。** 工房も畑も持たない
- これを貫く限り、ライフシム側の要素(友好度・プレゼント・季節行事・納品)も、ハンザ都市の要素(告解・救貧・海外貿易・ギルド・参事会)も、「つなぐ」行為の相手や場として入り、芯が崩れない

**フェッチクエストを正面から面白くする。** プレイヤーが提示すれば通常の取引になり、NPC が提示すればニーズというクエストになる。どちらも「誰かから手に入れて、誰かに渡す」ことで果たし、それを生きた経済と生きたコミュニティが支える。

### 業態の拡大ルート

**行商人(零細小売り)→ 店舗(小売り・卸売り)→ 大商会(小売り・卸売り・貿易・金融・不動産)。** 生産職にはならない。

## コアループ

商売の本質を「相場差で儲けること」ではなく「**人々のニーズを発見し、満たすこと**」と定義する。ニーズは手書きのクエストではなく、シミュレーションの状態(在庫不足、病気、行事、天候…)から発生し、会話を通じて「人の困りごと」としてプレイヤーに開示される。

1. **歩く・聞く**:街を歩き、NPCと会話して情報とニーズを発見する(困りごと、需要、相場、噂、人間関係)
2. **商う**:発見したニーズを満たす。仕入れ・販売・価格交渉・約束の履行。利益は結果としてついてくる
3. **信用を築く・広げる**:傾聴と約束の履行がNPC個人からの信用を高める。利益と信用を従業員・店舗・大口の信任(ギルド/参事会/教会)へ再投資する(M1 から)
4. **変わる**:経済と都市が変化し(価格、街並み、NPCの暮らし)、新たなニーズと機会が生まれる → 1へ

## USP(差別化点)

1. **情報を足で稼ぐことがゲームプレイになる**
   経済シムの定番である全知の相場表を捨てる。プレイヤーが知っている価格は「実際に見聞きした価格」だけ。情報の非対称性がUIの制約ではなく、体験の中心になる。
2. **NPCは台本ではなく、経済合理性+社会規範で動く**
   各NPCは欲求・予算・価値観パラメータを持つ自律エージェント。プレイヤーの買い占めが価格を動かし、NPCの生活を変え、街の姿に波及する。
3. **信用が資本になる**
   会話・傾聴・約束の履行がNPC個人からの信用を築く。信用は取引相手の選好、交渉価格の幅、掛け売りの可否、情報開示の深さに効く。「商いは信用で回る」という中近世商業の実像を、メカニクスとして再現する。
4. **マップ=社会実験**
   マップごとに時代・地域・支配的な倫理観(蓄財肯定 / 喜捨規範 / ギルド統制など)を設定。同じシステムの上で「違う社会」が創発するのを遊び比べられる。

## スコープ

段階ごとの中身と Exit Criteria は [企画書 §6](02-project-proposal.md) が持つ。本節は EA 時点で何があるかと、1.0 までの規模の上限だけを書く。

### EA 時点のスコープ

- 事業:**行商人 → 自分の店と従業員**(従業員の仕事は店番のみ)
- 中身:企画書 §6 の M0・M1・M2〜EA の行
- プレイ時間:完成した5〜10時間([企画書 §5.3](02-project-proposal.md))

### 規模の上限(1.0 まで)

- マップ:**1都市**(時代テーマ1つ)
- 品目:10〜20種 / NPC:50〜100体
- プレイ時間:10〜20時間
- EA 後のアップデート(企画書 §6 の 1.4〜1.8)のどこまでを 1.0 に含めるかは M2 で決める
- 追加マップ(別時代・別規範)は 1.0 の後のアップデートまたは続編スコープとする

## 開発体制・期間

- 個人開発(企画・実装・調整)+ 既存アセット/AI活用(グラフィック・音)
- 期間:12ヶ月で EA 開始(M0 → M1 → M2〜EA。期日は [GitHub Milestone](https://github.com/stama72/visionary/milestones) が持つ)

## 主要リスクと縮小プラン

| リスク                               | 対策 / 縮小プラン                                                                                                 |
| ------------------------------------ | ----------------------------------------------------------------------------------------------------------------- |
| 相場の聞き込みと売買が「作業」になる | ニーズ発見→充足をクエスト的な単位としてループの中心に据える(v0.2で反映)。経済は簡略化しても捨てない。ニーズと価格の両方がシムから創発することが、単なるおつかいゲームとの差別化の生命線 |
| 信用のシム組み込みで複雑化・バランス崩壊 | M1でアルゴリズム段階から検証する(M0 は信用を持たない。[ADR-0015](adr/0015-roadmap-rebuilt-from-minimal-element.md))。厳しければNPC同士の取引への適用を切り、「プレイヤー⇔NPC間の取引条件・会話発生条件」への縮小実装にフォールバック |
| ニーズを会話で提示する台詞量が膨張   | シム状態→台詞のテンプレート+パラメータ差し込みで生成。手書き台詞は主要NPCに限定。変換パイプラインはTDDの検証項目とする |
| エージェントシムのスコープ膨張       | シム部を純C#ライブラリに分離し、品目・NPC数を設定値で制御。上限を仕様で固定                                       |
| 1年で完成しない                      | 下の縮小順序に従って切る。各マイルストーンで発動の要否をレビューする(企画書 §6) |

### 縮小順序

**対象は [企画書 §6](02-project-proposal.md) の M2〜EA の行の項目である** — EA の期限を縮めるのは、EA までに作るものを切ることだけだからである。EA 後のアップデート(教会・訪問と招待など)は順序に入れない。M1 の中身と期日の釣り合いは [#246](https://github.com/stama72/visionary/issues/246) が持つ。[世界観設定書 §1.1](02b-world-setting.md) の四つのアプローチ(b 成長 / c 絆 / d 日常の美しさ / a 灯火)の重みに従い、**d の風味から切り、経済の深さを後に残す** — 深さが差別化の軸だからである([企画書 §3.2](02-project-proposal.md))。

| 切る順 | 何を | 切ったときに残るもの |
| ------ | ---- | -------------------- |
| 1 | d **季節ごとのビジュアル変化**(タイル・木の紅葉と落葉の差し替え) | 季節は明るさ・昼の長さ・天候・シムの状態で出す。素材の量が4倍にならない |
| 2 | d **マップ拡張** | 3×3 のマップと M1 の中世風のマップ |
| 3 | c・d **外部 NPC(水夫)** | 都市の住人 |
| 4 | c **季節市** | 日々の市 |
| 5 | b **運送手段** | 徒歩の行商 |
| 6 | b **職業追加** | M1 の職業と品目(下限9種。[ADR-0007](adr/0007-m1-scale-follows-economic-model.md)) |
| 7 | b **雇用と家事** | 世帯単位の生産と消費 |
| 8 | b **生産関数の本格調整** | M1 の生産関数 |
| 9 | b **都市外交易** | 都市外市場の窓口([GDD02d](03-gdd/02d-external-market-and-money.md)) |

**港と海の描写は M2 に入ってから判断する。** 海沿いの都市であることと海上貿易は世界観の芯なので、縮小順序には入れない。

**切らないもの:**

- b **最小構成要素**(困りごとを取引で解決し、感謝される)と、**自分の店と店番の従業員**(EA の成長の到達点。[ADR-0015](adr/0015-roadmap-rebuilt-from-minimal-element.md) 論点4)
- c **の基礎**(会話・信用・人助け)
- d **都市の動き**(NPC の生活動線・時刻の明るさ・天候・季節のシム側)。アート品質の代わりに暖かさを出す担い手である([検討資料02a §5](02a-identity-and-positioning.md))
- **最低限の音楽**
