## ハイコンセプト(1文)

**神視点ではなく、地面から見る経済シミュレーション。**
中近世の都市を自分の足で歩き、噂と相場を頼りに商いをして、生きた経済の中で一介の行商人から都市を動かす豪商へ成り上がる。

## ジャンル / プラットフォーム / 価格帯

- ジャンル:商人ライフシム × エージェントベース経済シミュレーション
- 視点:2Dトップダウン(主人公目線で街を歩く。俯瞰マップ・神視点UIを持たない)
- プラットフォーム:PC(Steam)/ 想定価格:1,500〜2,000円
- グラフィック:ピクセルアート(既存アセット+AI生成を活用し、独自制作は最小限)

## ターゲット

- 一次:経済・経営シム好きのコアPCゲーマー(Moonlighter、Potion Craft、大航海時代、Anno系のプレイヤー)
- 二次:生活シム・スローライフ系プレイヤー(Stardew Valley層)のうち、経営要素に惹かれる層

## コアループ

1. **歩く・聞く**:街を歩き、NPCと会話して情報を得る(相場、噂、需要、人間関係、規範)
2. **商う**:情報の非対称性を活かして仕入れ・販売・価格交渉の意思決定をする
3. **広げる**:利益を従業員・店舗・信用(領主/ギルド/教会)へ再投資する
4. **変わる**:経済と都市が変化し(価格、街並み、NPCの暮らし)、新たな機会と義務が生まれる → 1へ

## USP(差別化点)

1. **情報を足で稼ぐことがゲームプレイになる**
   経済シムの定番である全知の相場表を捨てる。プレイヤーが知っている価格は「実際に見聞きした価格」だけ。情報の非対称性がUIの制約ではなく、体験の中心になる。
2. **NPCは台本ではなく、経済合理性+社会規範で動く**
   各NPCは欲求・予算・価値観パラメータを持つ自律エージェント。プレイヤーの買い占めが価格を動かし、NPCの生活を変え、街の姿に波及する。
3. **マップ=社会実験**
   マップごとに時代・地域・支配的な倫理観(蓄財肯定 / 喜捨規範 / ギルド統制など)を設定。同じシステムの上で「違う社会」が創発するのを遊び比べられる。

## 類似作との差分

| 作品                     | 共通点                   | 本作との差分                                                        |
| ------------------------ | ------------------------ | ------------------------------------------------------------------- |
| Moonlighter              | 商人として売買・価格発見 | 本作は経済が自律シミュレーションで動き、NPC側にも生活と動機がある   |
| 大航海時代シリーズ       | 相場差で稼ぐ交易         | 本作は1都市を深く歩く。俯瞰の交易マップではなく対話と噂で情報を得る |
| Anno / Banished          | 経済シミュレーション     | 本作は神視点を捨て、経済の「中の一人」としてプレイする              |
| Kingdom Come等 没入型RPG | 地に足のついた中世世界   | 本作は戦闘ではなく商いが主活動。シムの深さで勝負する                |

## v1.0 スコープ(上限)

- マップ:**1都市**(時代テーマ1つ)
- 品目:10〜20種 / NPC:50〜100体
- 事業:行商 → 店舗 → 従業員雇用 → 領主の信任による事業拡張(1系統)
- プレイ時間:10〜20時間
- 追加マップ(別時代・別規範)はv1.1以降のアップデートまたは続編スコープとする

## 開発体制・期間

- 個人開発(企画・実装・調整)+ 既存アセット/AI活用(グラフィック・音)
- 期間:12ヶ月(プロト1.5ヶ月 → 垂直スライス4ヶ月 → アルファ8ヶ月 → ベータ10.5ヶ月 → リリース)

## 主要リスクと縮小プラン

| リスク                               | 対策 / 縮小プラン                                                                                                 |
| ------------------------------------ | ----------------------------------------------------------------------------------------------------------------- |
| 創発経済が「正しい」が「面白くない」 | M0で判定。面白くなければ経済を簡略化し、会話・交渉・成り上がりのRPG的手触りに軸足を移す                           |
| エージェントシムのスコープ膨張       | シム部を純C#ライブラリに分離し、品目・NPC数を設定値で制御。上限を仕様で固定                                       |
| 1年で完成しない                      | 縮小順序を事前定義:社会規範システム → 従業員AI深度 → 品目数 → 都市イベント。コアループ(歩く・聞く・商う)は死守 |
