## 0. この文書の位置づけ

**本書は「この世界が何であるか」と「それをどう見せるか」を持つ。** GDD より上に置く。GDD は個々のシステムの設計図であり、本書はすべての分冊・アート・台詞・ストアページが同じ世界を指すための基準である。

- **なぜこの時代・地域を選んだか**は [ADR-0011](adr/0011-hanseatic-city-and-council.md) が持つ。本書は結果としての「今の設定」だけを書く
- **メカニクスは書かない。** 本書が「同情で必需品を割り引く商人がいる」と書き、それがどう数値になるかは GDD が持つ。本書からどの分冊へ何が流れるかは §12
- **史実は借りるが縛られない。** 都市名・人名・年号は架空である。借りるのは制度と空気であって年表ではない(ADR-0011 帰結)

## 1. 核 — 一文と四つのアプローチ

> **都市に広がる明かりと往来、巡り続ける四季と営み。**
>
> プレイヤーは、その往来の中の一人である。

ハイコンセプト「中世都市に暮らす、ひとりの商人のリアリティ」([コンセプトシート](01-concept-sheet.md))を、世界の側から言い直したものである。**本作の本質は「生活感」にあり、その暖かみの側に置く。** 経済シミュレーションと商人 RPG が交わる中心は、都市で人が暮らしていることそのものだからである。暗い面も作るが、それは暖かさを成立させる地面であって主題ではない。**「都市で生きる」ことに価値を感じる作品にする。**

一文の四つの語は、それぞれ世界の担い手を指す。

| 語 | 指すもの | 本書 |
| -- | -------- | ---- |
| 明かり | 夜の街にともる生の証。松明・暖炉・蝋燭 | §6 |
| 往来 | 人が行き交い、互いに関わる都市。生きた経済とコミュニティ | §3・§4・§5 |
| 四季 | 巡る季節と自然。港の開閉、収穫、昼の長さ | §6 |
| 営み | 働き、稼ぎ、食べ、暮らす日々。竈の煙 | §5・§6 |

### 1.1 四つのアプローチと位置づけ

中世の深みと cozy な体験を両立させるために、四つのアプローチを組み合わせる。**四つとも価値があるが、同じ重さではない。**

| | アプローチ | 何で出すか | 位置づけ |
| - | ---------- | ---------- | -------- |
| **b** | **地に足の着いた成長**(泥臭さ × 希望) | 商人としてのサクセスストーリー。お金を稼ぐ、店を持つ | **コアループ** |
| **c** | **コミュニティと絆**(人間賛歌) | NPC との交流から信用を得ていく体験、コミュニティの中での人助け | **心をつかむ** |
| **d** | **日常の美しさ**(コージー・ライフシム) | 風景の美しさ、季節の変化。**主に都市の動きが担い**、ドット絵と音楽は効率を優先する | **作品世界への愛着を生む** |
| **a** | **暗闇の中の灯火**(コントラスト) | 主に教会が担う。厳しさの中の救い(§7) | **スパイス** |

**差別化を生むのは b と c の組み合わせである。** 地面の視点で成長していく経済シミュレーションは独自性を持ち、経済状態がそのままリアルな生活になるコミュニティは、既存のライフシム以上の没入を生みうる。

c は v1.0 の後に最も大きく伸びる余地を持つ — 季節行事、NPC を家に招く・招かれる、約束して一緒に出かける、会話イベント、結婚。v1.0 での深さと、切るときの順序は [コンセプトシート](01-concept-sheet.md)のリスク表(縮小順序)が持つ。

## 2. 舞台 — 時代・場所・制度(今の仕様)

| 項目 | 設定 |
| ---- | ---- |
| 時代 | 15世紀。印刷術の前後、宗教改革の前。**カトリックの時代** |
| 場所 | 北海沿岸の**ハンザ同盟に属する自由都市**(架空)。周囲は都市の支配下にある農村・森林 |
| 都市の統治 | **市参事会**(大商人の合議体)。封建領主はいない。課税・財政・衛兵・城壁と港の建設は参事会が決める |
| 経済の骨格 | 港を通じた遠隔地貿易(塩・穀物・ニシン・毛織物・毛皮・蝋)と、都市内の手工業。冬は北海の航海が止まり、港が閉じる |
| 宗教 | カトリック。教会は利子と過剰な利得を「強欲」の罪と教える。修道会が救貧を担う |
| 社会の緊張 | 参事会を占める大商人 対 手工業者(ツンフト闘争)/ 教会 対 商人の政治権力 / 遠隔地商人 対 港湾の日雇い |

この設定が本作に与えるものと奪うものは [ADR-0011](adr/0011-hanseatic-city-and-council.md) の理由と帰結に書いた。要点だけ:**港と貿易が自然に立つ。利子で増やす金融ではなく、日々の利ざやを足で稼ぐことが商人の本業になる。貧富の格差と転落が、作り足さなくても設定として最初からある。代わりに「領主」という分かりやすい権力を失い、参事会は顔のある複数の商人として設計する。**

## 3. 都市に生きる人々

職業と世帯の仕様は [GDD02 §3](03-gdd/02-economy.md)・[GDD08](03-gdd/08-household-and-decision.md) が持つ。本節は「どんな人がいて、何を恐れ、何を望んでいるか」だけを書く。

| 層 | 誰か | 恐れているもの | 望んでいるもの |
| -- | ---- | -------------- | -------------- |
| 参事会家門 | 遠隔地貿易で財を成した大商人。参事会を占める | 家門の没落、船の難破、神の裁き | 家名の存続、死後の魂の救い(寄進・施療院の建設) |
| 商人 | 店を構える商人、行商人、貿易商 | 掛け売りの踏み倒し、相場の読み違い、信用の失墜 | 常連、大口の信任、いつか参事会へ |
| 手工業の親方 | 工房と徒弟を持つ | 原料の高騰、注文の途絶、徒弟を養えなくなること | 工房の維持、ツンフトでの発言力 |
| 職人・徒弟 | 親方の下で働く | 解雇、親方の破産、独立できないまま歳をとること | 独立、あるいは今日の飯 |
| 日雇い・港湾労働者 | 船が着けば働き、着かなければ働けない | 冬、病、飢え | 明日も仕事があること |
| 聖職者・修道者 | 教会と修道院。救貧と看取り | 信仰の衰え、施しの枯渇 | 魂の救い、貧者の救済 |
| 貧民・寡婦・孤児 | 転落した者、農村から流入した者 | 明日 | 施し、仕事、居場所 |

**誰も端役ではない。** 経済シムの上では全員が家計を持つエージェントであり、会話の上では全員が自分の事情を語る。日雇いの一言は、大商人の一言と同じ重さで街の情報である。

## 4. 社会規範 — 協調を保つ仕組み

経済学とゲーム理論の視点で言えば、社会規範とは**社会の構成員全員が協調戦略を維持できるようにするための環境**である。裏切れば損をする、困れば助けてもらえる、だから今日も約束を守る。本作の規範はこの見方で設計する。

| 仕組み | 世界での姿 | ゲームでの入口 |
| ------ | ---------- | -------------- |
| **信用** | 約束を守る者が取引相手に選ばれ、破った者は街で相手にされなくなる。繰り返し取引する都市だからこそ評判が資本になる | [GDD01](03-gdd/01-trust-and-conversation.md)(実装済みの軸) |
| **教会の活動** | 説教が強欲を戒め、修道会が貧者に食事と寝床を与え、死にゆく者を看取る。施しは商人の贖罪でもある | GDD07(未着手)。v1.0 で実装する |
| **同情** | 困窮している相手に、商人が必需品を割り引いて売る。損をしてでも隣人を生かす | [GDD06](03-gdd/06-trade-and-negotiation.md)。v1.0 で実装する |
| **相互扶助** | ツンフトと兄弟団が、病人・寡婦・葬儀を面倒みる。ギルドは統制の装置であると同時に保険でもある | GDD07(未着手)。v1.0 では特定の形に特化しない |

**v1.0 では、特定の規範に特化しない。** 教会の活動と、困窮者への必需品の割引(同情)の二つを入れる。マップごとに支配的な倫理観を変える構想(コンセプトシート USP④「マップ=社会実験」)は、この二つが機能してから広げる。

## 5. 暖かさ

**暖かさは本作の本質である**(§1)。厳しさ(§7)が本物だから、暖かさは作り物に見えない — ただし主従はこちらが主である。

| 暖かさ | 世界での姿 | アプローチ |
| ------ | ---------- | ---------- |
| **人と人の間** | 顔なじみができ、名前で呼ばれ、頼まれごとをされる。約束を守った相手が次の商いを持ってくる。困っている隣人を助け、助けられる | c |
| **成り上がりの手応え** | 小銭を足で稼ぎ、屋台が店になり、店に常連がつく。自分の商いで街の暮らしが少し変わる | b |
| **豊作の喜び** | 秋の収穫、季節市に集まる農民、春に港が開いて最初の船が着く日。街が明るくなる | d |
| **大過なく充足した日々** | 何も起きない一日。道端の花、屋根の猫、夕方の鐘、夕餉の煙。ほとんどの日はこれであり、その幸せが分かるように作る | d |
| **同情と信仰からの助け合い** | 困窮した隣人への割引、施し、看取り。修道女が貧民街の教会で花を育てている | a・c |
| **合理的な行動としての協力** | 掛け売り、共同の仕入れ、ツンフトの相互扶助。助けることが長期的に得である社会 | b・c |
| **教会による救貧** | 施療院と孤児院。商人の寄進で建ち、修道会が運営する。街の富が貧者へ還流する経路 | a |

**暖かさは言葉では伝わらない。** 季節・天候・人々の生活動線の演出で出す([検討資料02a §5](02a-identity-and-positioning.md)「世界が動いている感」)。絵の上手さではなく、世界が動いていることで暖かさを出す。その反復モチーフは §6 が持つ。

## 6. 象徴 — 花・明かり・煙・四季

アート・音・UI・台詞が繰り返し立ち返るモチーフ。**どれも「生」の側の象徴であり、世界の状態とともに変わる。** 一枚絵の美しさではなく、時間とともに変わることで見せる。

| 象徴 | 意味 | 世界での姿 |
| ---- | ---- | ---------- |
| **花** | はかなさの象徴であり、ささやかな繁栄の証でもある | 道端の花、教会の花([idea/004 §2.1](idea/004-教会.md))、商家の窓のフラワーボックス。季節で咲き、枯れる |
| **明かり** | 花と並ぶ生の象徴。夜の中に人がいることの証 | 松明、暖炉、蝋燭。夜の街に灯りがともり、消えていく |
| **煙** | 暮らしの象徴 | 暖炉と調理で燃やす薪の煙。煙が上がる家には、今日の営みがある |
| **四季と自然** | 巡り続ける時間 | 時刻による明るさの変化、月明かりの満ち欠け、季節による昼の長さの変化。木の成長・紅葉・落葉。鳥・風・波の音。天気 |

**担い手は主に都市の動きである**(§1.1 の d)。人が歩き、灯りがともり、煙が上がり、季節が移ることは、シムの状態から出せる。ドット絵と音楽は効率を優先し、これらの動きを邪魔しない水準で揃える。

## 7. 厳しさ

**厳しさは主題ではなく、暖かさを成立させる地面である**(§1.1 の a はスパイス)。量を増やして暗さを売らない。

**いかに困難な状況にあっても、人間は生きていくことをやめられない。** 厳しさとは罰でも演出でもなく、生きている経済の当然の帰結として現れる。

### 7.1 経済情勢の悪化

| 事象 | 世界での姿 | 街に起きること |
| ---- | ---------- | -------------- |
| 貨幣の悪化(インフレ) | 参事会が財政のために貨幣の銀含有を落とす。同じ額面で買えるものが減る | 蓄えの目減り。賃金と物価の追いかけっこ |
| 疫病 | ペストが数年おきに戻ってくる。港から入る | 働き手が減り、生産が落ち、葬儀が増える。教会が看取りに追われる |
| 飢饉 | 凶作の年、周辺農村からの穀物が細る。冬に港が閉じれば外からも来ない | 穀物価格の高騰。困窮世帯の連鎖 |
| 戦争・海賊 | 同盟と王国の戦争、海賊による航路の途絶 | 貿易品が入らない。船乗りと日雇いが職を失う |

これらは**都市の状態**であり、個別のクエストではない。どの事象をいつ入れるかは [GDD03 §5](03-gdd/03-seasons-and-city.md)(都市の状態遷移)が持つ。M0・M1 には入らない。

### 7.2 転落

破産した者は街から消えるのではなく、**街の中で下の層へ落ちる**。親方は職人に、職人は日雇いに、日雇いは施しを受ける側に。プレイヤーは転落した相手と翌日も同じ通りで会う。困窮と破産の仕様は [GDD02 §6.3](03-gdd/02-economy.md)、親方の行き先は [GDD10 §3](03-gdd/10-employment.md)。

### 7.3 不合理の中にある皮肉

苦しいときこそ酒を飲む。苦しいときこそ一発逆転に賭けたくなる。合理的な家計計算の外側にある行動が、人間らしさであり娯楽でもある。

- **酒場**:困っている者ほど通う。酒が回れば口も軽くなる(情報の場でもある)
- **賭場**:負けが込んだ者が最後の銭を賭ける。プレイヤーも賭けられる
- **占い・噂**:根拠のない「今年の冬は寒い」が薪の値を動かす([idea/002 §2.3](idea/002-都市.md))

これらは NPC の意思決定の「合理性からの逸脱」として GDD08 に接続する。原典は [idea/002 §1.2](idea/002-都市.md)。

### 7.4 合理性の中にある残酷さ

経済情勢が悪化したとき、**貧困に陥ると分かった上で徒弟を解雇できるか**。親方 NPC はする([GDD10 §2.1](03-gdd/10-employment.md))。工房を守るために、養えない者を切る。それは正しい判断であり、同時に残酷である。

プレイヤーは中盤で従業員を雇う([企画書 §4](02-project-proposal.md))。だから同じ問いがプレイヤーにも来る。本作はこの選択に正解を用意しない。

## 8. 同じ人間の中に — 両立の原則

厳しさと暖かさを別々の人物に割り振らない。**同じ一人の中に両方がある**ことが、本作の人間の描き方である。

- 不況の年に徒弟を解雇した親方が、翌年その徒弟の葬儀に金を出す
- 利子を取って財を成した大商人が、死の床で全財産を施療院に寄進する(贖罪。[idea/004 §1.2](idea/004-教会.md))
- 困窮した隣人にパンを割り引いた商人が、翌日には別の客に高値を吹っかける
- 修道女は貧者を救うが、街の商人に施しを求めて頭を下げ続ける現実主義者でもある

台詞と行動の設計はこの原則に従う。**善人と悪人を作らない。事情のある人を作る。**

## 9. プレイヤーの立ち位置

**プレイヤーは例外ではない。この都市に生き、選択することを迫られる。**

- よそ者として着く。誰も自分を知らない([企画書 §4](02-project-proposal.md) 序盤)。市民権は、一年と一日をこの街で暮らして初めて得られる
- 掛け売りを踏み倒される側にもなる。相場を読み違えて損もする。破産すれば、街の中で下の層へ落ちる
- 従業員を養えなくなったとき、解雇するかを選ぶ(§7.4)。困窮した客に割り引くかを選ぶ。教会に寄進するか、その金で仕入れるかを選ぶ
- 本作はどの選択が正しいかを言わない。街が結果で応える(信用、噂、価格、街並み)

プレイヤーは神ではなく、街の中の一人である(コンセプトシート「神視点UIを持たない」)。この視点の制約は UI の都合ではなく、世界観の帰結である。

## 10. 語り口と表現の指針

台詞テンプレート(GDD01 §3.3)、ストアページ、アートに共通する指針。

- **説教しない。** ナレーションで教訓を語らない。「解雇は残酷だ」と誰も言わない。徒弟が翌日日雇いの列に並んでいるだけである
- **人は自分の事情を語る。** NPC は世界の説明をしない。自分の家計、自分の困りごと、自分が聞いた噂を話す。世界はその断片から立ち上がる
- **数字の裏に人がいる。** 価格が上がったとき、プレイヤーが見るのは数字ではなく「今週は薪が買えない」と言う人である
- **メメント・モリとカルペ・ディエムを同時に。** 死が近い街だからこそ、今日の酒と祭りが輝く([idea/004 §1](idea/004-教会.md))。暗さに沈まない
- **象徴で語る。** 花・明かり・煙・四季(§6)を反復モチーフとして使い、状態の変化で見せる
- **ビジュアルは中世 × レトロ 2D。** 紙とスクロール風の UI([idea/006](idea/006-ビジュアル.md))。Stardew に寄せない
