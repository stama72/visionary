## 1. エグゼクティブサマリ

**中世都市に暮らす、ひとりの商人のリアリティ。** 生きた都市で、生きた暮らしができるゲーム——中近世都市を自分の足で歩き、人々のニーズを見つけて商いをし、信用を元手に成り上がる商人ライフシム。エージェントベースの経済シミュレーションが「都市が生きている」ことを、季節・天候・人々の暮らしの質感が「暮らしが生きている」ことを支える。

マーケティングの第一声には「**相場表のない経済シム。情報は足で稼げ**」という尖ったフックを用いる。作るもの(アイデンティティ)と第一声(フック)を分離する二層戦略([検討資料02a](02a-identity-and-positioning.md)で決定)。

- プラットフォーム:PC(Steam)/ **早期アクセスで開始**(EA価格1,400〜1,800円、1.0で改定余地)/ 日英対応
- 開発:個人・12ヶ月(2026-09〜2027-08 **EA開始**目標。1.0は就活明け2028年度に照準)
- 基準販売目標:**EA開始後1年で5,000本**(悲観1,000本/楽観30,000本)

## 2. アイデンティティと企画コンセプト(要約)

本作の本質は「経済シム」でも「ライフシム」でもなく、その交差点にある:**生きた都市で、生きた暮らしができるゲーム**。経済シミュレーションの深さは「都市が生きている」ことの実装であり、生活の質感(季節・天候・人々の暮らし、富と困窮のコントラスト)は「暮らしが生きている」ことの実装である。どちらかが手段でどちらかが目的なのではなく、同じ一つの体験の両面である(詳細:[検討資料02a](02a-identity-and-positioning.md) §1)。

企画詳細は[コンセプトシート](01-concept-sheet.md)を正とする。本書では要点のみ:

- **コアループ**:歩く・聞く(ニーズと情報の発見)→ 商う(ニーズ充足・交渉・約束の履行)→ 信用を築く・広げる(再投資)→ 都市が変わる
- **USP**:①情報を足で稼ぐ(全知の相場表を持たない)②NPCは経済合理性+社会規範で動く自律エージェント ③信用が資本になる ④マップ=社会実験
- **v1.0スコープ上限**:1都市、品目10〜20種、NPC 50〜100体、プレイ時間10〜20時間

## 3. 市場分析

### 3.1 参照タイトルの実績

「商人・店主として商いをするゲーム」はSteamで実績あるジャンルであり、小規模開発でも十分な売上例がある。

| タイトル | 体制・価格帯 | 実績(出典ベース) | 本作への示唆 |
|---|---|---|---|
| Moonlighter | 小規模+パブリッシャー / $19.99 | 2年で100万本、2022年に累計200万本 | 「商人」フックはマス層に届く。ただし戦闘(ローグライト)併用型 |
| Potion Craft | 小規模 / $14.99 | 早期アクセス開始3日で10万本、Steam売上世界1位を3日間維持 | 「職業ロールプレイ×触って楽しいUI」の強さ。フックが一言で伝わることの価値 |
| Travellers Rest | 少人数 / $17.99 | 推定38万〜93万本、推定粗収益$4.1M以上、レビュー約1.8万件(88%好評) | 酒場経営=「場を営む」ライフシムの市場は太い。早期アクセス長期運用モデル |
| Strange Horticulture | **2人開発** / $15.99 | Steam2ヶ月で6万本・$75万、全機種累計100万本超 | **少人数でも「会話と観察が中心の店主ゲーム」で大きく当てられる**ことの直接的な証明。本作に最も近い成功モデル |
| Winkeltje: The Little Shop | 少人数 / $19.99 | レビュー約1,600件(88%好評)。推定数万本規模 | 堅実な中規模ヒット。本作の悲観〜基準ケースの現実的な参照点 |
| The Guild 3 | 中規模スタジオ / $39.99 | レビュー約2,700件、**59%(Mixed)** | **反面教師**。中世商人ライフシムという近接コンセプトで、シムの複雑さに手触りとコンテンツの完成度が追いつかず失敗した先例 |

推定値はレビュー数×係数(Boxleiter法、目安30〜50倍)および外部推計サイトによる概算を含む。

### 3.2 市場からの示唆

1. **ジャンル需要は実証済み**:商人・店主・経営ライフシムは「Steamで個人〜少人数開発が戦える」代表的ジャンルであり、100万本級の上振れ事例が複数ある。
2. **低価格cozyショップシムは供給過剰**:2024年以降「◯◯ Shop Simulator」型の低価格タイトルが大量供給されており、「店を経営できます」だけでは埋没する。**差別化の軸は「生きた経済シム+信用」という深さであり、これを捨てると本作はレッドオーシャン側に落ちる**(コンセプトシートのリスク表「経済は簡略化しても捨てない」と対応)。
3. **The Guild 3の教訓**:シムの野心が大きくても、プレイヤーから見た手触り(何をすると何が起きるか)が濁ると評価が崩壊する。本作はスコープ上限(1都市・品目20・NPC100)を仕様で固定し、「浅く広く」ではなく「狭く生きている」を目指す。
4. **フックの一言性が生死を分ける**:Potion Craft・Strange Horticultureはストアページの3秒で価値が伝わる。本作のフックは「**相場表のない経済シム。情報は足で稼げ**」で統一する。

### 3.3 ポジショニング

```
          シム深度:深い
              │
   The Guild 3│  ★本作
   (神視点寄り)│  (地面視点)
              │
 神視点 ──────┼────── 主人公視点
              │
  Anno/Banished│  Moonlighter
              │  Winkeltje / cozy系
          シム深度:浅い
```

「主人公視点 × シム深度が深い」の右上象限はほぼ空白。ここが本作のポジション。

### 3.4 ライフシム市場と二層戦略

ライフシム側の市場調査([検討資料02a](02a-identity-and-positioning.md) §2に詳細と出典)からの要点:

- 「Stardew Valleyみたいなゲーム」の需要の裾野は最大級だが、市場は飽和(農業系はSteamシミュレーションの10%超、当事者の「the boom is over」発言)。勝者(Fields of Mistria:EA初週10万本→累計100万本)の条件は極めて高品質なアートであり、既存アセット+AI生成の本作はこの土俵で正面勝負できない
- 本作に近い「中間ポジション」の先行者(Kynseed 10〜20万本、Mirthwood 70% Mixed、The Guild 3 59% Mixed)は苦戦しているが、失敗理由は共通して「**機能を広げすぎて全てが浅い**」。商い一本に絞り生活の質感を纏わせる本作の構成は未踏
- 結論(**二層戦略**):アイデンティティは中間(生きた都市で生きた暮らし)、マーケティングの第一声は経済シム側の尖った言葉。cozy層はストアページのスクリーンショット・GIFの暖かさで二次的に獲得する
- ビジュアルはStardew系に「寄せて勝負」しない。絵の上手さではなく「**世界が動いている感**」(季節・天候・NPCの生活動線の演出)で暖かさを出す——これは本作のシム技術がそのまま活きる土俵である

## 4. ターゲットとプレイ体験

- **一次ターゲット**:経済・経営シム好きのコアPCゲーマー(Potion Craft、Moonlighter、大航海時代、Anno系)。「数字の裏に世界がある」ことに喜びを感じる層
- **二次ターゲット**:スローライフ・生活シム層(Stardew Valley、Travellers Rest)のうち、人間関係と商いの要素に惹かれる層

**体験の流れ(基準ケース)**:
- 序盤(〜2時間):行商人として着任。誰も自分を知らない街で、会話から小さなニーズを拾い、初めての「ありがとう」と利益を得る
- 中盤(〜10時間):常連と信用ができ、掛け売り・大口取引・従業員雇用が解禁。街の経済の因果(自分の買い占めが価格を動かす)が見え始める
- 終盤(〜20時間):領主・ギルドの信任を得て事業を拡張。都市の姿が自分の商いの結果として変わっていく

## 5. 販売計画

### 5.1 価格と販売目標

価格:EA開始時 **1,400〜1,800円($9.99〜12.99)** を基準に最終調整し、1.0で改定の余地を残す。参照作($15-20)より低く、初作・EA・コンテンツ量見合いの設定。

| ケース | 本数(1年) | 粗売上 | 手取り概算(※) | 前提 |
|---|---|---|---|---|
| 悲観 | 1,000本 | 180万円 | 約90万円 | 発見性を獲得できず。初作インディーの中央値はこの水準以下であり、確率的には最も高い |
| 基準 | 5,000本 | 900万円 | 約450万円 | ウィッシュリスト5,000件以上でリリース、デモ・Next Fest施策が機能 |
| 楽観 | 30,000本 | 5,400万円 | 約2,700万円 | インフルエンサー/メディア露出でフックがバイラル化(Strange Horticulture初動並み) |

※ Steam手数料30%、地域価格・セール・返金・税を含めた概算で粗売上の約50%と仮置き。

### 5.2 マーケティング施策(開発と並行)

| 時期 | 施策 |
|---|---|
| M1完了時(2026-12) | Steamページ公開。以後ウィッシュリスト数を毎月記録 |
| M2期間中 | 開発ログ発信(X/YouTube短尺)。GIFで「相場表がない」体験を見せる |
| M3(2027-06頃) | 無料デモ公開 → 直近のSteam Next Fest参加(ウィッシュリスト獲得の主戦場) |
| EA開始 | 日英同時。ローンチ割引10% |

**EA開始ゲート**:ウィッシュリスト5,000件未満の場合、EA開始を遅らせて施策を追加するか、価格・スコープを再検討する(M3レビューで判断)。

### 5.3 早期アクセス運用計画

EAはこのジャンルの標準ルート(Travellers Rest、Fields of Mistria、Coral Island等)だが、未完成EAへの不信も強い。**EA開始条件は「完成した楽しさ5〜10時間」とし、ここは妥協しない。**

| 期間 | 運用 |
|---|---|
| 2027-08 EA開始 | 完成した5〜10時間+ロードマップ公開 |
| 2027-09〜2028-03(就活期) | 低負荷運用:バグ修正・小規模パッチのみ。コミュニティ対応は週次にバッチ化 |
| 2028-04〜(内定後) | 本格アップデート再開。経済深化+コンテンツ追加を積み、1.0で価格改定 |

この構造により「早めに出して就活前に実績化する」と「継続開発で化ける余地を残す」を両立する。

## 7. 体制とコスト

- 開発:個人(企画・実装・調整)。グラフィック・音は既存アセット+AI生成を活用し独自制作を最小化
- 技術:Godot 4 + C#、シム部は純C#ライブラリ(`Visionary.Sim`)として分離([ADR-0001](adr/0001-engine-and-simulation-architecture.md))

| 費目 | 概算 |
|---|---|
| Steam Direct登録料 | $100(約1.5万円) |
| アセット購入(タイルセット・キャラ・音) | 3〜5万円 |
| ツール(Aseprite等)・フォントライセンス | 1〜2万円 |
| 翻訳校正(英語ネイティブチェック、外注) | 3〜5万円 |
| **合計** | **約10〜15万円** |

損益分岐は約150本。金銭的リスクは極小であり、実質的なリスクは12ヶ月の機会費用に集中する。

## 8. リスク(企画書レベル)

技術・デザインリスクは[コンセプトシート](01-concept-sheet.md)のリスク表を正とする。本書では事業リスクを追加:

| リスク | 対策 |
|---|---|
| 発見性の欠如(誰にも見つからない) | フックの一言性(「相場表のない経済シム」)をストア・発信のすべてで統一。M1からウィッシュリストを計測しゲートで判断 |
| cozyショップシム供給過剰への埋没 | 「深さ」側に明確にポジショニング。cozy文脈の見た目に寄せすぎない |
| 就活時期と開発期間の競合 | M2(機能凍結)までを最優先。以降は遅延しても「動く全機能+文書一式」がポートフォリオとして成立する構造にする |
| EA長期化によるジャンル不信への巻き込まれ | EA開始条件「完成した5〜10時間」を厳守。ロードマップを公開し、就活期も月次で小さく更新を継続して「生きているプロジェクト」を示す |
