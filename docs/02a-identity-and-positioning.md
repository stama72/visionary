## 0. 問題提起

企画書v0.1は「既存の経済/経営シムとどう differentiate するか」に焦点があり、**この作品が何であるのか**が伝わらない。差別化は「何と違うか」しか語らず、アイデンティティは「何であるか」を語る。本資料では (1) アイデンティティの言語化、(2) ライフシム側の市場調査、(3) 3つの販売戦略の比較検討を行う。

## 1. 作品のアイデンティティ

### 1.1 二つの挑戦

この作品は、性質の異なる二つの挑戦の交差点にある。

- **高度な経済シミュレーション**:エンジニア・経済学徒としての挑戦。NPC一人ひとりが家計と動機を持ち、都市の経済が創発する。「生きた経済に触れられる」体験
- **生きた暖かみのあるライフシム**:コミュニティと自然の中で暮らしている感覚(Stardew Valley的)。「何かを作りたい」「誰かの暮らしを変えたい」という思いを行動と言葉に変え、人脈を広げ、信頼を勝ち取り、夢を実現していく体験(『本好きの下剋上』的)。天候や季節が農家の収穫も道端の花も変え、街の暮らしと自然が地続きである世界

### 1.2 本質は交差点にある

二つは別のものだが、組み合わせることで初めて独自性が生まれる。**「生きた都市で、生きた暮らしができるゲーム」**——経済シムの深さは「都市が生きている」ことの実装であり、ライフシムの暖かさは「暮らしが生きている」ことの実装である。どちらかが手段でどちらかが目的なのではなく、同じ一つの体験の両面である。

提供する体験の本質:**生きた街の中で、人々と関わり、彼らのために働き、何かを達成する心地よさ。**

idea/002の「貧しい人たちの暮らしにも光を当てる」「生と死、富と困窮のコントラストを描くことが人間を描くこと」という記述は、この作品が単なるcozyでも単なる経済パズルでもないことを示す、アイデンティティの中核的な一文である。

### 1.3 一言で言うと(候補、要決定)

- **案A:「中世都市に暮らす、ひとりの商人のリアリティ」← 決定(2026-08-23、起案者)**
- 案B:「生きた都市で、生きた暮らしを」(アイデンティティの説明文として本文中で併用)
- 案C:「街の人みんなに、家計と事情がある。商人としてそこに割って入れ」(フック側の言葉として活用余地あり)

### 2.2 市場からの示唆

1. **需要の裾野は最大級**:「Stardew Valleyみたいなゲーム」を探すプレイヤーは恒常的に大量にいる(検索・推薦記事・Redditスレッドが無数に存在)。認知さえされれば流入経路は太い。
2. **ただし「ブームは終わった」**:農業系はSteamシミュレーションジャンルの10%超を占める飽和状態で、Stardew Valley元開発協力者のArthur Lee自身が「the boom is over」と発言。未完成EAの乱発でジャンルへの信頼も摩耗している。
3. **勝者の共通点はビジュアルの第一印象**:Fields of Mistriaの成功はアート品質による。cozy層はスクリーンショット3枚で買う/買わないを決める。**既存アセット+AI生成の絵作りで、この土俵の正面勝負はできない**。
4. **EAはこのジャンルの標準ルート**:Travellers Rest(6年)、Fields of Mistria(2年)、Coral Island、Sun Havenと、主要作はほぼ全てEA出身。ただしEA開始時点で「既に楽しい5〜10時間」が要求され、未完成品への風当たりは年々強い。
5. **中間ポジションの先行者は苦戦している**:Kynseed(実力者でも中規模止まり)、Mirthwood(Mixed)、The Guild 3(Mixed)。ただし失敗理由は共通して「**機能を広げすぎて、すべてが浅い**」。中間だから失敗したのではなく、中間を「両ジャンルの機能の和集合」と解釈したから失敗した。本作のように「商い一本に絞り、その周りに生活の質感を配置する」構成は、実はどの先行者も試していない。

## 3. 制約の再確認(戦略評価の前提)

- **工数**:学期中 週10〜20h、休暇中 週50h → **1年で約1,200時間**(専業の約半分)
- **期限**:就活開始(3年春=2028年春)前にリリース済みが必須 → 1〜1.5年。内定後(4年春〜)に本格アップデートの余力が生まれる
- **含意**:1,200時間は「経済シムの深さ」と「ライフシムのコンテンツ量」の**両方を初回リリースで満たすには絶対的に足りない**。どちらを初回リリースの評価軸にするか=どちらを「EAや無料アプデで育てる側」に回すかの選択が戦略の本体になる

## 4. 3つの販売戦略の比較

### 戦略A:経済シム寄り(企画書v0.1の現行戦略)

フック「相場表のない経済シム。情報は足で稼げ」。深さで訴求し、ライフシム要素は補完。

| 論点                     | 評価                                                                                                                                                                                                   |
| ------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 宣伝・流入経路           | シム系コミュニティ(r/tycoon、r/BaseBuildingGames、Songs of Syx/RimWorld層)、シミュレーション系キュレータ、創発の面白GIF(「NPCの買い占めで価格が動く」)。ニッチだが**競合が少なく声が通りやすい** |
| 売上見込み               | 基準3,000〜5,000本。深さに刺さる層は購買力・口コミ力が高い(Songs of Syx型)。上振れ天井は中(〜5万本)                                                                                                    |
| 1,000本の確度            | **中〜高**。フックの一言性が強く、ニッチ内で埋没しにくい                                                                                                                                         |
| 作りたいものとのギャップ | **あり(これが本資料の出発点)**。暖かい暮らしの体験が訴求から抜け落ちる。また「深さ」を期待して来た層に1,200時間分のシムでは浅いと言われるリスク(Guild 3化)                                       |
| スコープ縮小耐性         | **弱い**。深さそのものが売りなので、シムを削ると訴求が崩壊する                                                                                                                                   |
| 継続開発で化けるか       | 化け得る(Songs of Syx型のEA深化)。ただし深化は工数勝負で、週10〜20hの体制と相性が悪い                                                                                                                  |

### 戦略B:ライフシム寄り(Stardewフォロワー・ポジション)

グラフィックと雰囲気をStardew Valley/Travellers Restに寄せ、「ちょっとひねったStardew系」として cozy 市場の流入を狙う。

| 論点                     | 評価                                                                                                                                                        |
| ------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 宣伝・流入経路           | 最大の裾野(Stardew-like検索、cozy系インフルエンサー、TikTok)。ただし**同じ入口に競合が最も密集**しており、入口の勝敗はビジュアル第一印象で決まる      |
| 売上見込み               | 天井は最大(Fields of Mistria 100万本)だが、それはアート品質とコンテンツ量の達成が条件。本作の体制では中央値シナリオが最も低い                               |
| 1,000本の確度            | **低〜中**。既存アセット+AI絵はcozy層の審美眼と最も相性が悪く、埋没確率が3戦略で最大                                                                  |
| 作りたいものとのギャップ | 情緒面は合うが、**コンテンツ量の期待と1,200時間の現実のギャップが致命的**。「農業も釣りも結婚もないの?」という評価軸に引きずり込まれる(Mirthwoodの轍) |
| スコープ縮小耐性         | **最弱**。ライフシムの評価は量(作物・季節イベント・結婚候補・コレクション)に強く相関する                                                              |
| 継続開発で化けるか       | EA長期運用(Travellers Rest型)で化け得るが、数年単位の消耗戦。就活スケジュールと最も相性が悪い                                                               |

### 戦略C:中間(「中世都市に暮らす商人のリアリティ」)

アイデンティティ(§1)をそのまま訴求する。「生きた都市で商人として暮らす」体験を、経済の深さとも、cozyな量とも違う第三の評価軸として提示する。

| 論点                     | 評価                                                                                                                                                                                                                                                                                                                                                |
| ------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 宣伝・流入経路           | 「Stardew系だが、農場ではなく商店。村人全員に家計と事情がある」という**説明可能性の高いピッチ**が立つ。econ層とcozy層の両方に説明できる反面、どちらのコミュニティでも「自分向けだ」と3秒で伝わる工夫が必要(二兎マーケの難所)。中世生活・歴史系の層(Kingdom Come、Manor Lords 200万本の実績が示す「中世リアリティ」需要)が第三の入口になり得る |
| 売上見込み               | 基準3,000〜8,000本。Kynseed(10〜20万本)が現実的な上限参照。中央値は戦略Aと同等以上                                                                                                                                                                                                                                                                  |
| 1,000本の確度            | **中**。フックの磨き込み次第。「中世」「商人」「生きた街」の組み合わせ自体に十分な引きがある(Guild 3が失敗し続けてもプレイヤーが買い続けている=**需要が満たされていない**)                                                                                                                                                              |
| 作りたいものとのギャップ | **最小(ゼロ)**。これが個人開発では決定的に重要——1,200時間×1年半を支えるのはモチベーションであり、作りたいものと売るものの一致は工数の質を直接高める                                                                                                                                                                                        |
| スコープ縮小耐性         | **中〜強**。核は「商いのループ」1本で、生活の質感(季節・天候・花・猫)は少量でも密度として機能する装飾レイヤー。量の評価軸(戦略B)に乗らなければ、削っても破綻しない                                                                                                                                                                            |
| 継続開発で化けるか       | **最大**。経済の深化(econ方向)とコンテンツ追加(cozy方向)の両方が拡張ルートとして開いている。EA→4年春からの本格アップデート→1.0という就活スケジュールとの整合も最良                                                                                                                                                                          |

## 5. 結論:アイデンティティはC、フックはAの言葉で

**アイデンティティ(作るもの)は戦略C**とし、**マーケティングの第一声(フック)には戦略Aの尖った言葉を使う**二層構成を推奨する。

- **作るもの**:「生きた都市で、生きた暮らしができるゲーム」。商いのループを核に、生活の質感(季節・天候・人々の暮らし・貧しさと豊かさのコントラスト)を密度として配置する
- **第一声(3秒で止めるための言葉)**:「相場表のない経済シム」「村人全員に家計がある」系の、尖りで注意を引く言葉。認知の入口は鋭さが全てであり、「暖かさ」は言葉では伝わらない(スクリーンショットと動画で伝わる)
- **二の矢(止まった人に見せるもの)**:ストアページのスクショ・GIFで生活の暖かさと街の質感を見せる。cozy層はここで拾う
- **ビジュアル戦略**:Stardewに「寄せて勝負」はしない(品質バーに届かない)。既存アセットのトーン統一と、光・季節・天候の演出(実装で出せる暖かさ)で減点を防ぐ。**絵の上手さではなく「世界が動いている感」で暖かさを出す**——これは本作のシム技術がそのまま活きる土俵である

### 5.1 リリース形態の推奨

**早期アクセスを基本線とする。**

- 現行M4(2027-08)を「1.0リリース」から「**EA開始**」に読み替える。EA開始時点で5〜10時間の完成した楽しさを要求水準とする(未完成EAへの不信が強いため、ここは妥協しない)
- 就活期間(2027秋〜2028春)は小規模パッチのみの低負荷運用
- 内定後(2028春〜)に本格アップデートを再開し、1.0を目指す——「継続的に開発して化ける」ルートを構造的に確保する
- 価格はEA開始時にやや低め($9.99〜12.99)、1.0で改定の余地を残す
