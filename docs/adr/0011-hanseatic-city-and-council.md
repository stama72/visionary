# ADR-0011: 時代設定を15世紀のハンザ同盟都市に定め、領主の層を市参事会で置き換える

- 日付: 2026-09-16
- ステータス: 承認
- 決定者: stama

## 背景

企画書・コンセプトシート・GDD は「中近世都市」とだけ書き、時代と地域を決めていなかった。一方で文書には**領主**が既に登場している — 終盤の「領主・ギルドの信任」([企画書 §4](../02-project-proposal.md))、「領主の信任による事業拡張」([コンセプトシート](../01-concept-sheet.md))、財政の支出先としての領主・衛兵([GDD09](../03-gdd/09-treasury-and-tax.md))。**時代設定を決めないまま、領主という設定だけが先に埋まっていた。**

時代設定は次の3つに同時に効くため、GDD07(組織)を書き始める前、そして正式タイトル([#68](https://github.com/stama72/visionary/issues/68))を決める前に確定させる必要がある:

- **組織の構造**:誰が税を取り、誰が大口の信任を与えるか(GDD07 / GDD09)
- **社会規範の中身**:蓄財・利子・救貧をどう扱う社会か(コンセプトシート USP②)
- **世界観と名前**:港・教会・貨幣・行事の名称、そしてタイトルが指すもの

候補の原案は [idea/003](../idea/003-時代設定.md)。

## 検討した選択肢

| 案 | 設定 | 都市の支配者 | 主な特徴 |
| -- | ---- | ------------ | -------- |
| 1 | 封建制の領邦都市(中世ドイツ内陸) | 世俗領主または教会領主 | 分かりやすい「領主」がいる。税は領主へ流れる |
| 2 | **15世紀・北海沿岸のハンザ同盟都市** | **市参事会(大商人の合議体)** | 港と遠隔地貿易。カトリック期。教会と商人の緊張、大商人と手工業者の格差 |
| 3 | 15世紀・イタリア都市国家(フィレンツェ型) | 有力家門・商人共和政 | 銀行・複式簿記・資本蓄積。ルネサンスの華やかさ |
| 4 | 架空世界(時代を特定しない) | 任意 | 史実の制約がない |

## 決定

**選択肢2。15世紀の北海沿岸にある、ハンザ同盟に属する架空の自由都市を舞台とする。** 都市に封建領主はいない。都市を治めるのは大商人からなる**市参事会**であり、文書中の「領主」の役割(課税・財政・大口の信任・建設事業の発注)は参事会が引き受ける。

都市名は架空とし、実在都市の再現を目指さない(史実への忠実さを負債にしない)。同盟・宗教・制度の枠組みだけを史実から借りる。

## 理由

決め手は**コアループとの整合**であり、歴史的な魅力の多寡ではない。

- **「足で稼ぐ」商いに時代が味方する。** カトリック期の教会は利子と過剰な利益追求を強欲の罪と教えていた([idea/004](../idea/004-教会.md))。資本を蓄積して金融で増やすのではなく、日々の取引で利ざやを稼ぐことが商人の本業になる。これは「相場表のない経済シム。情報は足で稼げ」という本作のフックそのものである
- **港が自然に立つ。** 都市外市場と貿易([GDD11](../03-gdd/11-external-trade.md))は本作の価格の錨であり貨幣の出入口である。ハンザ都市は港を前提に成り立つ都市なので、貿易の設定に説明が要らない
- **貧富の格差と転落が、史実の構造として最初から都市にある。** 参事会を占める大商人と手工業者の緊張(ツンフト闘争)、遠隔地商人と日雇い労働者の落差は、本作が描きたい「生と死、富と困窮のコントラスト」([idea/002](../idea/002-都市.md) §2.1)を設定として持っている。作り足す必要がない
- **信用がそのまま政治になる。** 参事会は商人の同業者で構成される。プレイヤーが商いで築いた信用が参事会への信任に直結する構造は、「信用が資本になる」(USP③)と一貫する。領主は商人社会の外にいる権力であり、信用の外側に別の通貨(忠誠・献上)を作ることになる
- **税が都市の中で還流する。** [GDD09 §2.1](../03-gdd/09-treasury-and-tax.md)「税収はできるだけ都市内に還流させる」は、税が領外の領主へ流出する案1より、参事会が建設事業・衛兵に支出する案2のほうが素直に成り立つ

### 案1を採らない理由

「領主」は分かりやすいが、商人社会の外側にいる権力である。信任を得る過程がコアループ(歩く・聞く・商う・信用)の外に出てしまい、献上と忠誠という別の系を作ることになる。分かりやすさは、参事会の役割を「都市を治める商人たち」と一言で説明することで補える。

### 案3を採らない理由

金融と簿記が主題になり、資本蓄積のゲームに寄る。相場表のない、情報の非対称性を足で埋める経済と相性が悪い。また参照作(大航海時代・Anno)の華やかな地中海のイメージと被り、ポジショニング上の差別化が弱くなる。

### 案4を採らない理由

「中世リアリティ」への需要(Kingdom Come、Manor Lords の実績。[検討資料02a §4](../02a-identity-and-positioning.md) 戦略C)を入口として使えなくなる。また社会規範(利子の罪、救貧、市参事会)を史実の裏付けなしにプレイヤーへ納得させるのは、説明コストが高い。

## 帰結(受け入れるトレードオフ)

- **文書中の「領主」は「市参事会」へ読み替える。** 企画書 §4・§6、コンセプトシート、GDD01 §3.3・§3.4、GDD02 §13、GDD09、GDD README(GDD07 の行)が対象。反映は別 issue で行う(本 ADR の PR では触らない)
- **武器・甲冑の需要源は参事会(衛兵・城壁)になる。** [GDD09 §2.2](../03-gdd/09-treasury-and-tax.md)「市民は武器を買わない。領主が衛兵に買う」という構造は変わらない。買い手の名前が変わるだけである
- **参事会は「顔のある個人の集まり」として設計する必要がある。** 領主なら1人の NPC で済んだが、参事会は複数の大商人 NPC の合議になる。GDD07 の設計コストは上がる。M0・M1 には入らないので受け入れる
- **冬に港が閉じる。** ハンザの航海は冬季に休止していた。季節が都市外市場に効く形([GDD03 §2](../03-gdd/03-seasons-and-city.md) / [GDD02 §9](../03-gdd/02-economy.md))は、これを前提に GDD11 の実装時点で決める
- **史実は借りるが縛られない。** 都市名・人名・年号は架空とする。史実と違う点を指摘されても直す義務を負わない。借りるのは制度と空気であって、年表ではない
- **時代の「厳しさ」の素材(疫病・飢饉・戦争・貨幣の悪化)は史実にある。** どれをゲームに入れるかは世界観設定書と GDD03(都市の状態遷移)が決める。本 ADR は舞台を決めただけである
